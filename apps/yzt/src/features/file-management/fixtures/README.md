# 文件预览测试样本

三个小文件均为本次自建的固定样本，不包含业务资料、凭据或来自第三方的文档内容。

- `sample.docx`：最小 Open XML 包，含中文、表格、嵌入 PNG、两页、页眉页脚、只读链接和用于确认不渲染的 HTML 片段；由真实浏览器测试使用
- `sample.pdf`：一页英文说明，用于人工检查浏览器原生 PDF 阅读器
- `sample.png`：720 × 420 的简单区域示意，用于图片预览、缩放、下载字节校验与 DOCX 嵌入图片

只给测试和开发样例 `/dev/file-management` 使用，生产业务不导入。它们验证基本解析和资源隔离，不代表复杂 Word 排版、所有图片编码或真实业务文件均已验收。
