# 3D.2：统一视图与二三维切换

日期：2026-10-19。范围遵循 [ADR 0064](../adr/0064-three-dimensional-integration-scope.md)，实现细节见 [map-cesium](../modules/map-cesium.md)。本阶段完成开发页验证，业务页仍使用二维画布。

## 分步结果

| 步骤 | 结果 | 学习点 |
|---|---|---|
| 3D.2a | 会话相机与 Cesium 姿态桥接，隐藏时保存精确姿态 | 共享模型与引擎表示的区别；意图和同步回声的区别 |
| 3D.2b | 统一生命周期、定位、拾取、投影与工具输入 | 窄接口隔离 SDK；纯规划与引擎副作用分离；CSS 坐标与世界坐标 |

## 切换中容易忽略的边界

1. 候选加载完成只代表这一轮 `whenReady()` 成功。恢复二维会追赶隐藏期间的样式，可能再次重载；此时先还原原图，等新一轮完成再交接。
2. 页面隐藏时保留候选准备结果，等页面恢复后验证目标能否激活，不能提前宣告成功。
3. 挂上上下文会同步执行排队的定位。定位回调可以再次切换，旧请求发布结果前仍要检查自己的信号。
4. 回滚自己也可能失败。清理候选、恢复原图、重新连接上下文要逐步保护；无法暂停的候选先释放，避免和原图同时活动。
5. 临时交互与业务结果的寿命不同。暂停通过 `leave` 清掉框选草稿、鼠标提示和测量预览，不能切回浏览工具而丢掉已确定的测量点。

## 验证方式

可控假视图覆盖模块、样式、激活的失败与晚到结果，以及快速切换、缓存、暂停和释放。真实 Chromium 的开发页测试连接 MapLibre 与 Cesium，检查默认二维、失败后原图可用、重试、画布身份复用、相机往返及暂停期间排队定位。

改坏验证将暂停时的 `leave` 改成 `move`，以及去掉交接后的意图检查，分别出现 3 个和 1 个断言失败；恢复后重新通过。具体回归与构建结果记录在 [模块文档](../modules/map-cesium.md#本轮验证与后续验收)。

## 下一步

3D.3a 从简单样式镜像开始，先让会话中的基础图层进入三维，再逐步接入 MVT、Worker 绘制、符号和高亮。不支持工具的能力声明与暂停策略、业务查询、性能及 GPU 资源验收保留到 3D.4；业务页切换随这些验收开放。
