- 独立 `/city-dashboard`，所有登录角色可访问，无菜单入口、不缓存页面；现状底图和登录页不提前加载驾驶舱图形库
- 96 项固定模拟指标、13 市、年份与城市筛选、地图和多年度图表联动、详情、PNG 导出及动画；模拟数据通过不等于真实统计业务验收

- 核查 feature 分层、路由权限、状态与计算、异步取消、图表和 WebGL 释放、导出快照、空筛选和缺失数据；未新增统计后端请求，未复制旧项目的鉴权和上传下载实现
- 详情沿用 Element 与 MxTitle；大屏的局部字体、色板和装饰保留用户已确认效果，不改全局主题

## 发现与修复

1. **部署缺少字体时三类图片导出失败**：字体不入库，原 `Promise.all` 在任一字体 404 后直接失败。新增用例先复现断言失败，再改为等待各字体完成或失败后使用后备字体；保留等待超时和卸载取消，不忽略其他导出异常
2. **重复实现下载生命周期**：驾驶舱保存 PNG 改为复用 `shared/file-transfer.saveFile`，沿用公共文件名处理及 URL 释放时机，不再单独用零延时回收下载 URL
3. **完整浏览器回归不稳定**：复现 `axios` 运行中预构建导致测试页重载，以及 MapLibre / Three.js 软件渲染等待超时。浏览器测试逐文件运行，并预构建已观察到的应用依赖；普通测试并行方式和生产逻辑不变，未放宽渲染断言或原有超时。首次 Linux CI 又暴露另外七个入口的延迟发现，补齐后改用全新 Vite 浏览器缓存复查，避免暖缓存掩盖问题

新增两项导出字体测试，覆盖缺字库与其他字体仍待加载、卸载立即取消及晚到结果。生产冒烟固定将字体返回 404，实际检查地图、卡片、详情三种 PNG 可下载且具备有效尺寸与内容字节；地图非空像素另由真实引擎测试验证。

## 设计理由与知识点

字体文件属于可失败的外部资源；字体就绪和图片导出生命周期分别管理，缺字库可沿用页面后备字体，而已取消的下载仍必须立即结束。下载交给公共能力，避免不同页面各自定义 URL 生命周期。

真实引擎测试不仅运行 JavaScript，还竞争软件光栅化资源。让浏览器文件逐一运行比延长所有超时更能控制负载；显式预构建已观察到的延迟依赖，避免把测试页重新加载误判为业务失败。保留单元测试并行，不扩大到全测试串行。
