# 3D.4：工具、查询、性能与资源释放验收

日期：2026-10-19。设计依据：[ADR 0068](../adr/0068-three-dimensional-tools-query-acceptance.md)，首期范围仍按 [ADR 0064](../adr/0064-three-dimensional-integration-scope.md)。

## 本步改动

- 现状底图接入已有 2D/3D 按钮，默认二维，保留缩放范围和滚轮速率。候选就绪才交接，加载失败保留原图，使用原地图提示区域重试；路由注入运行时，不破坏应用层懒加载边界
- 工具声明 `supportedViews`。不支持的视图采用浏览手势但保留原工具身份与状态；公共指针仍可用于读数。测量、位置拾取、点框选显式支持二三维
- 切换与暂停清指针预览、框选草稿，保留测量已确定点、已完成结果和已生成地理范围的查询。状态栏保留拾取表面及椭球基准高度，天空或不可投影时没有坐标；本步不新增高度显示
- 三维框边缘补采样；无区划的多边形也经过有效性、舍入与 120 坐标检查。有区划时先与 `readyBoundary` 求交，再检查简化后的投影误差。天空、跨经线、退化和超预算显示既有警告区域，不发请求
- 三维只查询已有五个登记数据集。后端总数与第一页 30 条沿用现行协议；不依赖空渲染查询估数，不增加猜测的面积或级别限制
- MVT 的 minzoom/bounds 外透明祖先共享 1×1 画布，真实瓦片和 provider 尺寸声明仍为 512。保留层序和透明语义，减少无内容纹理开销
- 实测 SDK 销毁后仍有 17 个地形缓冲有效；最终销毁在 SDK 之后关闭本视图独占 WebGL 上下文，暂停与缓存切换不关闭。已取消的 MVT 请求向 SDK 返回透明占位，保留底层取消和真实错误语义

## 验收方法

单元测试检查状态、请求和拒绝路径；浏览器测试只使用本地数据，运行真实 Cesium、MapLibre、Canvas、WebGL 和 Worker。浏览器文件串行执行，运行期间冻结相关源码，避免 HMR 污染结果。未启动本地开发服务。

查询的独立密采样复核与生产采样分开，保留旧四角算法作为误差对照。覆盖倾斜、旋转、地平线附近、部分天空和含洞区划；误差验证是有预算的数值采样，不声称适用于任意投影的解析证明。

资源验收区分项目 Worker 与 SDK Worker，区分缓存字节、WebGL 有效对象和实际时长。64 MiB 是 MVT 自有缓存预算，不是浏览器、CPU/GPU 总内存上限。软件 WebGL 的帧时间不代表实际显卡性能。

## 故障注入与问题记录

- 工具支持条件反转：模型和三维输入断言失败；丢掉读数的表面/高度：读数断言失败
- 关闭三维框边细分：非线性投影误差约 40 像素，超过 2 像素断言；跳过舍入后的投影复核：不可接受范围被接受；把视图监听改回异步：切换后仍有框选草稿，断言失败
- 候选失败当作当前引擎失败：状态类别断言失败；恢复后通过
- MVT 空祖先改回 512：尺寸断言失败；恢复共享 1 像素后通过
- 去掉最终上下文释放：`isContextLost()` 断言失败；主动取消改回向 SDK 拒绝：占位结果断言失败。真实非取消错误仍拒绝，晚到位图关闭后宽高为 0
- 强制二维按钮一直按下：三维交接完成后的按钮状态断言失败，恢复后相关 63 项回归通过
- 临时忽略 Cesium 的工具拖动限制：真实 Playwright 框选拖动使相机中心移动约 0.099°，相机应不变的断言失败；恢复后测量、定位与拖动三项均通过
- 首轮真实查询新增依赖触发 Vite 优化重载：将既有四个 turf 子包和 axios 补入预优化清单，随后查询与完整切换 4 项在无重载的运行中通过

## 性能与释放实测

环境为本机 Chromium / SwiftShader 软件 WebGL；数据全部本地，时间不含真实网络，不是生产服务承诺。

| 场景 | 观测结果 |
|---|---|
| 两个真实 MVT Worker，6 批 × 16 个绘制请求 | 第 17 个受背压限制；每批结束 inflight=0；所有产物消费后关闭 |
| 默认总 64 MiB 缓存预算 | 每线程最终 94,224 B、48 瓦片、24 来源；首批约 73 ms，后续约 5.5～7 ms |
| 总 8 KiB 压力预算，强制 LRU 淘汰 | 每线程最终 3,926 B、2 瓦片、1 来源；首批约 110 ms，后续约 6.5～8.4 ms |
| 合成两层场景，3 次重新创建，每次 3 轮相机变化与暂停恢复 | 首帧约 1.700 / 0.713 / 0.785 s；移动约 0.070～0.542 s；恢复约 0.233～0.290 s |
| 三轮场景的 GPU 对象 | 峰值 38 纹理、24 缓冲；显式 delete 合计 384 纹理、21 缓冲，其余在最终上下文关闭后失效；全部探针句柄 `isTexture/isBuffer=false` |
| Worker 生命周期 | 项目 Worker 全部 terminate；SDK Worker 首轮新建 3 个，后续不再增长，不强行关闭 SDK 私有 Worker |
| 连续相机变化与暂停的正常取消 | 560 次取消，修复后 SDK 错误日志 0；真实错误的拒绝测试仍通过 |

WebGL 扩展在当前 Chromium 可用。若浏览器不提供 `WEBGL_lose_context`，仍执行 SDK 销毁，但不能承诺残余 GPU 立即回收。对象失效不等于显式 delete 数量相等，也不等于测得进程或显卡总字节数。

无地形模式的 `globe.pick` 拾取 SDK 的地球三角网，实测高倍率中心的椭球高度可为约 −0.010728 m。状态栏数据沿用真实 `PickResult`，不强制写零；这是网格近似的残差，不能当成实测高程。本步未改动既有拾取算法，界面不增加高度栏。

27 层开发页沿用实际符号、高亮、遮罩和测量分组，画布约 1100×727；独立执行的切换记录如下。首次三维之前的模拟失败没有创建实例，因此重试计时对应首次实例创建；依赖已由测试工具准备，不能当作首次打开网页的网络加载时间。

| 阶段 | 本次实测 |
|---|---|
| 首次二维 | 224.8 ms |
| 首次三维就绪 | 16,514.7 ms |
| 返回缓存二维 | 62.5 ms |
| 恢复缓存三维并追赶样式 | 360.4 ms |
| 两轮普通往返：二维 | 54.0 / 53.7 ms |
| 两轮普通往返：三维 | 379.5 / 159.5 ms |
| 整个测试，含变色、重排、暂停、重建与断言 | 26.574 s |

首个三维画面在软件渲染下仍明显偏慢；这些数字说明缓存往返的收益，不把它描述为首屏性能已经达到产品目标。与上步约 23.6 s 的观测没有做同环境交替 A/B，不宣称确定的提速比例。

## 后续边界

真实后端网络、全省业务数据的统计成本、用户设备的硬件帧率和进程总内存需要部署环境测量；这里的合成多源负载和公开 GPU 对象检查不替代这些数据。没有增加地形、3D Tiles、模型、地下、漫游或地形/空间测量。切换仍不保存到账号偏好，默认二维。

旧项目 `master-demo` 本轮再次核对仍为 `6b4799b`，现状底图、CommonMap 和工具栏路径与基线无新差异；未新增旧项目的私有 SDK 调用或隐藏二维查询。
