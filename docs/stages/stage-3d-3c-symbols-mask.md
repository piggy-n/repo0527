# 3D.3c 符号、高亮与区划遮罩

日期：2026-10-19。沿用统一影像和 Worker 路线，设计见 [ADR 0067](../adr/0067-symbols-highlights-world-mask.md)。旧项目 `master-demo` 仍为 `6b4799b`，本步重新核对的三维目录和切换模块没有新增差异。

## 本步实现

| 能力 | 实现与边界 |
|---|---|
| 资源花纹 | 复用实际八种 SDF 图片及三档 zoom 表达式，支持普通 RGBA、像素比、颜色与透明度；图片变化只更新依赖层 |
| 边缘与线型 | 硬边覆盖按用户选择严格二值化；虚线长度按线宽换算；面内收半线宽保留洞和细线；其他非零偏移报告诊断 |
| 行政边界 | URL GeoJSON 共享下载、结构校验、取消与晚到隔离；省市县界继续使用本地文件，光晕保留 |
| 选择高亮 | 使用实际 `selectionGroup`；单个完整几何、批量 MVT `guid` 过滤、换目标、闪烁、年份替换继续由原拥有者推导 |
| 区划遮罩 | 世界补集覆盖两极和日界线；保留洞与岛，按墨卡托原始边线细分投影；不收缩成局部包围盒 |
| 分组层序 | 资源、选择、遮罩、注记、边界、区划高亮、测量保持既定顺序；开发页沿用已有显隐、变色、重排、暂停和切换按钮 |

## 画面对照和已知差异

| 对照对象 | 验证方式 | 结论边界 |
|---|---|---|
| 普通图片与跨瓦片花纹 | 真实画布逐像素比较相邻瓦片与整幅参考，包含非整数比例和局部面原点 | Canvas 插值允许最多 1 级 alpha 量化误差；不是允许错相位 |
| SDF 与八种实际资源花纹 | 规范阈值、颜色和像素比断言，加业务生成的八种图案及 zoom 换档实帧 | 梯度近似 shader 屏幕导数，不承诺二维逐像素一致 |
| 硬边填充与孔洞 | 覆盖边缘所有 alpha 的取值、洞内透明像素 | 关闭抗锯齿仅约束面覆盖，花纹纹理本身仍可半透明 |
| 面内收与光晕 | 细线宽度、面内外像素、虚线间隙、线外光晕 | 内侧裁剪加双倍描边与二维偏移路径的拐角、虚线长度有差异；模糊核也不同 |
| 世界补集与层序 | 两极、±180°、洞岛和半像素边界；Cesium 俯视与斜视下读取稳定帧 | 仅支持世界矩形补集与普通墨卡托范围内的洞岛；不扩展普通跨经线业务几何 |

用户选择严格硬边后，绘制增加局部覆盖掩模及像素扫描。每次瓦片绘制的花纹缓存同时限制 64 张/4 MiB；该预算不包含正在绘制的覆盖画布、位图和 Cesium 纹理。URL GeoJSON 仅在有租约期间保留数据；暂停或隐藏取消等待，恢复重新获得数据，HTTP 缓存仍可复用。

实际省市县边界和 15 级大面虚线暴露了视窗外路径开销：合成 70,000 顶点、200,000 像素跨度的对照中，构路径约 4 ms，无虚线描边约 0.38 s，有虚线约 4.2～4.7 s，不能把它误诊为下载或就绪等待。修复使用已有 `bbox-clip` 仅裁穿框的线段，保留整条路径累计长度，只展开视窗外扩范围里的虚线，再一次描边，避免重置相位及重复透明度。普通几何与闭合拐角作严格像素对照；Canvas 光晕边缘的 alpha 可能随路径分段产生差异，实测最大差 22，主线、孔洞与一次合成语义另外检查。这里的合成计时用于定位原因，不代表省域性能验收。

粗级别瓦片还有另一处开销：县界在相机 13 级、瓦片 0 级时，虚线周期约 0.00067 纹理像素，整份数据约展开 39 万个实段。浏览器探针确认下载和 `requestImage` 均已完成，却迟迟没有稳定帧。合成 8,420 顶点、263 像素总长的对照用 `getImageData()` 强制完成栅格化：当前算法的默认画布约 2,453 ms，设置 `willReadFrequently: true` 后约 15 ms，像素结果相同；换成原生虚线仍约 2,543 ms，不能解决根因。因此 GeoJSON 和 MVT 的线图层使用偏向软件渲染的离屏画布，保持精确虚线算法、样式级别及颜色，不跳过粗瓦片或改用平均透明度。这些计时仅说明当前 Chromium 环境的局部瓶颈，浏览器对该选项的实现仍可能不同。

开发页的 27 层全景在 SwiftShader 软件 WebGL 下首次三维准备约 23.6 秒，缓存三维恢复约 243 毫秒，完整按钮操作约 25.8 秒。公开场景探针确认瓦片队列持续收敛到零，各层均已就绪，没有暂停死锁。没有匹配几何的 GeoJSON 层现复用 1×1 恒透明画布，保留图层身份、顺序和瓦片尺度；不能用丢弃瓦片替代，因为 SDK 会回退到父影像。功能测试的就绪预算按这次实测从 15 秒调整为 45 秒，总用例预算为 60 秒，仍检查真实就绪与全部交互断言。此预算不是产品性能标准；全景首屏负载、空瓦片和多层纹理成本继续列入 3D.4，业务页三维入口仍未开放。

遮罩投影的最终复核发现：只检查边线的四分之一、中点和四分之三位置，可能漏掉真正的最大弦误差；一条跨赤道长边的回归样例测得 0.272923 像素，超过约定的 0.25 像素。现改为检查逆墨卡托导数等于弦斜率的全部内部驻点，再决定是否二分，坐标仍由 SDK 投影；横边、竖边和瓦片同侧不可见的边不细分，赤道附近的舍入误差单独处理，递归深度最多 24。回归先复现断言失败，再验证修复，未放宽精度要求。

## 测试与构建

验证包括普通测试、真实 Chromium Canvas/Worker/Cesium 和开发页测试。样例使用本地合成 MVT、实际业务样式推导和仓库里的行政区 GeoJSON，不访问后端或天地图，也不启动开发服务。

新增测试故意改坏后再恢复：SDF 阈值、花纹相位、硬边二值化、内收线宽、遮罩细分精度、最后租约取消、花纹档位、MVT 选择目标、图片依赖失效和 URL 就绪等待均由断言发现错误。线裁剪的相位与远端顶点、软件画布选项以及空纹理尺寸也做了断言改坏验证。动态图片新增时的迟到错误、外部重绘回调异常误记来源失败也先复现断言失败，再修复。

最终 `pnpm test` 全量通过：图标包 35 项、web 1893 项，合计 1928 项、210 个文件，包含真实 Chromium 的 Canvas、Worker、Cesium、MapLibre 与开发页回归。`pnpm typecheck`、`pnpm lint`、`pnpm build`、`pnpm build:intranet` 全部通过。另用独立 Vite 库构建验证生产路由未包含的开发页、二三维运行时和地图实现，MVT Worker 单独输出约 159.45 kB。既有的 sm-crypto-v2 浏览器兼容提示与大分块提示仍保留，产物检查通过。最终复核 UTF-8、BOM、换行及原有文件结尾均未改变。

## 学习点与下一步

本步把样式图片的所有权、表达式求值、图形覆盖和纹理合成分开：会话保存原始图片，绘制器负责像素，镜像根据图片身份判断失效。URL 来源的租约把“一个图层不再等待”与“所有图层都不需要下载”区分开。世界遮罩则把球面覆盖与业务几何边线分开处理，避免将二维世界环误画成局部面。

下一步 3D.4 验证工具、查询与状态栏，特别是三维屏幕范围到地表几何的误差、`queryRendered()` 为空时的查询限制；再验收省域样式性能、连续切换与资源释放。业务页三维切换尚未开放。
