## 已确认交互

- 保留左侧条件、中央地图、底部结果的布局。左栏 320px，统一使用 `MxPanel headerTone="muted"`、蓝色标题竖条、项目字体与色板
- 属性查询、空间查询、自然语言、高级查询共用一个切换栏；高级查询不再有独立按钮或另一套浮窗。切换方式清除上一方式的结果，模块与图层切换重置条件
- 属性查询保留增减条件、全部满足 / 任一满足和表达式查看；行政区划显式选择，不从 SQL 文本中反推
- 高级查询支持字段、运算符、枚举值插入，只编辑筛选条件，不编辑完整 SELECT 语句。真实接入时核对接口接受的表达式范围，后端仍须校验，不把前端约束当成安全边界
- 空间查询保留框选、多边形与 SHP 导入；绘制复用地图会话工具模型，与其他地图工具互斥
- 标题、模式切换与查询 / 重置按钮固定，长表单内部滚动。结果默认收起，查询后展开，支持收起 / 最大化，分页固定，每页 20 条
- 已执行查询拥有独立条件快照；修改表单提示重新查询，翻页和导出使用已执行条件，避免结果与条件错位
- 点击结果行显示右侧详情并定位；导出保留 Excel / SHP / GDB 的格式选择，使用公共下载能力
- 窄屏条件改为抽屉，查询成功后收起；结果表在自身区域横向滚动，不撑宽地图和整个页面

替代方案是继续沿用旧高级查询侧挂面板，或将其做成弹框；两者都会增加布局及操作区的重复，因此采用同级切换。

## 正式接入结构

1. `pages/data-query/DataQueryPage` 按路由 props 接收模块，`QueryWorkspace` 组合界面；业务在 `features/data-query`，不跨 feature 导入
2. 表单、已提交查询快照与服务端结果分开。分页、地图筛选和导出共用快照；结果由 TanStack Query 持有，切换、重置、离开页面或换会话取消旧读取
3. 框选、多边形通过 map-core 的 `PolygonDrawTool` 实现，和测量、移动等共用单一工具模型；SHP / ZIP 通过旧 FormData 契约上传，不在前端猜测文件内容
4. 地图复用现有底图、边界、定位及工具栏。GUID 几何读取和几何 schema 从资源地图提取到 `shared/map`；旧资源地图继续复用同一逻辑。结果选中时开始相机操作，等待期间用户拖图会作废自动定位
5. 导出复用 `shared/file-transfer` 的 POST 取流、文件名解析、进度、取消及重试。导出是读取结果的操作，离开页面和换会话取消；保留 JSON / FormData 请求体，不另造 Blob 下载链路
6. 旧六个图层配置按四组字段迁移，重复地类枚举共用常量；自然语言严格匹配支持的示例，未匹配时明确提示，不宽泛猜测用户意图

## 待联调与范围限制

- 森林草原湿地荒漠、水资源：查询图层、字段和接口配置待提供，目前只有可操作地图壳
- 自然语言：只支持旧版已有示例；通用解析和真实统计图表待后续接口，不展示演示统计作为业务结果
- SHP / ZIP：请求与取消按旧契约实现，实际可接受的压缩目录、坐标系、配套文件及错误响应需用业务样本核对
- 导出：固定接口验证格式、文件名、请求快照和原始 SHP 文件传递；真实 Excel / SHP / GDB 内容与大文件耗时待核对
- 医疗机构旧配置两处字段都叫 `IFTC`（“是否为县区级医院”“是否传染病医院”），本轮保留第一项，第二项字段身份待核实，避免同名条件互相覆盖
- 地类名称旧枚举的部分编码 / 名称对应存在疑点，例如 `0601` 与“工业用地”“采矿用地”，暂保留旧契约，不自行改写后端取值
