## 背景

- 状态栏在左下角（ADR 0095）：比例尺（三维是视点高度）、鼠标所在的经纬度（不在画布上时前面写"中心"、显示画布中心）、不为 0 的旋转和俯仰。请求状态的条目紧跟在右边（ADR 0158）："正在加载 3 项 · 62%"、"2 项加载失败"、"已加载完成"。
- 条目排在宽度会变的读数后面：缩放时比例尺变长变短，鼠标进出画布时"中心"出现、消失，条目跟着左右移。2026-11-22 用户要求条目不动，改成按最宽的读数留位、"中心"一直占位、条目最小宽 160。
- 2026-11-23 用户：留位造成大段空白（二维 1 km 时实测 83～100 像素）；要求取消不必要的固定长度、不因状态变化抖动，加载时只有 Loading 图标和百分比，其他状态优先用图标、细节放 Tooltip，减少冗余文字。

## 候选方案

原型 `local/design/status-bar/`（`DESIGN.md` 是梳理和说明，`compare.html` 是截图对照），实测移动次数和预留的空白：

| 方案 | 排法 | 移动 | 预留的空白 | 代价 |
|---|---|---|---|---|
| 现在 | 读数留位，条目在后 | 0 | 83～100 像素 | 大段空白 |
| 甲 状态在前 | 定宽的按钮，后面是经纬度、比例尺 | 0 | 只在按钮里，空闲时约 35 像素（图标居中） | 按钮一直在 |
| 甲′ 同甲，空闲时隐藏按钮 | | 每轮加载出现、结束时读数整体移两次，约 64 像素 | 0 | 抖动 |
| 乙 状态在后 | 比例尺留到 80 像素，状态紧跟 | 0 | 约 53 像素 | 留位还在 |
| 丙 状态靠右 | 状态在这一行的右端、底图卡左边 | 按钮左边缘每轮 1～2 次 | 0 | 离读数远；明细要改成贴着按钮 |

## 决定

### 1. 排法：宽度会变的放后面，状态放在前面、大小固定

- 顺序是：请求状态的按钮、经纬度、比例尺（三维是视点高度）、旋转和俯仰。宽度会变的读数排在后面，后面没有东西被它推动，不留位。
- 经纬度前面一直有一个图标：鼠标在画布上是指针（`readout-pointer`），不在时是画布中心（`readout-center`），含义写在悬停提示和读屏名称里，不再写"中心"两个字；江苏范围内经纬度的位数不变，等宽数字、不做字距调整（`font-kerning: none`，普惠体的数字和"°′″."之间有字距调整），进出画布、移动鼠标时宽度不变，后面的比例尺不动。
- `MapStatusBar` 去掉 `reserve`，插槽 `after` 换成 `before`（排在状态栏左边、间距 8，取舍前先让出它的宽度）；三把量尺按最宽的读数量（80 像素的"200 km"、"8888 km"、有的角度换成 -180°、85°），缩放、转动时排法不来回切换。放不下时仍先去掉旋转和俯仰，再去掉经纬度。

### 2. 请求状态的按钮

- 一直在（三类都关掉时除外，ADR 0167）。宽度按看不见的"转圈 99%"固定、内容居中：状态变了宽度不变，后面的读数不动。
- 加载中：主色的转圈加百分比，百分比向下取整、最多 99（瓦片都到了、模型还在读索引时也没完成）；只有读模型索引、高斯泼溅时只有转圈；上一轮有失败时转圈右上角一个红点。不再写"正在加载 N 项"，去掉底边的进度线。
- 有失败：橙色的警告图标加项数。完成：绿色的勾，留 1.5 秒。空闲：灰色的勾。
- 全称在读屏名称和 Tooltip 里（纯函数 `requestStatusText`、`requestStatusTip`）：如"正在加载 3 项，已完成 62%；1 项有失败。点击查看明细"；空闲时是"查看数据加载的明细"。明细开着时不提示。
- 出现、合并、留多久的规则（0.8 秒、0.4 秒、1.5 秒、合并显示、失败留到下一轮结束）不变；`requestSummary` 原来"不显示"的情况现在是空闲（`idle`），只有三类都关掉时是 `hidden`；明细开着时不再至少显示"已加载完成"（按钮本来就在）。
- 明细的内容、位置（贴着资源图层面板，用户 2026-11-16）不变；按钮一直在，空闲时也能点开看已完成的项。

### 3. 其他读数

- 三维的视点高度写成图标加高度（"420 km"），视点在地表以下换成向下的图标、写深度，全称"视点高度 420 km""视点在地表以下 18 m"在提示里。
- 旋转、俯仰留在状态栏最后（用户 2026-11-23），写成图标加角度，悬停说明"旋转 35°""俯仰 45°"。
- 读数前的图标接鼠标（悬停提示），状态栏别处仍不挡地图。
- 删掉步行时的人称、眼高、朝向（`useMapReadout` 的 `walking`）：漫游时整条状态栏隐藏（ADR 0095），只有现状底图用状态栏，这几段看不到。

## 后果

- 二维 1 km 时状态栏里预留的空白从 83～100 像素降到按钮里的约 35 像素；缩放、鼠标进出画布、加载开始和结束时，按钮、经纬度、比例尺都不动（浏览器测试 `RequestStatusChip.browser.test.tsx`）。
- 比例尺从第一段挪到经纬度后面；手机宽度（这一行约 250）放不下经纬度，只留按钮和比例尺。
- 新图标 `readout-pointer`、`readout-center`、`readout-eye-height`、`readout-eye-below`、`readout-bearing`、`readout-pitch`，Tabler 风格自绘（`docs/modules/icons.md`）。
- 没留的：经纬度跑到东经 100° 以西、北纬 10° 以南时少一位；切换二三维时比例尺换成视点高度，最后一段的宽度会变（后面只有角度）。
