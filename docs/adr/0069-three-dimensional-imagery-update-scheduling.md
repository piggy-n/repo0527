# ADR 0069：三维影像更新时机与几何复用

- 状态：接受（现有三维能力的性能修复）
- 日期：2026-10-19
- 补充：ADR 0065～0068

## 背景

用户反馈首次三维加载慢、拖动和缩放反复重绘、工具栏缩放偶发“对象已销毁”。原镜像在共享相机的浮点 zoom 变化时立即替换所有矢量影像，包括隐藏层。三维平移也可能改变中心纬度和地表距离，从而改变共享尺度；动画逐帧写回会造成连续取消、重画和纹理上传。

原有程序定位测试使用空样式，不能检查带影像的动画销毁时机。新增真实引擎测试证实：四次缩放中有 32 次影像销毁发生在 SDK 渲染调用尚未退出时。这个测试证明了不安全的时序，不等于已稳定复现用户截图中的同一异常。

GeoJSON 每个图层、每次缩放都重新投影来源；每张瓦片再扫描全部图形。省界有 20,829 个坐标，三个描边层会重复处理相同数据。旧项目通过整数级别、瓦片级别和 Entity 降低更新频率，但这些做法不满足当前精确相机级别求值与统一影像层序的约定。

## 决定

### 镜像更新与相机运动

保留统一影像绘制和共享会话，不更换引擎或改用瓦片级别求样式。Surface 按已有姿态比较精度判断运动与静止，只控制绘制，不用于判断相机操作的 cause 或最新意图。不能只依赖 SDK 的 moveEnd：全量回归发现斜视相机有微小浮点抖动，SDK 仍判断为移动，项目姿态比较已连续相等，导致永远不交付稳定帧。

运动检查放在公开的 postUpdate 中，按需渲染没有新画面时仍能检查。固定锚姿态只在显著变化后更新，避免逐帧比较漏掉累计慢移；连续 500 毫秒没有显著变化后结束运动并请求最终帧。窗口由项目持有，与本轮 SDK 的默认等待长度相同，不读取其私有配置。暂停清窗口，恢复重新建立稳定帧观察窗口，但镜像先追赶最新尺度；只有后续检测到实际运动才推迟影像重画，不能把恢复本身当成运动。

- 已显示的图层在运动期间复用旧影像，结束后按最终精确 zoom 更新一次。运动期间线宽、点半径和花纹可能随旧影像暂时缩放，静止后的尺寸与求值规则不变
- minzoom/maxzoom 显隐仍随当前级别更新，新显示的图层先追到当前尺度。用户变色、数据替换、高亮等样式提交仍及时生效，不等整个手势结束
- 隐藏层不随缩放重建；显示时只追赶一次最新状态。暂停保留缓存，恢复追赶最新会话
- 镜像的后续更新由 Surface 排到当前 SDK 调用结束后的微任务，并合并同一轮通知。构造首轮仍同步准备，确保 inactive 候选不会以空样式报告就绪
- 排队刷新有身份检查，暂停或释放后旧回调失效。首帧和稳定帧必须等待 pending 刷新完成，不能越过尚未应用的样式

### GeoJSON 几何与瓦片

每个影像端口持有独立的 GeoJsonGeometryCache，按不可变 GeoJSON 对象身份弱缓存投影和图形包围盒。同源的多层描边、后续缩放可复用几何；替换数据对象自然失效，视图释放时清空缓存。

瓦片先按包围盒粗筛，并外扩点半径、描边、线宽、尖角和模糊范围，保留抗锯齿余量。只有完全不相交的图形才跳过，不简化坐标、不切断多边形孔洞。空瓦片复用透明像素，不使用会回退到父影像的瓦片丢弃策略。

纯色 background 和整层没有可绘制图形的提供者，其空间内容恒定：最大层级固定为 0，并复用单张 1×1 画布。背景的颜色、透明度随 zoom 改变时仍按正常镜像流程替换提供者；非空图层中某张瓦片恰好为空，不会降低整个提供者的最大层级。

这一步不引入 GeoJSON Worker 或空间索引。大环包围盒覆盖瓦片时仍需遍历该环；几何缓存也不代表进程总内存预算。取消后的 URL 空占位不再访问已经释放的视图缓存。

## 备选方案

- 只减少动画时长或提高等待超时：不能消除重复构建和 SDK 栈内销毁
- 将 zoom 四舍五入，或按瓦片级别求样式：会改变现有符号、花纹及显隐的求值语义
- 改回 Entity：不能保持任意栅格与点线面的完整叠放顺序
- 立刻引入更多 Worker 或合并全部影像层：增加所有权、缓存和层序复杂度，先用测量确认剩余瓶颈再决定

## 验证与学习点

验证分成确定性的工作量断言、真实浏览器交互和独立的加载计时。测试覆盖运动中的更新合并、业务变色、显隐切换、暂停恢复、释放后迟到请求、几何投影次数及瓦片边缘像素。工具栏使用真实按钮与完整本地样式，自动化不请求后端或天地图。

性能对照固定提交、场景和浏览器，记录实际耗时，不把软件 WebGL 数字当作用户显卡帧率。旧项目只作为行为和算法参考，不以不同场景的计时宣称已经追平。结果与尚未验证的部分见[性能修复记录](../stages/stage-3d-performance-repair.md)。

知识点是把状态同步频率与昂贵资源更新频率分开：共享相机可以逐帧精确更新，影像可以在安全时机收敛到最新状态。弱缓存解决数据身份复用，视图所有权解决最终释放，两者不能互相替代。
