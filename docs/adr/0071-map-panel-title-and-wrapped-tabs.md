# 0071. 地图工具的标准标题与两列标签

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0053、0066、0070 中功能面板的标题、标签排布和收起展示

## 背景

320 宽的面板将多个标签、单项关闭、收起和全部关闭放在同一行，三个以上功能不能同时看全。选中标签的蓝色文字、额外的按钮底座和 Tooltip 也偏离了现有面板的简洁外观。用户确认采用标准标题行与独立标签区。

## 决定

1. 标题固定为「地图工具」，复用 `MxTitle` 的面板级标题：16 / 600、`--color-text-strong`、4 × 16 主色竖条。标题行保持 48 高，与资源详情一致
2. 标签独占标题下方的宽度，每行两项：一至两项一行，三至四项两行；名称与单项关闭按钮全部展示，取消横向滚动与省略。极窄时名称允许换行，字号不缩小
3. 标签名称统一深色、16 / 600。选中只增加浅灰底和底部短线，不改变文字颜色、字号或字重。标签区固定在内容滚动区外
4. 标题右侧使用「收起 / 展开」「关闭全部」文字按钮，移除圆形底座、分隔线和重复 Tooltip。各标签保留小叉和明确的无障碍名称，只关闭对应功能；整组关闭不影响独立详情与底图
5. 收起时隐藏标签与内容，只保留 48 高标题行；已打开功能、当前标签与输入保留，内容收到 `active: false`。展开入口或右侧工具栏可恢复，继续使用现有面板高度分配

## 取舍

增加标签区的纵向空间，换取四项功能直接可见；保持面板宽度和既有业务状态。现状底图只有四项功能，无需增加标签溢出菜单。

## 验证

将原来的横向滚动浏览器用例改为四标签换行、完整可见、标题样式一致、内容滚动不隐藏标签，以及收起后保留状态的用例。按用户要求仅运行生产构建，测试用例与实际页面效果仍需后续验收。
