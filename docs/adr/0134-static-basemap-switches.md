# 0134. 静态底图的默认外观：地名、分色改为代码开关，陆地色换算成不透明 HEX

- 状态：已接受
- 日期：2026-11-03
- 修改 ADR 0133 第 2、3 节的默认外观；绘制方式、底图目录、默认选中静态底图不变

## 背景

ADR 0133 的静态底图默认各市分色、带市县地名。用户看过后要求：地名可以在代码层面开关、默认关闭；配色可以在代码层面开关，默认全省同一种颜色（CREAM）；这两个开关不进 `.env`。

四种颜色要淡一些：把原色按 75% 透明度和背景色混合，换算成不透明的 HEX 色值，代码里不用透明度变量（用户 2026-11-03 明确）。用户没有指定背景色，取地图上实际垫在陆地下面的省外底色 `#E6EAF0`。

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 开关放在哪 | 环境变量；`static-basemap.ts` 里的常量；单独的小文件 | 单独的小文件 `shared/config/static-basemap-options.ts`：用户明确不进 `.env`；`static-basemap.ts` 有 `?url` 导入，Node 直接运行的生成工具读不了它，缩略图也要跟着分色开关 |
| 颜色怎么变淡 | `fill-opacity` 乘 0.75；颜色值带透明度；换算成不透明 HEX | 不透明 HEX（用户要求）：颜色在任何背景上都一样，滑块的 100% 就是完全不透明，没有多一层透明度要理解 |
| 换算放在哪 | 运行时用函数计算；生成工具计算；直接写结果 | 直接写结果：换算只做一次，配色表一眼能看到实际颜色，换算关系由测试核对 |
| 关闭分色时的颜色表达式 | 13 个市都写同一个颜色的 `match`；一个常量 | 常量：没有多余的分支，代码不存在的市也不会落到兜底的底色 |

## 决定

### 1. 开关

```ts
// shared/config/static-basemap-options.ts
export const STATIC_BASEMAP_OPTIONS: StaticBasemapOptions = { labels: false, cityColors: false };
```

| 开关 | 关闭（默认） | 打开 |
|---|---|---|
| `labels` | `basemap-labels` 分组是空的，不请求地名数据 | 市、区县地名，和 ADR 0133 第 3 节一样 |
| `cityColors` | 全省用 `STATIC_LAND_COLOR`（CREAM，`#F3F1E9`） | 各市按 `STATIC_CITY_COLORS` 取色，相邻的市不同色 |

- 只在这个文件里改。改 `cityColors` 后运行 `basemap:generate` 更新缩略图，缩略图和当前配置不一致时测试失败
- `staticBasemapGroup`、`staticLabelsGroup` 的第二个参数默认取这个常量，测试传入固定的值，所以改默认值只影响"默认关闭"那一条用例
- 页面仍然传 `root: BASEMAP_STYLE_ROOT`，`localIdeographFontFamily` 和地名数据也保留：打开开关时不用改页面。这些在地名关闭时不起作用

### 2. 陆地的颜色

每个通道按 `round(原色 × 0.75 + 背景色 × 0.25)` 换算，背景色是 `#E6EAF0`：

| 名称 | 原色 | 换算后 |
|---|---|---|
| CREAM | `#F7F3E6` | `#F3F1E9` |
| MOSS | `#F0F3E4` | `#EEF1E7` |
| SAND | `#F6EEE3` | `#F2EDE6` |
| MINT | `#ECF2E9` | `#EBF0EB` |

- `static-palette.ts` 直接写换算后的色值，原色写在注释里；换算关系由 `static-basemap.test.ts` 核对
- 代码和缩略图里都没有陆地的透明度。`fill-opacity` 只有底图的透明度滑块：滑块 100% 时完全不透明

## 后果

- 好处：开关集中在一个文件，不增加部署配置；打开任一开关不用改页面和样式代码
- 好处：默认只有一种颜色，业务图层更突出，也少了地名和业务内容的重叠
- 代价：切换要改代码并重新构建，部署时不能单独开关
- 代价：陆地和省外的颜色差变小（`#F3F1E9` 和 `#E6EAF0`），主要靠省界区分；市之间仍有白色细线，没有要求去掉
- 代价：换背景色要重新换算四个色值、同步测试和冒烟用例里的值，并运行 `basemap:generate`
