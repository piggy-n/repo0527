# 0077. 城市体检驾驶舱独立渲染与资源所有权

- 状态：已接受（用户确认交互预览并要求继续 D2）
- 日期：2026-10-21

## 背景

驾驶舱纳入阶段六，必须保留旧版 Three.js 立体行政区地图及 ECharts 图表。它不属于暂缓的现状底图 Cesium 模块；指标目前均为固定模拟数据。用户已提供三张 WebP，并确认大屏整体方向与局部适配。

## 候选方案

1. 逐行移植旧巨型组件：迁入快，但数据、图表、导出与资源释放继续互相依赖
2. 先建设通用图表平台或改用现状底图引擎：扩大范围，并改变既有视觉和交互
3. 在驾驶舱 feature 内拆分纯计算、状态、场景与组件，复用必要的公共资源

## 决定

采用方案 3。顶级 `/city-dashboard` 独立懒加载，不使用 AppLayout、不缓存页面；要求登录，所有登录角色可访问，无菜单入口。数据入口与展示分离，不声明不存在的统计接口。

ECharts 5.6.0 按 core 注册柱、线、二维地图、图例、标签避让和 Canvas；Three.js 精确锁定 0.183.2、GSAP 3.13.0，对齐旧实现。D3 只安装 d3-geo 3.1.1、d3-polygon 3.0.1；简化复用已有 @turf/simplify 7.4.0。本轮只读检查并行资源管理工作树，未发现同类图形依赖；公共依赖清单和锁文件在合入时统一核对并单独提交。

复用 shared/map/region 的本地市界，投影及展示简化操作副本，保留同市多面与孔洞。场景类接收快照和窄回调，使用 DisposableStack 管理监听、观察器、纹理、材质、几何和渲染器；加载使用 LatestController，过期结果不挂载。WebGL 创建失败或运行中上下文丢失均回退 ECharts 二维地图。

导出按点击时的图表选项或地图像素、标签、指标冻结，等待字体与编码后复核生命周期。地图截图同步更新相机和标签；重复导出禁用对应按钮，离开后不启动旧下载。输出沿用 PNG；背景资产统一使用用户提供的 WebP，两者用途不同。

大屏样式仅在驾驶舱局部，普通控件与详情复用 Element、MxTitle、SvgIcon。字体沿用普惠体 3.x 与同授权官方完整思源宋体 CN Heavy，统一置于忽略目录 public/fonts，不复制旧缺字子集。

用户确认 D2 后，D3 使用页面局部阶段编排，有限动画按可见时长驱动，不改变 GSAP 全局 ticker；减少动画直接收敛终态。扫光间隔用一次性等待，相机/标签按输入变化重算。触控板合并惯性逐卡翻页，触屏保留原生滑动并在停止后校正停靠；异步定位仍使用 LatestController，不与普通尺寸更新争抢取消通道。

## 后果

驾驶舱分块包含必要的图形库，只在进入该路由时加载；生产冒烟检查登录和现状底图未请求该分块。D2 已由用户确认，D3 完成统一入场、惯性翻卡、首次字体与有界生命周期测量，等待用户验收。软件渲染、30 轮计数和 dispose 检查不等同于真实 GPU 显存或长期无泄漏证明，测量条件及未验证项见模块文档。

新增 ADR 编号只在本工作树使用；与并行分支合并时复核编号及依赖版本。迁移基线、素材记录和实际验证见 [模块文档](../modules/city-dashboard.md)。
