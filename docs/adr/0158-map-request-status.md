# 0158. 地图数据的请求状态：适配器按数据源统计瓦片，状态栏右边的条目和明细

- 状态：已接受（2026-11-14 用户确认原型，空闲时隐藏；同一天实现）
- 日期：2026-11-14
- 补充：ADR 0024（视图接口多一项可选的 `sourceActivity`）、ADR 0041（数据源错误之外再统计瓦片请求）、ADR 0053 第 5 节（状态栏右边加一个条目）、ADR 0059（当前图层的行内状态加转圈）、ADR 0157

## 背景

- 地类图斑一类资源单张瓦片约 6 MB（ADR 0132），慢的时候用户看不出是哪个图层在等、等了多久，也看不出是不是卡住了。
- 现有的只有瓦片失败：视图记下每个数据源的第一条错误（ADR 0041），拥有者推导出状态图标（ADR 0059）。
- 引擎能告诉页面什么（MapLibre 6.12 的源码，2026-11-14 核实）：
  - 数据源开始请求一张新瓦片时发 `dataloading`（带 `tile`）；已有瓦片的重新加载不发。
  - 瓦片到了发 `data`（地图转发成 `sourcedata`，带 `tile`），取消发 `dataabort`，失败发带 `tile` 的 `error`。
  - 后端返回 404 时不发任何事件，没有变化的瓦片（304）也不发。
  - 数据源的每个事件都带 `isSourceLoaded`：这时这个数据源是否已经没有在请求。
  - 主线程拿不到每张瓦片的字节数：瓦片在 Worker 里请求。
- 三维模型只有 `sceneStatus` 的加载中、就绪、失败；"细节还剩几块"要改三维的契约（ADR 0157 第 6 节，往后放）。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 统计放在哪 | 页面直接听原生事件；适配器统计，视图接口给出 | **适配器。** 只有适配器能碰引擎（ADR 0024）；数据源移除、样式整体重建时要一起清掉，这些只有适配器知道 |
| 404 的空瓦片怎样结束 | 等超时；看数据源事件的 `isSourceLoaded`，地图空闲（`idle`）时全部结束 | **`isSourceLoaded` 加 `idle`。** 这两个是引擎说"没有在请求了"的地方；超时要猜一个时长 |
| 多久更新一次 | 每张瓦片更新；上下文一帧最多更新一次 | **一帧一次。** 视野里一次请求几十上百张瓦片 |
| 什么时候显示 | 有请求就显示；加载超过 0.4 秒才显示，空闲时隐藏 | **超过 0.4 秒、空闲时隐藏**（用户确认）。快的请求不打扰，大部分时间不和经纬度抢位置 |
| 统计哪些请求 | 地图数据和接口请求都算；只算地图数据 | **只算地图数据**：资源图层的瓦片、三维模型、底图。查询、目录这类接口各自有加载状态 |

## 决定

### 1. 适配器的统计

- map-core 的 `SourceActivityTracker` 按数据源统计"这一轮"的瓦片：空闲以后请求第一张瓦片时开始新的一轮，记请求、到了、失败的张数和开始、结束的时间。
  - 取消的瓦片不算请求；全部取消时这一轮不留下。
  - 不是这一轮在等的瓦片（重新加载）的结果不算。
  - 结束后保留这一轮的结果，下一轮开始时清掉，所以失败显示到下一次请求为止。
- MapLibre 适配器把 `dataloading`、`sourcedata`、`dataabort` 和带 `tile` 的 `error` 交给它。数据源的事件带着 `isSourceLoaded` 为 true 时，还在等的瓦片算到了（404 的空瓦片）；地图空闲时全部这样结束。数据源移除、样式整体重建时忘掉。
- 视图接口多一项可选的 `sourceActivity`（每个数据源这一轮的请求）和 `onSourceActivityChange`。map-vue 的上下文给出只读的 `sourceActivity`，一帧最多更新一次。

### 2. 状态栏右边的条目

- 放在状态栏右边（`MapStatusBar` 的 `after` 插槽，它的宽度先让出来再取舍状态栏的几段）。
- 加载超过 0.4 秒才出现：转圈、"正在加载 N 项 · 百分比"，底边一条 2 像素的进度；同时有失败的加一个红点。
- 没有在显示的加载、有失败时：橙色三角加"N 项加载失败"。
- 显示过的加载结束后，"已加载完成"留 1.5 秒再消失；快的加载结束时不显示。
- 时钟只在有加载、刚结束时每 250 毫秒走一格，只在条目组件里读，不带动页面重渲染。

### 3. 点开的明细

- 浮层"数据加载"开在条目上方，分加载中、有失败、已完成三组。
- 瓦片写"34/52 张"和进度条，等了 5 秒以上写"已等待 N 秒"；失败写"N 张失败"。模型写"读取模型…"、"加载失败"加重试、"已完成"。
- 点一行在当前图层里选中它（底图除外）；点外面、按 Esc、再点条目都关闭。
- 不显示字节数（拿不到），不提供"取消"（隐藏图层就是取消）。

### 4. 来源和行内的转圈

- 页面给出三类来源：当前地图里画着的资源图层（每个资源一个数据源）、三维里加入并显示着的模型、底图（`basemap` 开头的数据源合成一项）。
- 当前图层里二维图层的行，加载超过 0.4 秒时在名称后面转圈，和条目用同一份数据（`useRequestStatus` 的 `loadingKeys`），两处说法一致。

## 后果

- 慢的时候能看到是哪个图层在等、等了多久；大部分时间什么都不显示。
- 统计只看引擎的公开事件。MapLibre 改了这些事件的语义（比如 404 也发事件）时，由适配器的单元测试和页面上的检查发现。
