# 0067. 三维符号、选择高亮与全球区划遮罩

- 状态：已接受（沿用 3D.0 的影像路线；用户确认严格硬边覆盖）
- 日期：2026-10-19
- 补充 ADR 0045、0051、0065、0066

## 背景

3D.3b 已把 MVT 点线面接入 Worker 和统一影像集合。实际资源样式还使用 SDF 花纹、虚线、面内收描边；行政边界使用本地 URL GeoJSON 和光晕。选择高亮引用已有来源与业务身份，区划裁剪则是世界矩形的补集，不能直接投影成普通球面多边形。

## 决定

1. 直接使用会话的 `StyleImages`，保留原始 RGBA、`sdf` 和 `pixelRatio`。图片名由 style-spec 求值，渲染器不根据名称重画八种业务图案。Worker 受限入口增加的只有图片数据类型导出，不引入 DOM 或主线程模块；传给 Worker 的图片使用结构化克隆，不转移会话拥有的像素缓冲。
2. 花纹相位锚定世界像素，局部覆盖画布和相邻瓦片使用相同原点。每次瓦片绘制独占着色纹理缓存，同时限制 64 张与 4 MiB，绘制结束即不再驻留；数据缓存仍按 ADR 0066 管理。图片变化只重建实际引用它的图层，动态图片名保守依赖全部图片。
3. `fill-antialias: false` 严格实现：先生成局部面的覆盖掩模，将覆盖 alpha 二值化，再合成填充。保留抗锯齿的替代方案更省一次绘制，但不符合业务样式的明确语义；用户选择严格覆盖。纹理自身仍可含透明像素，颜色透明度在覆盖之后应用。
4. 虚线按线宽单位换算；`line-offset` 支持 0 和面内收半线宽，后者用面内裁剪加双倍描边。其他偏移明确诊断。线段先裁到带外扩余量的视窗，原路径累计长度决定虚线相位；只展开附近的虚线片段，再一次描边，避免半透明与光晕重复叠加。跨框裁剪复用已有 `@turf/bbox-clip`。`line-blur` 用 Canvas 光晕保留现有边界效果；SDF 用 0.75 阈值及邻域梯度近似屏幕导数。拐角、虚线长度、模糊核及 SDF 边缘不承诺与二维逐像素相同，不能据此修改二维样式。
5. 根据外环几何识别闭合的世界矩形，不依赖 `region-clip` 名称。世界外部直接铺满 Geographic 瓦片，覆盖到 ±90°；洞与岛按原有多面结构保留。普通边沿 Web Mercator 直线，转地理瓦片时自适应细分，误差不超过 0.25 纹理像素，再生成硬边覆盖。拒绝把世界外环收缩成局部包围盒；普通业务跨日界线和极区路径仍未支持。
6. URL GeoJSON 按不可变来源对象共享下载与解析。每个影像拥有可取消租约，最后使用者释放时取消请求并丢弃数据；缩放替换先获得新租约，复用已有数据。下载和解析后检查取消，异步影像就绪前不交付整图就绪或稳定帧。加载失败进入来源错误，其他图层仍可完成加载。
7. 高亮、区划与测量继续使用原来的样式分组和层序，不另存选择、年份或裁剪范围。单个高亮使用完整 GeoJSON，批量高亮跨分组引用当年的 MVT 来源并按 `guid` 过滤。新增文字、图标碰撞布局与业务工具查询不在本步范围。

## 验证与后续

用真实 Canvas 检查 SDF/RGBA、花纹相位、硬边、孔洞、细线、虚线、光晕；用真实 Worker 检查图片往返与缓存复用；用真实 Cesium 和业务样式推导函数检查高亮、年份、遮罩层序与本地行政边界。测试只使用本地数据，不请求后端或天地图。

画面对照、故障注入与构建结果记录在 [3D.3c 阶段记录](../stages/stage-3d-3c-symbols-mask.md)。省域吞吐、快速缩放和平移、长期资源释放、工具与查询仍在 3D.4 验收后决定业务页开放。
