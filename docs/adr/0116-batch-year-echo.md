# 0116. 现状底图的批量设置年份：回显最后一次设置的年份，没有数据的年份不再提示

- 状态：已接受
- 日期：2026-10-29
- 修改：ADR 0052 第 2 节（批量设置选完不保留选中值、不存年份）、ADR 0094 第 3 节（选了没有数据的年份时提示）

## 背景

ADR 0052 把批量设置年份定为"一次操作"：选完就执行，选择框回到占位，不存"当前年份"，理由是存下的统一年份会和各资源自己的年份对不上。用户此前反馈过"批量设置成功，但输入框未回显"，当时按 ADR 0052 保留了原行为（`docs/design/current-map-reference.md`"批量年份"一节），并留了一句：以后可以讨论"明确标注最近批量设置"。

2026-10-29 用户明确要求：

1. 批量设置年份后，选择框回显这一年，显示值和实际的设置一致
2. 去掉 2020、2021 年的提示（ADR 0094 加上这两个固定选项时，选了没有数据的年份提示"没有资源有 2020 年的数据，图层保持不变"）
3. 在 ADR 里说明年份的设置和回显逻辑，并记下以后可能改成后端的查询条件，这次的实现不要妨碍以后的改造

批量设置只改有这一年的资源，之后还能单独改某一个资源，所以"回显"可以有几种含义。开工前问了用户：单独改了某个有这一年的资源之后，选择框怎么显示。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 回显什么 | 从各资源的年份推导（有这一年的资源都是这一年时才显示）；记下最后一次批量设置的年份，一直显示它 | 记下最后一次（用户选）：选择框表示"最近一次批量设置成了哪一年"，单独改某个资源不影响它；推导的做法在选了没有数据的年份时什么都显示不出来，且有几种年份同时满足时说不清 |
| 记在哪里 | 面板自己的界面状态；资源图层的拥有者 | 拥有者：它是这组图层设置的一部分，要随偏好存下；以后改成查询条件时也由拥有者交给请求 |
| 要不要存 | 只在本次打开期间记住；随资源图层的偏好存下 | 存下：各资源的年份本来就随偏好存下，刷新后选择框也应显示当时批量设置的年份 |
| 再选同一年 | 不处理（Element 的选择值没变时不发 `update:modelValue`）；点选项也执行 | 点选项也执行：单独改过某个资源后，再选回显着的那一年要能把它切回来（ADR 0052 验收的"重复操作"） |

## 决定

### 1. 设置与回显

- 拥有者 `useResourceLayers` 新增：
  - `batchYears`：批量设置可选的年份（`batchYearOptions`，多年份资源的年份并集加上固定的 2020、2021，新的在前），面板不再自己算
  - `batchYear`：最后一次批量设置的年份；没有批量设置过、或已不在可选年份里（目录变了）时为 `null`
- `setYearForAll(year)` 照旧：有这一年的资源不论是否勾选都切过去，其他不变，只替换一次显示状态；没有任何资源有这一年时图层不变；同时记下这一年。年份不是整数时抛错，什么也不记
- `batchYear` 只给面板回显，不参与样式推导、点选和图例，各资源的年份仍是唯一决定地图的状态；单独用 `setYear` 改某个资源时它不变
- 面板的"批量设置年份"选择框 `modelValue` 绑定 `batchYear`（`null` 时显示占位）。再点回显着的那一年也执行：Element Plus 2.14 的单选在值没变时不发 `update:modelValue`，所以由选项的内容（铺满整行的 `span`）响应点击，只在点的是回显着的那一年时调用 `setYearForAll`；键盘选回同一年仍不会再执行
- 选了 2020、2021 这类还没有数据的年份：图层不变，选择框照样回显，不再提示；`hasYearData` 随提示一起删去

### 2. 存储

- 存在同一项偏好 `resource-layers` 里，存储格式多一个可选的 `batchYear`（整数或 `null`），版本不变：2026-10-29 之前存下的没有这一项，按没有批量设置过还原；不是整数时整份偏好不通过校验（ADR 0042 第 3 节）
- 还原后同样经过 `batchYear` 的检查，不在当前目录的可选年份里时不回显

### 3. 以后改成后端查询条件

用户提出批量年份以后可能作为后端的查询条件（例如目录、瓦片或点选按年份查询）。这次的实现为它留的余地和到时要改的地方：

- 年份已经是拥有者的一项独立状态，界面只读 `batchYear`、`batchYears` 并调用 `setYearForAll`，到时面板不用改；接口参数由拥有者从这项状态取，组件不直接拼
- 到时它的含义会从"最近一次批量设置"变成"当前的查询条件"：要重新决定单独改某个资源的年份时是否允许、是否同步改这个条件，以及目录按年份请求后"可选的年份"从哪里来。这些决定写新的 ADR，取代本 ADR 第 1 节
- 存储格式里的 `batchYear` 可以继续用；含义变了、需要不同的校验时把偏好的版本加 1（ADR 0042）
- 不在这次预先加接口参数和查询键，避免按没有实测的接口写代码（AGENTS.md 迁移规则）

## 后果

- 选择框能看到最近一次批量设置的年份；它不表示所有资源都是这一年，资源各自的年份仍在"已选择图层"和图例里看
- 删去了没有数据时的提示：选 2020、2021 只会看到选择框回显，地图不变；后端有了这两年的多年份数据后自动生效（roadmap 的待办不变）
- 为了"再选同一年也执行"，选项里多了一层铺满整行的 `span`（抵消 Element 选项左 20、右 32 的内边距）；Element 改了选项的内边距时可点的区域会变小，但文字仍然可点
- 测试：拥有者记下和回显的规则、偏好写入与还原（包括旧格式）、面板的回显、单独改年份不影响回显、再选同一年切回来、没有数据的年份不提示；改坏回显和"再选同一年"都由断言测出
