# 0076. 按需复用浅灰底面板标题栏

- 状态：已接受
- 日期：2026-10-21

## 背景

现状底图与资源管理已采用相同浅灰主标题，但样式分散在业务组件中。用户确认先验收并合入文件管理，再统一标题栏并写入通用设计规范。

## 候选方案

1. 全局修改所有面板、弹窗：简单，但会连带改变内部区块和没有标题的紧凑浮层
2. 继续在各业务中覆盖头部：保留局部效果，但容易出现背景、留白和折叠状态差异
3. 公共组件提供按需变体：统一已确认的主标题，默认外观与特殊布局保持稳定

## 决定

采用方案 3。`MxPanel` 增加 `headerTone="muted"`，默认 `plain`。灰底只覆盖主标题行，使用 `--color-neutral-bg-light`；标题继续使用 `MxTitle level="panel"`，16 / 600、深色文字、4 × 16 主色竖条、间隔 8，头部最小高 48、左右留 16。普通面板内容上留 16，浮动地图面板留 8，`flush` 不添加内容内边距。

增加 `subheader` 插槽承载标题下方固定标签区。地图工具改用同一个公共标题及操作区，标签在浅灰标题之外，收起时只剩 48 高标题行，单 / 多功能切换不影响内容身份。

文件目录与列表、资源目录 / 列表 / 详情、地图资源图层 / 功能组 / 资源详情使用此变体；文件上传与预览复用已有 `dialog-panel-header`。底图不设标题，继续使用已确认的紧凑透明度 / 关闭操作栏；已勾选保留 40 高与 14 字号，不提升成主标题。内部区块、功能标签和无标题面板不自动套灰底。

## 后果

删除业务中的重复灰底与普通面板上间距规则。新增页面按布局规范选择变体，不通过后代选择器改公共头部。`/dev/theme` 同时保留默认、浅灰、卡片头部样例，`/dev/map-ui` 使用真实公共变体；修改后检查实际页面、断点两侧、折叠与滚动，再运行相关回归和构建。
