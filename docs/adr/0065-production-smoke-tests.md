# 0065. 提前加入生产构建的浏览器冒烟

- 状态：已接受
- 日期：2026-10-19
- 补充：ADR 0040 中完整页面流程留到阶段七的安排

## 背景

Vitest 浏览器模式已经覆盖真实引擎与布局，但没有把生产入口、动态分块、登录、Worker 和页面缓存串起来。阶段五评审后决定先加入最小流程，其他业务端到端测试仍留到阶段七。

## 候选方案

- 复用真实账号的性能脚本：依赖后端与公网，无法在 CI 稳定运行
- 在 Vitest 中挂载页面：不能覆盖生产分块和真实入口
- 复用已安装的 Playwright Test，访问构建产物：覆盖完整流程，无需新依赖

## 决定

1. `tools/smoke/` 使用 `playwright/test`，命名 `*.spec.ts`，与 Vitest 的 `*.test.ts` 分开；不导入应用源码
2. CI 在内网生产构建之后执行 `test:smoke`，Playwright 管理本地预览的启动与退出；不用开发服务器，不复用已有服务
3. 使用独立浏览器上下文和固定账号响应，模拟登录、空资源目录与空文件列表，未声明接口及公网请求直接失败。地图使用真实 MapLibre、Worker 和构建中的本地省界，不替换地图引擎
4. 正常流程验证登录、地图首次画面稳定、切到文件管理、改变窗口尺寸、回到地图；原画布必须复用，区划搜索与相机层级保留，绘图缓冲区与显示尺寸一致
5. 分别替换登录页、地图页、运行时分块为抛错模块，验证首次导航失败、重复失败不叠提示，以及用户刷新后恢复。模块执行失败会被浏览器缓存，原地重试成功的语义另由内存路由用例覆盖
6. `MapCanvas` 外层通过 `data-map-view-state` 暴露既有视图状态，不增加新状态或原生地图出口；只读低频生命周期状态，不影响内层 MapLibre 的 class
7. 检查未处理异常与 Promise 拒绝；不设性能耗时门槛、不截图比对、不重试掩盖失败。测试输出放入已忽略的 `smoke-results.local/`

## 后果

可以检查应用装配与产物加载，但不替代真实后端、业务瓦片、字体或部署网络验收。CI 没有私有字体时按现有规则回退到系统字体。性能仍用 `measure:map-load` 单独实测。

本轮按用户要求只执行构建，新增冒烟及故障用例未在本地运行，执行结果待 CI 确认。
