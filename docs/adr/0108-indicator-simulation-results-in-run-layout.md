# 0108. 指标智能推演：结果展示并入推演阶段的布局

- 状态：已接受
- 日期：2026-10-29

## 背景

S12 之后的结果展示还是 S8 的样子（ADR 0105 第 1 条）：地图满屏，左侧推演概览（条件、版本、回看推演流程），右侧推演结果（指标页签、三个关键数字、AI 结论、多年度对比、城市对比、参数敏感性、变化归因、对比的一方），地图下方是数值 / 达标 / 差值着色，阶段条上有人工干预和重新编排。用户看了之后：

- 同意结果展示和前两个阶段统一框架
- 去掉版本对比，以及右侧除了结果以外的图表；"更关注算了哪些、结果是什么，而不是对比"

第五版原型（`apps/web/public/design.local/indicator-simulation-v5/`，不入库）先做成"上方指标卡 + 地图 + 右侧说明"，用户看后再改：左侧面板不再显示 AI 推理，改成显示结果（不要"怎么算的"）；去掉上方的指标卡和右侧面板；去掉"人工干预"；"重新编排"换成更显眼的按钮、放在更显眼的位置。改后的原型 2026-10-29 确认。

## 候选方案

1. **结果放在哪**：保留单独的结果阶段（浮在满屏地图上）；并进推演阶段的分栏布局，主区在流程图和地图之间切换
2. **地图画布放在哪**：页面层一直挂着、位置对准主区（或用 Teleport 把节点挪进主区）；放进推演阶段主区的内容区，第一次推演完成时创建
3. **结果的选择**：沿用"看哪一版、和谁比"；只看最新一版，存用户选过的指标、年度、着色、放大的市
4. **设施点和服务圈什么时候画**：按地图级别（minzoom）；按"放大到一个市"这个状态
5. **对话里看结果**：都交给改条件的规则（"看苏州市"会加上苏州市）；推演完成后先认看结果的说法，只换视图

## 决定

1. **结果是推演阶段的另一个视图**：推演完成后标题栏只留阶段和"推演流程 / 推演结果"的切换（暂停、人工干预、停止都去掉），"查看结果"、点流程图上的评价节点、对话里看结果的说法都切到结果。看结果时左侧是"推演结果"，主区是地图；看流程时左侧是 AI 推理，主区是流程图。重新推演时回到流程图（取代 ADR 0105 第 1 条、ADR 0107 第 1 条中结果展示的排布）
2. **左侧推演结果**（`ResultList`）：每项指标一条，写结果、目标和达标（一个市时是这个市达标、接近、未达标；多个市时写"达标 n/m 市"，全部、部分、都没有对应三态），模拟情景标出来；选中的一条用结果数值字号，展开各市的条形（一个市时是各区县），竖线是目标，悬停一市时地图描出它的边界，点一市放大到它。底部是整行的主按钮"重新编排"（`button-xl`）
3. **地图画布放进主区**：和流程图叠在内容区里，不在看的一层隐藏但保留尺寸；第一次推演完成时才创建，之后切换视图、重新推演都保留，回到条件编排时随推演阶段卸载。页面层不再有地图
4. **只看最新一版**（`useSimulationResult`）：拥有者只存用户选过的部分，由 `resolveSelection` 按最新一版的条件定下在看什么——选过的指标、年度、市还在条件里就沿用，否则是主指标、最新年度、整个范围；回到条件编排时清空。去掉版本对比、对比的一方、差值着色、关键数字、AI 结论、多年度和城市对比、参数敏感性、变化归因与它们的图表，以及结果阶段的人工干预和预览描边。引擎的版本仍保留（重算时作废和追加的规则不变），界面不再列出
5. **地图**：着色只有数值和达标；图例、着色和年度合在左下一张卡片里，登记成悬浮元素，镜头定位时避开。城市标注可以点（放大到这个市，左上出现"返回推演范围"），互相压住时先省掉数值、再只留圆点（`map/label-layout.ts` 按估算的宽度摆，不量 DOM）；鼠标下的区县用 `PointerHint` 提示名称、值和达标。设施点和服务圈只在放大到一个市（或范围只有一个市）时画：实测两个市的范围和一个市只差半级，按级别分不开
6. **达标三态的颜色**（第五版原型，结果展示）：达标主色、接近琥珀、未达标红；地图上用浅一档的填充常量。取代 S8 起结果面板和地图上"达标绿、未达标红"的用法（2026-10-29 用户确认的规则，ADR 0105 时期的模块文档）；条件编排的预估栏、人工干预的预估仍是原来的颜色
7. **对话里看结果**（`result/view-commands.ts`）：推演完成后先认这些说法——回看推演流程、按达标 / 数值着色、回到推演范围、看条件里的某一年、看范围里的某个市、看条件里的某项指标、看结果；带改动意思的说法（加上、去掉、只看、改成、规程、人口、目标、暂停、停止等）和条件外的市、年度、指标交给原来的规则。看结果时左侧没有时间线，AI 的回复在时间线上照记，同时写在对话栏输入框下面；改了条件、参数而重算的回复只记在时间线上。看结果时的快捷说法先给看结果的，再给两条改参数的

## 后果

- 结果相关的代码少了一半以上：删掉 `ResultStage`、`ResultsPanel`、`RunOverview`、`SimulationChart`、`result/chart-options.ts`、`result/chart-runtime.ts`，`model/analysis.ts` 的变化归因与敏感性，`run/narrative.ts` 的改动说明，`map-frame.ts` 的描边分组（换成悬停的市的描边）。这一页不再用 ECharts
- 推演阶段卸载（回到条件编排）时地图画布一起释放，下一次推演完成时重新创建
- 人工干预只在推演进行中可用；完成后要改参数，用对话说
- 1200 宽、全省时地图被图例让出一块后偏小；窄屏（小于 1200）时左侧推演结果和 AI 推理一样收进抽屉
