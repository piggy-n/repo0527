# 0037. 坐标定位与位置点

- 状态：已接受
- 日期：2026-10-10
- 落实 ADR 0029 留下的"`flyTo` 放在可视区域中心"；补充 ADR 0034（拾取工具）与 ADR 0036（工具栏上的面板开关）

## 背景

旧项目（yzt `master-demo` 836f03b）的"坐标定位"只是占位按钮，点击只会关掉区划定位面板。5B.6 新做，用户给出的方向：

- 度分秒、小数输入，地图拾取，定位，整合在一个面板里
- 地图上的点可以交互：按住一会儿进入拖动、调整点位；单击查看位置信息（不叫"位置分享"）
- 度分秒输入要降低门槛：能输入标准格式，也能只输入数字、由系统补上 `° ′ ″`；输入、编辑、复制都方便，复制出来的是规范、可以直接使用的坐标

交互方案先在原型里试过（长按时长、识别规则），用户确认了以下取舍：长按 0.5 秒；点位下方统一显示"坐标定位点"；拾取后打开位置信息；定位时至少放大到 14 级；复制用规范的 `′″`；"清除"也清掉点位；所在区划用 turf 判断；坐标定位与区划定位的面板互斥。

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 补全 `° ′ ″` | 输入时自动插入；输入时显示识别结果，离开输入框或回车时规范成标准格式 | 后者：边输入边插入，光标会跳、删字不顺、粘贴容易乱 |
| 两种格式的识别 | 各认各的；都认，格式只决定显示 | 都认：填哪种写法都能定位，切换格式不丢已输入的值 |
| 地图上的点 | 样式里的符号图层；DOM 浮层 | DOM 浮层：单击、长按、拖动要命中图钉，文字要字形文件；用视图的 `project` 定位，三维同样适用（同 ADR 0035 的标签） |
| 进入拖动 | 按下就拖；长按 0.5 秒 | 长按：避免单击查看信息时误拖；0.5 秒是常见的长按时长 |
| 位置信息的位置 | tippy / floating-ui；自己算 | 自己算：锚点是随相机每帧移动的地图点，只需要"放上方、放不下翻到下方、左右不出画布"，写成纯函数可以测试 |
| 复制 | `navigator.clipboard`；VueUse 的 `useClipboard({ legacy: true })` | 后者：剪贴板接口要求 https 或 localhost，内网的 http 部署要退回 `execCommand` |
| 所在区划 | 自己写射线法；`@turf/boolean-point-in-polygon` | turf 的单个包：成熟、处理洞和多面，按需安装（[map-core.md](../modules/map-core.md) 的选型） |
| `flyTo` 避开悬浮元素 | MapLibre 的 `padding`；`offset` | `offset`：`padding` 会留在地图上，改变"会话相机的中心就是画布中心"（ADR 0029） |

## 决定

### 1. 位置点

- 同一时间最多一个位置点：经纬度和来源（输入、拾取、拖动），新的替换旧的；关面板不删除。经纬度按 CGCS2000，与 WGS84 视为相同（ADR 0024），不涉及投影坐标
- 拥有者 `useLocationPoint`（`shared/map/location`）持有位置点和位置信息是否打开，提供放置、删除、开关位置信息；页面登记它的拾取工具
- 工具栏的"清除"同时清掉测量结果和位置点；区划选择不算"画上去的东西"，不清

### 2. 坐标的识别与格式

纯函数，度分秒和小数两种模式都按同一套规则识别：

- 标准写法：`118°46′40.5″`、半角 `'"`、`度分秒` 汉字、全角数字和符号
- 分隔的数字：`118 46 40.5`，依次是度、分、秒，分、秒可以省略
- 连写的数字：经度按"度 3 位（不超过 180，否则 2 位）、分 2 位、秒 2 位"，纬度按"度 2 位（不超过 90，否则 1 位）、分 2 位、秒 2 位"，秒可以带小数
- 小数度：`118.7778`
- 方向：`E` / `W` / `N` / `S`、东经 / 西经 / 北纬 / 南纬、负号；方向和输入框对不上时报错
- 校验：分、秒小于 60，经度在 −180～180，纬度在 −90～90；纬度超过 90 而经度不超过 90 时提示可能填反
- 显示与复制：小数 6 位（约 0.1 米），度分秒的秒 2 位小数（约 0.3 米）；复制的格式是 `118.777800, 32.056500` 和 `118°46′40.00″E, 32°03′23.40″N`

### 3. 定位

- `MapView.flyTo` 增加 `padding`，MapLibre 适配器换算成 `offset`（左右、上下留白之差的一半）；map-vue 的视口没传 `padding` 时避开登记的悬浮元素，和 `fitBounds` 一样
- 坐标定位：放下位置点，飞到它，缩放小于 14 级时放大到 14 级，否则保持；点在江苏省外时照常定位

### 4. 拾取

- 临时任务工具：十字光标，鼠标旁提示"点击地图拾取点位，Esc 取消"
- 单击一次就放下位置点、填入输入框、打开位置信息，然后退出（回到之前的常驻模式），地图不移动；再点"拾取"、按 Esc、关闭面板时取消

### 5. 地图上的点与位置信息

- 图钉的尖端对准坐标，下方显示"坐标定位点"
- 单击开关位置信息；按住 0.5 秒（图钉周围有进度）进入拖动，拖动时图钉抬起，输入框和位置信息实时更新，松开放下，Esc 回到原位；还没进入拖动就移动超过 4 像素时取消，不拖动也不平移地图
- 按下、移动、到时、松开、Esc 的判断写成与 DOM 无关的状态机，用假定时器测试
- 当前工具不是"移动"时，位置点不响应鼠标，单击落到地图上
- 位置信息挂在图钉上方，放不下时翻到下方，左右不超出画布；内容是小数、度分秒两行（各带复制按钮）、所在区划和"删除位置点"
- 所在区划：用县界的多边形判断点落在哪个区县（"南京市 / 玄武区"），都不在时是"不在江苏省内"；县界简化过，边界附近可能判错

### 6. 面板与工具栏

- `CoordinateLocatePanel`：度分秒 / 小数切换（默认度分秒，本次进入页面内记住），经度、纬度输入框，下方显示识别结果或错误，"拾取"（拾取中显示为按下）和"定位"；一次粘贴一对坐标到经度框时分到两个框
- 工具栏的"坐标定位"是开关面板的动作（ADR 0036 的 `pressed`）；页面保证坐标定位与区划定位的面板同一时间只开一个

## 后果

- 好处：输入、拾取、拖动设置的是同一个位置点，面板、图钉、位置信息不会对不上；能力在 `shared/map`，数据查询等页面可以复用
- 好处：识别规则、长按状态机、弹出位置都是纯函数，测试不依赖 DOM 和真实地图
- 代价：多一个依赖 `@turf/boolean-point-in-polygon`；所在区划依赖县界，第一次判断要下载县界（约 200 KB，之后用缓存）
- 代价：拖到画布边缘时不自动平移地图，要先放下、平移，再拖
