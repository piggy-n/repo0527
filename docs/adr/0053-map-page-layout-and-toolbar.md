# 0053. 地图页的布局与工具栏

- 状态：已接受
- 日期：2026-10-15
- 修正 ADR 0034 第 5 节（工具栏的位置与登记）、ADR 0043 第 5 节（图例的位置与版权控件）、ADR 0052 第 2 节（批量设置年份的位置）
- 补充 ADR 0029（登记哪些悬浮元素）、ADR 0031（底图的切换界面）、ADR 0039（按钮缩放的连续点击）、ADR 0041（目录的展示顺序与叠放顺序分开）、ADR 0042（面板的偏好）

## 背景

5A～5C 的地图页界面只做到能联调（roadmap"阶段五"：界面与逻辑解耦）。5D 开始专门设计，第一步 5D.0 定整体布局和视觉语言，之后逐块设计（roadmap"5D 地图页界面的专门设计"）。

### 联调骨架的现状

- 浮层分两列：左边是资源图层面板（320，撑满高度），右边一列从上到下堆着横排的工具栏、区划或坐标定位面板、点选详情、底图面板、边界面板、图例
- 工具栏是横排的 Element 按钮，放不下时换行（5A.3 测过 768 宽时约 760 宽）；没有放大缩小，不显示层级
- 底图、边界面板一直展开；图例在右列最下面，为右下角的 MapLibre 版权控件留出 32 像素（ADR 0043 第 5 节）。2026-10-15 去掉了控件里的 MapLibre 链接，样式里的数据源都没有写署名，控件现在是空的
- 区划、坐标定位、点选详情、图例各自登记为贴右边的悬浮元素；坐标定位面板卸载时退出拾取，符号编辑器卸载时丢弃取色预览
- 资源图层的拥有者只有一份顺序 `order`（叠放顺序），`move` 改的就是它；目录的 `index` 决定按值配色的默认颜色（`paletteColor(resource.index)`）
- 没有比例尺、经纬度等基本信息

### 用户的设计想法与取舍（2026-10-15）

- 工具栏竖排：业务工具保留图标加文字，去掉"默认视角"；另有一组只显示图标的地图基础工具（当前层级、放大、缩小、2D/3D、默认视角），两组外观上有区别，属于同一套竖向工具栏；不要指北针
- 层级显示整数；2D/3D 显示，三维阶段之前点击没有效果
- 底图用缩略图切换；图例、底图放在右下角
- 左下角（资源面板右边）放比例尺、经纬度等基本信息，二维不显示高度
- 资源面板保持 320 宽；"已勾选"区可以拖动排序

### 设计稿与评审

- 5D.0 的静态 HTML 设计稿（不入库，底图是真实的天地图瓦片）画了右下角的三种摆法，用户选了摆法 A：基础组在右下角，版权信息并进状态栏
- 本文初稿评审（2026-10-15）认为方向合理，要求修订：右侧改为两组 Tab 面板；资源树的拖动用独立的目录顺序；缩放按钮固定 ±1 并处理连续点击；补上窄屏的互斥规则、按完整名称重新核算工具栏高度；统一左侧面板等视觉细节；补充状态栏的更新条件和实施顺序。本文是修订后的版本

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 右下角 | A 基础组在右下角，图例、底图卡片在它左边；B 两组工具栏在右上连成一列；C 同 B，底图卡片放到左下 | A（用户选择）：业务操作在右上、视角操作在右下，区分明显，也是地图应用常见的"缩放在右下角"；角上没有位置给版权控件 |
| 右侧的多个面板怎样并存 | 各自一个面板，上下排列，底图面板作为弹出层盖住图例（初稿）；分成两组，每组一个外壳、用 Tab 切换 | 两组 Tab 面板（评审）：同一时间每组只显示一个内容，不会越排越长，也不会互相盖住 |
| 资源树的拖动改哪个顺序 | 拥有者的 `move`（叠放顺序）；独立的目录顺序 | 独立的目录顺序（评审）：目录顺序管展示，叠放顺序管地图上的上下关系，叠放只在"已勾选"里调整 |
| 放大、缩小的步长 | 到相邻的整数级（初稿）；固定 ±1 | 固定 ±1（评审）：和用户熟悉的地图一致；层级的显示另外定义，连续点击时累计目标级别 |
| 窄屏 | 各面板限制最大宽度；左右两边互斥 | 互斥（评审）：限宽在 375 宽时仍会让右侧面板盖住资源面板 |
| 工具栏的名称 | 改成"区划""定位"；保留"区划定位""坐标定位" | 保留完整名称（评审），每行两个字，按钮按两行重新核算高度 |
| 署名 | MapLibre 的版权控件；map-core 从样式收集、map-vue 提供（初稿）；底图的拥有者给出最小的署名 | 先核实天地图的授权要求，需要时由底图的拥有者给出最小的署名，放在状态栏末尾；只有底图一个来源，不做跨层的收集 |
| 基础工具和比例尺 | MapLibre 的 `NavigationControl`、`ScaleControl`；自己做 | 自己做：只有适配器写二维地图，内置控件的样式和位置与设计不一致，三维也要同样的界面 |
| 层级显示 | 四舍五入；一位小数；向下取整 | 向下取整：面板的"放大至第 N 级显示"、点选的"14 级以上只用渲染要素"都按"级别 ≥ N"判断 |
| 指北针 | 要；不要 | 不要（用户决定）：旋转、俯仰不为 0 时状态栏显示角度，"默认视角"把两者归零 |
| 底图入口 | 一直展开的面板（骨架）；工具栏按钮弹出（旧项目）；缩略图卡片 | 缩略图卡片（用户决定） |
| 图标 | 用户提供；Tabler Icons（MIT）；Lucide（ISC） | Tabler：线性风格统一，地图类的图标多；用户有更合适的再替换个别图标 |
| 悬浮面板的外观 | 浅色；深色 | 浅色，沿用 page-layout.md"画布型"的原则 |

## 决定

以下尺寸都在地图区域里，`M` 是 `--space-lg`（16）。

### 1. 区域划分

```
+----------------------------------------------------------------------+
| +-- resources 320 --+              +-- functions 320 --+  +-- biz --+ |
| |                   |              | [tab][tab][tab]   |  |   56    | |
| |                   |              +-------------------+  |         | |
| |                   |                                     +---------+ |
| |                   |              +-- display 320 ----+             |
| |                   |              | [tab][tab]        |  +-- base -+ |
| |                   |              +-------------------+  |   40    | |
| |                   |  [status ...]   [legend][basemap]   |         | |
| +-------------------+                                     +---------+ |
+----------------------------------------------------------------------+
```

resources 是资源图层面板，functions 是功能面板，display 是显示面板，biz 是业务组，base 是基础组，status 是状态栏，legend、basemap 是卡片行的图例卡、底图卡。

| 区域 | 位置 | 内容 |
|---|---|---|
| 资源图层面板 | 左 `M`，上下各 `M`，宽 320 | 收起时是左上角的竖条（40 宽，图标加竖排的"资源图层"），和分栏页面窄屏时的窄条一致 |
| 业务组 | 右上角，右 `M`、上 `M`，宽 56 | 移动、点选 · 测距、测面、清除 · 区划定位、坐标定位 |
| 基础组 | 右下角，底 `M`，宽 40，和业务组的中线对齐 | 层级、放大、缩小、默认视角、2D/3D |
| 功能面板 | 右边缘离画布右边 88（`M` + 56 + `M`），上 `M`，宽 320 | 区划定位、坐标定位、资源详情，Tab 切换（第 4 节） |
| 显示面板 | 右边缘同上，底边在卡片行上面 `--space-md`，宽 320 | 图例、底图（含行政区边界），Tab 切换 |
| 卡片行 | 底 `M`，右边缘和两组面板对齐 | 图例卡、底图卡，各 56 × 56，间隔 `--space-md` |
| 状态栏 | 底 `M`，左边从资源面板（或竖条）右边再隔 `M` 开始 | 第 5 节 |

- 最右边一列只放两组工具栏；两组面板都在它左边，右边缘对齐
- 两组面板放在同一条纵向的弹性容器里：功能面板靠上、显示面板靠下，各自按内容定高、设最大高度、内容区内部滚动，同时打开时按比例收缩，不重叠

### 2. 业务组

- 竖排，图标在上、文字在下（12px，行高 16），每行两个字："区划定位""坐标定位"分两行。按钮宽 48；文字一行的高 46，两行的高 62；整组高约 380（内边距 8、两条分隔线）
- 三组之间有分隔线；"默认视角"移到基础组
- 状态：当前工具（同一时间只有一个，是一种模式）用实心主色；打开着面板的按钮（区划定位、坐标定位）用浅主色底
- 提示文字和无障碍名称始终是完整的名称；矮屏时只显示图标（第 8 节）
- 工具栏的按钮仍由页面挑选、动作的回调仍由页面给出（ADR 0034）；`items` 改为分组的列表，用来画分隔线

### 3. 基础组

- 层级：当前缩放级别向下取整（加 1e-6 再取整，避免 7.9999999 显示成 7），悬停显示精确值（如"当前层级 13（13.6）"）；只显示，不能点。显示方式和缩放的步长分开定义
- 放大、缩小：每次 ±1（13.6 → 14.6 / 12.6），截断在页面给的缩放范围里，到头时对应的按钮不可用；动画 300 ms，手感在实现后体验确认
- 连续点击：按钮缩放记着自己的目标级别。上一次按钮缩放的相机操作还有效（没被新的操作作废）时，在目标级别上再加减 1；否则从当前相机的级别开始。每次点击都是一次新的相机操作（`runCameraOperation`），读目标级别在开始新操作之前。滚轮、拖动、默认视角、区划定位等新的操作会作废它（ADR 0038、0039），之后的点击从当时的级别重新开始，不读动画的中间值
- 滚轮：首轮的目标是降低灵敏度、保持连续和平滑，不要求"滚一下正好一级"。适配器加滚轮和触控板的缩放速率选项（MapLibre 的 `scrollZoom.setWheelZoomRate`、`setZoomRate`），取值用普通鼠标和触控板分别实测后定
- 默认视角：原来的 `goToDefaultView`（ADR 0033）
- 2D/3D：上下两格，当前的一格高亮。三维阶段之前点 3D 没有效果，提示"三维暂未开放"（外观照常，`aria-disabled`）
- 只有图标的按钮都用 Element 的 `ElTooltip` 提示名称
- 这一组是 `shared/map` 的一个组件，内容固定；以后别的地图页需要不同的组合时再加 `items`

### 4. 右侧的两组 Tab 面板

| 面板 | 内容（Tab 的顺序） | 入口 |
|---|---|---|
| 功能面板 | 区划定位、坐标定位、资源详情 | 业务组的"区划定位""坐标定位"；用点选工具在地图上单击或框选 |
| 显示面板 | 图例、底图（含行政区边界） | 图例卡、底图卡 |

每组共用一个面板外壳，头部是已打开功能的 Tab（每个 Tab 带关闭按钮），同一时间只显示一个内容；只打开一个时，这一个 Tab 就像标题。两组之间互不影响。

**打开、切换与关闭**

- 点入口：没打开时打开并切到它；打开了但没在显示时切到它；正在显示时关闭它
- 用点选工具单击或框选、开始识别时，打开并切到资源详情（这是用户的操作，在点击的当下切换）
- 关闭（Tab 上的关闭按钮、再点入口）：从已打开里去掉；关的是当前的 Tab 时，切到最近显示过的另一个；都关了外壳消失
- 关闭资源详情就是点选的 `close()`，清除选择；切到别的 Tab 只是隐藏，选择、高亮和结果都保留。拥有者自己清除了结果（取消勾选资源、换年份、离开点选工具等，ADR 0047）时，资源详情的 Tab 随之关闭
- 请求返回后（识别、加载更多、详情、区划边界）只更新自己的内容，不切换 Tab；只有用户的操作会切换

**隐藏与关闭**

- 打开期间内容一直挂载，切走时隐藏：坐标输入、查询结果、图例的展开状态都保留
- 内容组件接收"是否在显示"（`active`）。隐藏时结束临时的交互：坐标定位的拾取退出，符号编辑的取色预览丢弃，内容里打开的下拉框、取色器等弹出层收起；关闭时卸载
- 坐标定位面板现在在卸载时退出拾取，改为在隐藏和卸载时都退出；符号编辑器同理（ADR 0044 的取色器规则不变）

**状态归属**

- "已打开的功能"和"当前 Tab"是页面的界面状态，由 `shared/map` 的一个组合式函数管理（两组各一个实例），切换和关闭的规则写成纯函数测试；业务状态仍在各自的拥有者里
- 原来各面板自己的头部、关闭按钮和悬浮元素登记移到外壳；面板拆成外壳和内容两部分
- 底图内容：三张缩略图（矢量、影像、无底图，只写类型，不介绍数据源）、当前底图的透明度；"行政区"一节：省界、市界、县界和透明度（拥有者不变，ADR 0031、0033）。缩略图用天地图南京附近 10 级的一张底图瓦片，不另做图片，只在 `appConfig.tianditu` 有值时请求；内网时只有"无底图"
- 图例内容和 ADR 0043、0044 相同，只是位置移到显示面板，不再为版权控件留位置

### 5. 状态栏与署名

| 视图 | 一直显示 | 有条件时显示 |
|---|---|---|
| 二维 | 比例尺；鼠标所在的经纬度（鼠标不在画布上时显示画布中心） | 旋转角、俯仰角：取整后不为 0 时显示 |
| 三维（三维阶段做） | 比例尺；鼠标所在的经纬度和地表高程；视点高度；俯仰角；方位角 | — |

- 经纬度的写法和坐标定位面板用同一个格式（度分秒或小数，`useLocationPoint` 的 `format`）
- 经纬度在三种情况下重新计算：鼠标移动；相机变化和画布尺寸变化（`projectionRevision`，鼠标不动、地图缩放时下面的经纬度也在变）；视图切换。视图失效或被替换时清掉旧的位置，视图不在就绪时不显示经纬度
- 鼠标位置：工具模型在把输入交给当前工具之前发出一个只读的输入事件，map-vue 订阅后在上下文里提供 `pointer`（画布上的屏幕坐标，离开画布时为 `null`），按动画帧合并；状态栏用 `view.pick` 换成经纬度。不依赖当前工具，也不碰原生地图（ADR 0024、0034）
- 比例尺：在画布中间的水平线上取相距 100 像素的两点 `pick`，按椭球面算距离（测量用的同一套计算，ADR 0035），选不超过 80 像素的整齐长度（1、2、5 × 10ⁿ 米，满 1000 米用 km）；拾取不到（三维看天空）时不显示。随相机和画布尺寸重算
- 宽度不够时先去掉旋转、俯仰（三维是视点高度等），再去掉经纬度；比例尺和署名一直保留
- 状态栏只显示，不拦截鼠标（`pointer-events: none`）
- 署名：先核实天地图服务授权要求的署名；需要时由底图的拥有者给出最小的署名文字，状态栏末尾显示，不需要时不显示。适配器关掉 MapLibre 的版权控件（摆法 A 的角上是基础组）。只有底图一个来源，不做跨 map-core、map-vue 的署名收集；以后有第二个需要署名的来源时再评估

### 6. 资源图层面板

**两种顺序**

| 顺序 | 管什么 | 在哪里调整 | 保存 |
|---|---|---|---|
| 目录顺序 | 资源树的展示：按父节点记录子节点（分类和资源）的顺序 | 资源树里拖动 | 单独的偏好，按账号 |
| 叠放顺序 | 地图上图层的上下关系（拥有者的 `order`） | "已勾选"里拖动（拥有者的 `move`） | 随资源图层的偏好（ADR 0042，不变） |

- 目录顺序只在推导面板的树时使用：不改查询缓存和目录本身，不改资源的身份和 `index`（按值配色的默认颜色不变），不改叠放顺序。新勾选的资源在叠放顺序里的位置仍按目录原来的顺序（ADR 0041）
- 第一版只能在同一个父节点下调整，不能拖到别的分类；搜索期间不能拖动（看到的是过滤后的列表，落点和完整目录对不上）
- 恢复时和最新的目录合并：记录里仍存在的子节点按记录的顺序；目录里新出现的排在后面，按目录顺序；已经不在目录里的忽略。读出时用 zod 校验（同一父节点下不重复）
- 两处的拖动手柄都能获得焦点、按上下方向键移动；提示分别是"调整目录顺序""调整叠放顺序（上层优先显示）"。是否引入拖动的库（如 SortableJS）在 5D.2 定

**布局与细节**

- 头部：竖杠标题"资源图层"、文字页签（主节点、统计报表、分节点资源，12px，当前的用主色加下划线）、收起按钮。统计报表、分节点资源点开是"暂无数据"
- 搜索框和"批量设置年份"在同一行；"没有这一年的资源保持不变"放进下拉框里，不再单独占一行（修正 ADR 0052 第 2 节的位置）
- 资源树：资源名称前面是几何类型的图标（面、线、点）；拖动手柄在悬停或获得焦点时出现
- 目录树和"已勾选"之间的分割线可以上下拖动，中间是圆形的手柄；两边各有最小高度；分割线能获得焦点，按上下方向键调整
- "已勾选"的标题用区块标题的规格（14 / 600，蓝色竖杠，`MxTitle` 的区块级别），和"资源图层"的面板标题分出层级；不放常驻的说明长句
- "已勾选"的每一行：拖动手柄、年份（多年份是选择，单年份是文字，宽度一样）、名称、透明度、×（取消勾选；状态按 `code` 保留，重新勾选时年份、透明度照旧）
- 透明度：显示百分比，带边框，看得出能点；点开是不带刻度的滑块
- 提示：最小显示级别（"放大至第 N 级显示"）收进名称后面的信息图标，悬停和键盘聚焦时显示；部分瓦片加载失败、配置错误这类要处理的状态仍直接显示在行里
- 默认透明度改为 100%（`DEFAULT_OPACITY` 由 0.9 改为 1）；已经存下的透明度保留原值，分不清是用户调的还是原来的默认值
- 面板的收起和分割线的位置（"已勾选"区占可用高度的比例）按账号记住，走 ADR 0042 的流程，读出时校验并限制在最小高度以内

### 7. 视觉语言

- 浮在地图上的元素（面板、工具栏、卡片）：`--color-bg-mask` 背景、`--shadow-md`、`--radius-md`；状态栏用 `--shadow-sm`、`--radius-sm`
- 面板沿用面板规范：头部 48 高，内容区内边距 `0 16 16`；标题直接用现有的 `MxTitle`（面板 16 / 600，区块 14 / 600）。地图上的面板和两组面板的外壳都用 `libs/ui` 的 `MxPanel`，加一种悬浮的外观，不另写一套；标题后的页签、外壳头部的 Tab 要用的插槽在实现时加
- 资源详情的内容：要素的标题和资源、年份在上，竖杠和标题的左边起点与其他面板一致；"返回列表"放在标题行右侧的操作区（或标题下面单独一行），带文字，不只是箭头
- 按钮状态：默认 `--color-text-regular`；悬停 `--color-primary-bg-light` 底、主色；当前工具主色实心、`--color-text-inverse`；按下（面板打开）`--color-primary-bg` 底、主色；不可用 `--color-text-disabled`
- 字号：面板里的正文 14（资源名称、区划、属性），次要信息 12（年份、透明度、数量、提示、状态栏、工具栏的文字）
- 图标：Tabler Icons 3.49.0 的线性图标，工具栏 20、面板里 16，颜色跟文字。放进 `assets/icons/` 时按用途命名（如 `map-measure-distance`、`geometry-polygon`），不用 Tabler 的名字，以后换图不用改代码；根元素的描边宽度由 2 改为 1.5；许可的署名和每个文件的来源写在 `docs/modules/icons.md`。Element 组件的图标属性（输入框前缀、下拉箭头等）仍用 Element 的图标

| 用途 | Tabler 图标 | 用途 | Tabler 图标 |
|---|---|---|---|
| 移动 | `hand-move` | 默认视角 | `home` |
| 点选 | `click` | 图例 | `list-details` |
| 测距 | `ruler-2` | 面 / 线 / 点 | `polygon` / `line` / `circle-dot` |

| 清除 | `eraser` | 分割线手柄 | `menu-2` |

### 8. 矮屏与窄屏

- 矮屏：地图区域放不下带文字的业务组和基础组（16 + 380 + 16 + 209 + 16，约 640 像素；1366 × 768 的笔记本上地图区域只有 530～560）时，业务组只显示图标，按钮高 32（整组约 250）。用页面根元素上的容器查询判断高度，不写脚本
- 窄屏：画布宽度小于全应用的窄屏断点（1200，`@yzt/ui`）时，左边的资源面板和右边的两组面板同一时间只显示一边：最后操作的一边显示，另一边隐藏。这是由状态推导的显示规则，不改各自的状态：资源面板的收起偏好不变，右侧已打开的功能保留（隐藏时按第 4 节结束临时的交互）；变宽以后两边按各自的状态显示
  - 点业务组的面板入口、图例卡、底图卡，或用点选工具开始识别，算操作右边
  - 展开资源面板（点竖条）算操作左边
- 小于 768（不是目标设备，ADR 0034 第 1 节）：图例卡、底图卡叠在基础组上面；面板的宽度不超过画布减去工具栏一列；状态栏只留比例尺和署名。抽屉等外观在 5D.8 再定

### 9. 定位时避开哪些元素（ADR 0029）

- 登记贴左边：资源图层面板（收起时是竖条）
- 登记贴右边：业务组（新加，修正 ADR 0034 第 5 节的"不登记"：竖排后它是一条贴边的长条）；两组面板的外壳（实际显示时，包括显示面板里的底图）
- 不登记：Tab 里的内容（由外壳代表，原来各面板自己的登记去掉）、基础组（贴右边的占用不超过业务组）、卡片行、状态栏

### 11. 实施与验收

- 先按本文修订设计稿，确认后再动代码
- 5D.0：两组面板的外壳与状态协调；把旧面板拆成外壳和内容（不只是挪位置）；按第 1 节搭出新的区域骨架；窄屏时左右只显示一边；`page-layout.md`"画布型"一节改为本文的布局
- 之后按 roadmap 的 5D.1～5D.8 逐块出设计稿、确认后替换组件；每块在真实页面上截图验收，检查 1440、1366 × 620、768 三种尺寸
- 测试要覆盖：Tab 的打开、切换、关闭和"关闭当前的切到最近显示过的"；隐藏时退出拾取、丢弃取色预览；资源详情关闭时清除选择、拥有者清除结果时 Tab 关闭；请求晚到不切换 Tab；两种顺序互不影响（拖目录不改叠放和默认颜色，拖叠放不改目录）；连续点击缩放累计、到边界不可用、被新的操作打断后重新开始；窄屏时左右只显示一边，变宽后恢复
- 滚轮的手感、缩放动画在实现后实际体验确认；静态设计稿只用于布局和视觉评审

## 后果

- 好处：右上是业务操作、右下是视角操作，最右边一列只放工具栏；右侧的面板固定为两组，同时打开多个功能时用 Tab 切换，不会越排越长或互相盖住
- 好处：目录顺序和叠放顺序各管各的，拖动资源树不会意外改变地图上的上下关系
- 好处：竖排的工具栏宽度固定，不随窗口宽度换行；矮屏只去掉文字
- 好处：比例尺、经纬度都由视图接口推导，二维、三维用同一个界面
- 代价：面板要拆成外壳和内容，内容要区分隐藏和关闭；多了几项逻辑（输入事件、缩放的连续点击、滚轮速率、目录顺序的偏好），要动 map-core、map-vue
- 代价：同一组里的功能不能同时看到（比如区划定位和资源详情要切换 Tab）
- 代价：业务组登记为悬浮元素后，没有打开面板时定位也会在右边多让出 72 像素
- 代价：用的是开源图标，和系统的其他素材（顶部导航的图标）风格不一定一致，以后要统一时再替换
