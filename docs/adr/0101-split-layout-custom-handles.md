# 0101. 分栏布局由页面给出收起把手和窄条：基本统计页的把手设计图

- 状态：已接受
- 日期：2026-10-28
- 补充：[ADR 0100](0100-space-monitoring-statistics.md) 第 6 节（"图标暂用 Element 的 `Fold`、`Expand`"）

## 背景

ADR 0100 给 `MxSplitLayout` 加了宽屏收起，收起按钮和窄条暂用 Element 的图标，等用户给出设计图标。2026-10-28 用户给了两个 SVG，内容和旧页面 `public/images/TongJi/` 的两张把手图一样：

- 收起时的竖条 80 × 277（右箭头，旧页面压着竖排的"统计报表计算"），展开时贴在面板右上角的横条 131 × 49（左箭头，比面板上边高 8）
- 每个 SVG 只是一张 1200 像素宽的 PNG 位图加一个白色箭头，各约 420 KB

它们不是单色图标：放进 `assets/icons/` 会进注册表，所有页面的入口多出约 850 KB；组件库也不能引用应用里的图片（ADR 0004、0016）。

## 候选方案

1. **素材**：原样使用 SVG；转成 2 倍尺寸的 WebP（项目的位图都用 WebP，如登录页、顶栏、驾驶舱）
2. **怎样接进布局**：页面自己画把手、不用布局的收起；`MxSplitLayout` 加插槽，外观由页面给出，按钮、状态和可访问名称仍由布局负责
3. **窄屏**：抽屉的窄条也换成设计图；仍用默认的 40 像素窄条

## 决定

1. **素材转成 2 倍尺寸的 WebP**（用户 2026-10-28 选定）：用 Playwright 的 Chromium 按 2 倍尺寸栅格化，编码为质量 0.9 的有损 WebP，保留透明通道；竖条 160 × 554、18 KB，横条 262 × 98、6.4 KB。放在 `pages/space-monitoring-statistics/images/`（`panel-handle-collapsed.webp`、`panel-handle-expanded.webp`，沿用旧项目的名字），只有这个页面的分块会加载
2. **`MxSplitLayout` 加两个插槽**：
   - `rail`：宽屏收起时窄条里的内容，代替图标和竖排名称；窄条变成没有底色、阴影和内边距的按钮，大小随内容、竖直居中，可访问名称由布局用 `aria-label`（侧栏名称）给出，内容可以只是图片
   - `collapse`：宽屏展开时的收起把手，由布局放在侧栏右上角（绝对定位，可以往上超出侧栏，不超过布局的内边距），可访问名称是"收起 + 侧栏名称"；有它时侧栏面板不再放默认的收起按钮（布局上下文的 `collapsible` 改名为 `collapseInPanel`，表示"由面板放收起按钮"）
3. **窄屏仍用默认的窄条和抽屉**：80 像素宽的竖条在手机宽度下太占地方；抽屉里只有关闭按钮
4. 竖条上的名称由页面压在设计图的浅色区域上（位置同旧页面），字号、颜色用令牌（16、半粗、主色），不新增旧页面的 20 号和 `#008fff`

## 后果

- 不传插槽的分栏页面不受影响，仍是 Element 图标；以后别的页面要换外观也走插槽，不在组件库里放图片
- 页面的插槽内容只管外观，点击、`aria-expanded`、宽窄屏的切换都还在布局里，测试也在 `libs/ui`
- 两张图共约 25 KB，原 SVG 不入库（用户桌面保留原件）
