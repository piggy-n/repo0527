# 0109. 指标智能推演改名为城市国土空间监测指标AI计算：文案、AI 输入框、机器人头像与按钮主次

- 状态：已接受
- 日期：2026-10-29
- 修改：ADR 0106 第 6 条（指令输入框的"刷新"和初始文字）、ADR 0107 中完成卡片的位置、ADR 0108 第 2 条（"重新编排"的叫法）与第 7 条（回复前的小圆球）

## 背景

S13 之后用户对整页提出一轮调整：

1. 页面改名"城市国土空间监测指标AI计算"；"推演"统一改为"计算"，"模拟情景"和"重新编排"另想叫法，"条件编排"改为"条件配置"；主标题（如"指标智能推演条件"）同步改名，加规范里的浅灰底
2. AI 输入框去掉前面的图标和下方所有灰色提示；占位直接写完整的示例，不加"你可以……""输入推演指令……"；Tab 把示例填进输入框；"刷新"改为"换一批"
3. 条件配置最后一步"AI计算"的图标和页面里原来的蓝色渐变 AI 图标，统一换成 main 上 AI 对话的机器人
4. 第二阶段的标题改为"AI计算"；对话加 AI 和用户（"我"）的头像；说明里不提 Excel；计算中右上角的继续 / 暂停、人工干预、停止分出主次
5. "查看结果""调整条件"固定在 AI计算对话区域的底部，不放在流程图底部
6. 去掉"竖线是目标""点城市标注放大，设施和服务范围放大后显示"

## 候选方案与用户的选择

| 问题 | 候选 | 选择 |
|---|---|---|
| "模拟情景"改成 | 自定义口径；自定义；调整口径 | 自定义口径：和一直保留的"标准口径"成对 |
| "重新编排"改成 | 调整条件；修改条件；返回条件配置 | 调整条件：说清点了做什么，和阶段名"条件配置"呼应 |
| 机器人图片从哪来 | 把 main 合进本分支后上移到 shared；复制一份到本模块 | 合 main 后上移：features 之间不能互相导入，复制会有两份 |
| 计算中三个按钮的主次 | 暂停为主、停止红色；人工干预为主；暂停为主、停止是文字按钮 | 暂停为主，人工干预默认（打开时浅色主色），停止红色朴素按钮 |

## 决定

1. **叫法**：界面上统一写"计算"（AI计算、计算流程、计算结果、开始计算、计算范围），阶段名"条件配置"，参数偏离标准口径时标"自定义口径"，回到条件配置是"调整条件"；界面文字不提 Excel（"当前使用自定义口径计算""参数都按标准口径计算""标准规则"）。名称、标题不在"AI"和汉字之间加空格（同 main 的"AI对话"），句子里照旧。对话的规则同时认新旧说法。代码的标识符、引擎和文档里描述历史的"推演""编排"不改
2. **浅灰底标题栏**：条件库、AI计算、计算结果三个侧栏面板用 `headerTone="muted"`（ADR 0076）。这一页的侧栏只有一块面板，S10 时"上下两块叠在一起分不开"的顾虑不存在
3. **AI 输入框**：打开时是空的，占位是一句完整的示例（条件配置时是指令示例，计算和结果阶段是第一条不是暂停、停止这类控制的快捷说法）；空着时 Tab 填入，有字时 Tab 照常移动焦点；"换一批"换一句示例并清空输入框，不再逐字打出。去掉小圆球和灰色提示，看结果时 AI 的回复仍写在输入框下面（左侧这时没有时间线）。高度改用 CSS 的叠放副本按"文字或示例"撑开：浏览器量高度时不算占位，`useTextareaAutosize` 量不出两行的示例
4. **机器人头像上移到 shared**：先把本地 main 合进本分支（`0c9fdaa`，不动 main），再把 `features/ai-chat/images/assistant.webp` 移到 `shared/chat-avatar/`，和"我"一起做成 `ChatAvatar`（speaker、size，机器人约占圆底的 72%、取双数），AI 对话改用它，外观不变。这一页的渐变圆球、闪光图标全部换成它；`simulation-ai` 图标、`--color-ai-violet`、`--color-ai-cyan`、`--orb-angle` 删除，`--color-ai-glow` 仍用于外发光
5. **对话的头像**：用户的话右侧是"我"；AI 的回复把时间线上的圆点换成机器人，圆心对准时间线
6. **按钮主次**：暂停 / 继续 `type="primary"`；人工干预默认，打开时 `primary` + `plain`；停止 `type="danger" plain`，仍用气泡确认
7. **完成后的操作**：流程图底部的完成卡片删除，"查看结果"（主按钮）和"调整条件"固定在 AI计算面板的 `footer`（`button-xl`，平分一行），只在完成后出现；完成的说明是时间线的最后一句。流程图全览不再给卡片留底部空间
8. **去掉的说明**：结果列表的"竖线是目标"、地图卡片的"点城市标注放大，设施和服务范围放大后显示"

## 后果

- 本分支包含了 main 的数据查询等提交，合回 main 时这部分已经在 main 上
- `ChatAvatar` 是第二个由 feature 上移的界面素材；以后的对话类页面直接用它，不再各自放图片或画圆球
- 输入框不再用 `useTextareaAutosize`，高度规则写在样式里（三行上限、`data-value` 的副本）
- 用户习惯的旧说法（只推演、重新编排、结束推演）在对话里仍然有效
- 这轮没有另做 HTML 原型：改动是文案、图标和局部的按钮位置，在真实页面上实现、验证后交用户验收
