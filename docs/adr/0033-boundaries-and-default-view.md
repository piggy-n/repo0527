# 0033. 行政区边界与默认视角

- 状态：已接受
- 日期：2026-10-10
- 更正 ADR 0031 中对旧项目叠放的描述（第 4 条的例子，已在 0031 中改正）

## 背景

5B.2 做省、市、县三级行政区边界和默认视角，是 `shared/map` 的第二个拥有者，沿用 ADR 0031 的写法（组合式函数持有状态和操作，纯函数推导分组，界面通过 props 拿到它）。

旧项目（yzt `master-demo` 836f03b）：

- 边界是 `public/static/geojson/` 下的三份静态文件，每一级由一个 GeoJSON 数据源加填充、发光、线几个图层画出；行政区边界的填充透明度和发光宽度都是 0，实际只有线可见。线的颜色都是 `#597EF7`，宽度随缩放变化：省最粗、不透明度 0.94，市次之、0.78，县最细、虚线、0.62，从 8 级开始
- 现状底图默认只显示省界；三级共用一条透明度，乘在各级原有的不透明度上。指标页四项基础图层默认全开（阶段六）
- 叠放：边界创建时插在注记下面，但每次业务图层显隐、透明度、排序变化后又被移到最顶（注释是"固定高层级"）。实际从下到上是底图、注记、业务图层、选中高亮、区划遮罩、县界、市界、省界、区划高亮。ADR 0031 写成了"边界在注记下面"，这里更正
- 默认视角：`flyTo` 到固定相机（119.5, 33.0, z6.8，俯角和旋转都是 0），500ms 线性动画，并清掉区划定位留下的 padding；地图的缩放范围是 5～18 级
- 静态边界不请求天地图，内网也能用；天地图行政区接口只在区划定位里用到（5B.5）

2026-10-10 实测：

| 文件 | 要素 | 点数 | 坐标小数位 | 大小（gzip） | 保留 6 位小数、只留名称和代码后（gzip） |
|---|---|---|---|---|---|
| 省界 | 1 | 20829 | 14～15 | 798 KB（310 KB） | 464 KB（139 KB） |
| 市界 | 14（连云港分成两块） | 64695 | 14～15 | 2479 KB（964 KB） | 1441 KB（432 KB） |
| 县界 | 95（江苏的县级区划全在） | 8420 | 6 | 198 KB（60 KB） | 199 KB（60 KB） |

- 县界大幅简化过（每个县约 89 个点），放大后和市界、省界对不齐；没有更精细的数据
- 省界的实际范围是 116.356～121.971°E、30.76～35.142°N；`JIANGSU_BOUNDS` 的东边界是 121.9，切掉了启东一角
- MapLibre 的 GeoJSON 数据源可以直接写地址，由 Worker 下载和解析；MapLibre 6 的 `fitBounds` 默认把旋转归零，俯角不变

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 数据处理 | 原样复制；转换一次、文档写明步骤；写成转换脚本 | 转换脚本：坐标保留 6 位小数（约 0.1 米），属性只留名称和代码，数据更新时重跑 |
| 数据放在哪 | `public/`；`src` 里用 `?url` 导入 | `?url`：文件名带内容哈希，可以长期缓存，数据不打进 JS 包 |
| 怎样加载 | 拥有者 `fetch` 后把对象放进样式；样式里直接写地址 | 写地址：主线程不解析 1.4 MB 的 JSON，会话里只存一个字符串，三维也能按地址加载 |
| 关闭的级别 | 留在样式里、设为不可见；不放进样式 | 不放进样式：勾选时才下载，和底图"没选中的不在样式里"一致 |
| 透明度 | 每级一条；三级共用一条 | 共用一条，与旧面板一致 |
| 默认视角 | 飞到固定相机；按江苏的范围适配 | 按范围适配：不同屏幕尺寸、面板展开收起时都完整显示江苏，并与进入页面时的定位一致 |
| 缩放范围 | 不限制；5～18 级 | 5～18 级，与旧项目一致 |

## 决定

### 1. 数据

- 来源是 yzt `836f03b` 的 `public/static/geojson/`。`apps/web/tools/boundaries` 的转换脚本把坐标保留 6 位小数，属性只留 `name` 和 `code`（省用 `adcode`，市用 `code`，县用 `gb`），输出到 `shared/map/boundary/data/`，文件名改为 `jiangsu-province.json`、`jiangsu-city.json`、`jiangsu-county.json`
- 县界原样迁移，文档里注明放大后对不齐。连云港的两个要素不影响画线，5B.5 按市定位时按代码合并

### 2. 加载

- 数据源写成 `{ type: 'geojson', data: url }`，`url` 来自 `?url` 导入。MapLibre 在 Worker 里下载和解析；5B.5 需要几何时再 `fetch` 同一个地址，会命中 HTTP 缓存
- 关闭的级别不在样式里，勾选时才下载；关掉再打开时重新解析（下载命中缓存）
- 下载失败由 MapLibre 的 `error` 事件经 `onError` 上报，暂不提示用户；哪些运行中的错误要提示，按 roadmap 5C.1 的事项一起定

### 3. 拥有者

- `boundaries` 分组：每个打开的级别一个数据源和一条线图层，ID 是 `boundaries-province` 等；从下到上是县、市、省。线的样式照搬旧项目，透明度乘在各级原有的不透明度上
- `useBoundaries()` 持有每一级是否显示和共用的透明度；初始只开省界，透明度 1。其他页面需要不同的初始值时（如指标页四项全开）再加参数

### 4. 分组的叠放

现状底图页现在声明 `['basemap', 'basemap-labels', 'boundaries']`。以后完整的顺序预计是：

```
basemap → basemap-labels → resources → highlight → region-mask → boundaries → region-highlight → measure
```

注记要不要压在资源图层上面（旧项目是资源压住注记，不透明的地类图斑会盖住地名），在 5C 决定。

### 5. 默认视角

- `JIANGSU_BOUNDS` 改为省界的实际范围向外取整：`[116.35, 30.75, 121.98, 35.15]`
- `shared/map` 的 `useDefaultView(map)`：本次进入页面后第一次就绪时不带动画地适配一次（原来写在现状底图页里），并提供 `goToDefaultView()`，用 500ms 动画适配江苏的范围，避开悬浮元素，旋转归零；视图没有就绪时什么也不做。工具栏（5B.3）调用它
- 地图倾斜时 `fitBounds` 不把俯角归零，实现时在浏览器里确认，需要时给视图接口的 `fitBounds` 加俯角选项
- 缩放范围 5～18 级是 `shared/map` 的常量，由页面通过画布的 `mapOptions` 传入

### 6. 联调界面

`BoundaryPanel` 用三个复选框和一条透明度滑块，没有打开任何级别时没有滑块；与底图面板一起放在右上角。5B.3 的工具栏做出来之前，临时放一个"默认视角"按钮。

## 后果

- 好处：边界数据缩小约四成，主线程不解析；不打开的级别不下载；默认视角在不同屏幕和布局下都完整显示江苏
- 代价：关掉再打开要重新解析；县界放大后对不齐；转换脚本依赖旧仓库里的原始文件
- 待定：倾斜时默认视角是否把俯角归零；下载失败是否提示用户
