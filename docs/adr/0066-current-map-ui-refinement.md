# 0066. 现状底图的资源操作、紧凑图例与独立底图浮窗

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0053 的工具栏、面板分组与窄屏布局，ADR 0057 的底图卡外观，ADR 0060 的已勾选区域布局；补充 ADR 0043、0044 的图例浏览与配置方式

## 背景

客户希望减少常驻操作与图例配置占用的空间，资源树和已勾选列表都能调整透明度。静态设计稿位于 `public/design.local/current-map-ui.html`，不入库；用户确认设计后明确底图独立、已勾选默认收起、复杂图例保留多色块摘要，并授权实现。

## 决定

1. 资源树里已勾选的资源、已勾选列表复用 `LayerOpacity`。入口只在行悬停、键盘聚焦或浮层打开时显示，打开状态使用主色；触屏直接显示。入口位于复选框外，按钮和浮层阻止选择、拖动事件冒泡。数值仍由 `useResourceLayers` 持有，调用既有 `setOpacity` 同步地图，不复制业务状态；沿用原数值语义，0% 完全透明、100% 完全显示，浮层两端明确标注。
2. 已勾选区域首次挂载默认收起，仅保留 40 像素的整行展开入口、数量、箭头，使用浅渐变和轻阴影；再次点击收起。展开状态只在页面缓存期间保留，不新增持久化字段，不覆盖已有分割比例。展开后沿用可拖动分割线；收起时不占分割线高度。
3. 已勾选列表左侧使用固定宽度的排序数字，悬停或聚焦手柄时换成拖动图标。排序继续使用 `useSortableList` 与上下方向键，数字随拥有者的顺序推导。取消勾选入口与透明度入口按相同规则显示。
4. 右上工具栏始终只显示图标，名称由 Tooltip 和无障碍标签给出；图例置于最下方。地图区域高度小于 648 时业务组使用两列，图例仍占末行；极矮区域允许工具列滚动，避免覆盖基础组。
5. 底图入口位于右下基础控制栏下方，使用 80 × 56 的缩略图卡，名称置于右下角，复用已有真实缩略图与按下状态。底图及行政区边界放在独立 `BasemapWindow` 中，自己登记定位避让；功能组的切换与统一关闭不影响底图。
6. 图例、区划定位、坐标定位及原有资源详情共用功能 Tab 面板。`show`（功能入口或识别开始）把对应标签移到最前；`select`（点击已有标签）只切换内容，保持顺序，避免点击目标跳位。保留单标签关闭，增加整组关闭；整组关闭逐项通知页面执行原有副作用，包括清除资源详情选择。
7. 图例按勾选资源及叠放顺序分组，年份单独显示。简单图例直接显示颜色、线型或符号；复杂图例默认显示原来的多色块摘要，由独立展开按钮查看完整内容。不会因只剩一条或重新排序而自动展开。
8. 图例浏览与配置分开：资源和分类项的样式设置由行内图标打开；全部恢复默认收进图例设置。地类默认两列平铺，仍可切回现状分类、工作分类并搜索；平铺隐藏重复分类标题和编码，完整编码、名称、含义与可调整说明放在悬停提示中。地类编辑器占满两列。
9. 图例仍从资源与符号拥有者推导，不读取或直接修改地图；透明度反映在色块和符号上，名称保持清晰。标签隐藏时保留浏览状态，卸载编辑器与取色浮层，沿用预览清理规则。

## 取舍与影响

- 未采用底图与图例共用容器：用户最终选择底图独立，允许两者同时查看
- 未删除地类的分类方式：默认平铺提高密度，仍保留原分类供核对编码
- 未把每次点击标签都当作重新打开：只在功能入口调用时前移，标签内部点击保持位置
- 沿用现有拥有者、地图样式绑定、面板外壳、拖动排序和设计令牌，不引入依赖，不改变接口或偏好格式

## 验证范围

本轮按用户要求仅运行 `pnpm build`，通过生产构建及已有产物检查。同步调整资源收起、透明度同步、图例展开、标签前移与关闭、底图独立等回归用例；未运行测试、类型检查、lint、改坏验证或启动页面服务，真实页面的交互和尺寸仍需后续验收。本次不提交。
