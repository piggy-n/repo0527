# 0090. 第三人称步行：弹簧臂相机、人物模型与暂不开放的入口

- 状态：已接受
- 日期：2026-10-27
- 落实 ADR 0078 第 6 节"第三人称和人物模型的代码一并迁移"（3D.4d-2）；补充 ADR 0086（步行意图加人称和人物模型，步行状态加人称）。入口按用户 2026-10-27 的要求暂不开放，和 ADR 0078 一致

## 背景

旧项目的第三人称在 `cesium/FirstPersonRoam.js`（和第一人称在一个类里）和 `cesium/RoamAvatar.js`：

- 相机挂在人头顶后方的"弹簧臂"上：绕的点比眼睛高 0.25 米，默认离人 4 米，滚轮、中键拖动在 1.5～8 米之间调；从绕点沿视线反方向每 0.1 米查一次导航网格的净空（`NavGrid.isFree`，四周留 0.25 米），碰到墙、柱子、顶板、地板就停在前面，被挡时立即缩短，挡的东西过去了再慢慢放回去。第一人称就是臂长为 0，切换时相机沿臂滑出、收回
- 俯仰在 -75°～25°，切到第三人称时至少俯看 18°；人走动时以每秒 540° 转向走的方向，往后走会转过身来；进站时先飞到眼睛处，落地后相机再拉出去
- 人物是 Cesium 的示例模型 Cesium Man，缩放到 1.72 米高；行走动画的相位按走过的距离推进（1.5 米一个周期），和场景时钟无关；模型只有行走动画，停下时先把这一步走完（到两腿交错的时刻）再让关节回到原始姿态；受光用和站内模型同一套头灯；相机离人 0.6～1.4 米之间淡入淡出
- 人物就挡在正前方的地面上，深度拾取拿到的是人身上的点：顺着视线穿过人物，在导航网格里找背后的表面；隔着闸机、栏杆的一律闪切（滑过去就是人从柜体里穿过去）
- 人称记在 localStorage，下次进站沿用

Cesium Man 的许可（Khronos glTF-Sample-Assets 的 `Models/CesiumMan/metadata.json`）：CC BY 4.0，© 2017 Cesium；模型上的 Cesium 标志是 Cesium 的商标。

用户 2026-10-27 选定：Cesium Man 入库并写明署名；人称切换放在步行操作条速度那一行的最前面，操作说明按人称换；人称在几次步行之间沿用，不记进偏好。之后要求第三人称做好、测试通过后暂时隐藏入口，页面上只保留第一人称。

## 决定

### 1. 会话

- `WalkRoam` 加 `view`（`first` | `third`，随时可以换）和 `avatar`（人物模型的绝对地址）；校验人称和地址
- `WalkRoamStatus` 加 `view`：视图正在用的人称，状态栏据此显示（第三人称是"第三视角 · 朝向 N°"，不写眼高）
- 新的提示 `avatar-failed`：人物模型加载失败，只报告一次，步行照常、只是看不到人

### 2. 规则（map-core `scene/nav/third-person.ts`）

- `WalkRig`：持有人称、臂长、第三人称想要的距离和人面朝的方向；`step(from, dt)` 在人挪过以后转身、伸缩臂，返回这一帧走过的距离（一帧挪了 1 米以上是闪切，不算走路）；`eye` 是相机的位置，`avatarAlpha` 按臂长淡入淡出
- `Walker` 的俯仰范围可以换（`limitPitch`）；`planMove` 按人称决定走不到的地方能不能直线滑过去
- `seeThroughAvatar`：拾取点在人身上（离脚下 0.5 米以内、地板以上 0.05～1.9 米）时沿视线找背后的表面
- `WalkCycle`：步态的相位和"把这一步走完"
- 参数都沿用旧项目；都是纯函数和不依赖 Cesium 的类，在 node 下测试

### 3. Cesium（map-cesium）

- `SceneWalk` 按 `WalkRig` 设相机；滚轮、中键拖动在第一人称改视场角，在第三人称调远近，切到第三人称时视场角回到默认；点击和遮挡判断先穿过看得见的人物
- `WalkAvatar`（`scene-walk-avatar.ts`）：每次步行一个，第一次要显示时才加载，结束步行时销毁；和站内模型共用头灯着色器（`createHeadlightShader`）；动画的相位交给 `WalkCycle`，场景时钟不走也照样播（`animateWhilePaused`）
- 模型地址由拥有者给出（随应用部署的 `roam/Cesium_Man.glb`），libs 不读 `BASE_URL`
- 键盘：焦点在单选、复选、按钮这类输入框上时照常行走，只有能打字的输入框、下拉和可编辑区域里不走。人称切换是单选按钮，原来凡是 `input` 都不走，点完切换要先点一下地图才能接着走（真实页面验证时发现）；第一人称同样适用

### 4. 拥有者与界面

- 拥有者的 `setWalkView`：人称在几次步行之间沿用（同速度），不记偏好
- `RoamBar` 的人称切换（第一人称 | 第三人称）在速度那一行最前面，由页面通过 `personSwitch` 决定显示；操作说明按人称：第三人称是"右键拖动旋转视角 · 滚轮 / 中键拖动调远近"
- **入口暂不开放**：现状底图页不传 `personSwitch`，页面上只有第一人称。开放时页面传上即可；开放前按设计规范在 `/dev/map-3d` 补上切换，由用户确认
- `public/roam/Cesium_Man.glb`（约 490 KB）入库，同目录的 `CREDITS.txt` 写明来源、许可和商标，随产物部署

## 后果

- 好处：第三人称和第一人称共用 `Walker`、导航网格和点击规则，换人称只换相机的挂法；规则在纯函数里，入口隐藏期间由单元测试和浏览器测试保持可以运行（ADR 0078 的代价）
- 代价：仓库多了一个约 490 KB 的二进制文件；入口隐藏期间第三人称不经过用户的界面验收
- 开放前要解决（2026-10-27 真实页面验证时看到）：默认的臂长和俯角下，人物的腿被下方居中的步行操作条挡住；Cesium Man 的原始姿态是双臂平伸，停下时站成这个姿势（旧项目同样如此）
- 待定：何时开放入口；人称是否记进偏好；有显卡的机器上第三人称的手感（臂长、转身速度、拉近时的淡出）
