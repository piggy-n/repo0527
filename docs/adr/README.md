# 架构决策记录（ADR）

一个重要决策写一份 ADR，记录当时的背景、考虑过的方案和最终选择的理由。查现在有效的结论先看[总览](overview.md)，本文是完整的索引。

- 只记难回退、跨模块的决定。取值调整写进配置说明，界面细节写进设计文档，不单独写 ADR（ADR 0142）
- 文件名：`NNNN-简短标题.md`，编号递增，不复用
- 状态：提议中 → 已接受；以后被新决策替代时改为「已被 NNNN 取代」
- 接受后正文不再修改，只允许更新状态行；文件移动时可以修路径，其他内容不动（ADR 0142）
- 新写或修正一份 ADR 时，同步总览或[地图架构总览](../modules/map-overview.md)对应的一行
