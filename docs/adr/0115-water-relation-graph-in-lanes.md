# 0115. 自助取数的水资源关系图按数据成果分泳道，其他资源沿用旧版知识图谱

- 状态：已接受
- 日期：2026-10-29
- 修改：ADR 0089（水资源的检索不再用 ECharts 力导图，其他资源不变）

## 背景

用户反馈自助取数第二步的知识图谱"节点关系不够明确、节点文字不清晰"。业务梳理了水资源在四类数据成果之间的分类和数据表：用地用海分类、国土调查、城市国土空间监测、水资源基础调查（丰水期、枯水期）。新的要求：

1. 建立不同数据成果之间的分类对应、层级归属和关联关系，以后能扩展到其他资源
2. 区分分类对应、上下级、字段映射、空间关联、时序关联，不能所有节点直接连线
3. 用分组、颜色、线型和关系文字说明数据来源、层级和联系
4. 按数据成果筛选，展开、收起节点，点击查看关联节点和关系详情
5. 统一字号、对比度、间距和缩放效果
6. 先用水资源里已经明确的关系演示；没有明确的对应不自行假定，预留补充的方式

旧版关系图（ADR 0089）的问题：坐标来自力导布局，位置本身没有含义；上下级画成带箭头的线，占了八成连线；关系只有"包含、对应"两种，文字只在悬停时出现；两套分类体系写死在节点类型、7 类图例和左右两个扇形布局里，加第三个数据成果要改四处。

## 候选方案

1. **在 ECharts 力导图上加节点类型和颜色**：位置仍然没有含义；四个数据成果放不进左右两扇；泳道背景、展开按钮在 ECharts 的漫游缩放下跟不上节点
2. **以资源概念为中心**（如"河流水面"连到四个数据成果）：需要跨成果的对应（130A01 河流、HL_FS 和 1701/1101 的关系），业务没有给出，违背第 6 条
3. **按数据成果分泳道，Vue 渲染卡片、SVG 画线**

2026-10-29 用方案 3 做了可操作原型，用户确认，并调整：默认画出全部关系；不要"资源类别"下拉框；界面上不出现数据来源表格、"依据"之类的说明；节点详情不列待补充事项；"适配全图"不用房子图标；水资源以外的资源沿用旧版知识图谱。

## 决定

采用方案 3。

- **数据**：`extraction/water-relations.json`，一个资源类别一份：数据成果 → 分类树（最多三级）→ 数据表（字段可以缺）。关系只写跨节点的四种：分类对应、时序关联、字段映射、空间关联；上下级由分类树表示，不另写。zod 校验，测试检查编号、两端存在、不重复，分类对应跨数据成果、时序关联在同一数据成果内。没有给出的关系不写；以后补一条记录，图上和图例会自动出现
- **选图**：检索词在水资源关系图里有命中，并且旧图谱的命中也都在水资源范围内，就用新的关系图，否则沿用旧版（`chooseExtractionGraph`）；第一步加"按资源类别：水资源"，直接打开全部节点
- **布局**：每个数据成果一条泳道（宽 200～300，间隔 40），顶边是成果的颜色；分类按层级缩进，下级左侧一条细竖线，不画上下级的线；数据表在泳道底部。卡片里写"编码 名称"：编码 12 号次要色、名称 14 号（一级类 600），文字不压线、不隐藏，太长时折行
- **关系线**：分类对应用实线、时序关联用点线，字段映射、空间关联预留短划线和点划线；颜色和线型一起区分，配色属于图表，放在 `relation-style.ts`。跨泳道的线连在卡片边缘之间；同一泳道的弧线画在右侧，逐条外扩。被收起的一端挂到最近的可见上级，同一对节点合成一条、线加粗。全部关系默认都画；悬停或键盘聚焦时相关的卡片描出关系色、线加粗并显示关系名称，其余线变淡，文字不变淡
- **交互**：数据成果的勾选标签、图例里的关系类型开关（没有数据的类型显示"待补充"，不能打开）、展开收起、检索标签（只显示命中节点、上下级和有关系的节点）、拖动空白处平移、Ctrl + 滚轮和图例栏右端的按钮缩放（60%～160%，整体缩放）、适配全图（四角图标，旧版同步更换）。详情列出层级、关联关系、下级分类的关系、下级、数据表字段和所属成果的数据表，点关联的节点在图上定位过去
- **实现**：视图推导（泳道、可见节点、合并关系）和线形是纯函数；连线位置从 DOM 量出（沿 offsetParent 累加，不受缩放的 transform 影响）；状态由 `useRelationGraph` 持有
- **弹窗**：水资源的第二步放宽到 1440，其他资源仍是 1180

## 后果

- 两套图并存：旧版 ECharts 关系图和 d3-force 布局继续用于其他资源，ADR 0089 对它们仍然有效
- 不能拖动单个节点：位置本身表示所属的数据成果和层级
- 卡片是按钮，可以用 Tab 聚焦，聚焦时同样突出相关的节点和关系
- 同一泳道里成对交错的时序弧线（丰水期 ↔ 枯水期）会互相交叉，悬停或选中时突出其中一条
- 增加资源类别：加一份同样结构的 JSON，在选图规则里登记；字段映射、空间关联需要的附加信息（如字段对）等有数据时再定
- 选中的节点照旧作为取数节点写进提交快照，取数条件不随数据表联动：取数接口确定后再做
