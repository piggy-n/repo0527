# 0069. 底图与行政区 Popover 的显示和关闭规则

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0068 的自动关闭与内部滚动规则

## 背景

用户反馈两个 Popover 出现滚动条，要求底图选项名称放在缩略图右下角，图标选中状态与功能开关一致，并且只通过关闭按钮关闭底图和行政区浮层。

## 决定

1. 继续复用 `MapOptionsPopover`、`BasemapPanel` 和 `BoundaryPanel`。去掉内容区的高度上限及内部滚动，按实际内容撑高；行政区选项在窄屏继续换行，透明度行展开也完整显示
2. 底图选项的简称叠在缩略图右下角，沿用底图入口的背景和圆角令牌，选中时使用主色底、反白文字，保留描边与选中勾
3. `ElPopover` 的 `visible` 仍由页面拥有者控制；只接受组件发出的打开请求，忽略外部点击、入口再次点击、失焦和 Esc 的关闭请求，由关闭按钮明确关闭。页面停用与窄屏左右排斥继续按原生命周期处理
4. 透明度入口使用独立选中类和 `aria-pressed` 绑定功能状态，不依赖嵌套 Tooltip 会改写的 `aria-expanded` 控制外观；行政区入口继续使用工具栏原有的按下状态
5. 资源行透明度继续遵守鼠标移出 2 秒关闭、滚动立即关闭的规则，按钮仍随资源行悬停或键盘焦点显示

## 取舍

保留 Element 的定位、箭头和键盘打开能力，通过已有状态接口限制关闭来源，不另造浮层。内容较少且布局紧凑，取消内部滚动而非隐藏滚动条或裁掉内容。

## 验证

补充关闭按钮、外部点击、重复点击入口、Esc 和透明度图标状态的回归用例。`pnpm build` 与产物检查通过；按用户要求未运行测试或启动页面服务，实际页面效果待验收。
