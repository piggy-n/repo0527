# 0146. 底图面板默认只有切换按钮，标注改成页面操作，浮层可以点外部和 Esc 关闭，三维画文字

- 状态：已接受
- 日期：2026-11-05
- 修改：ADR 0069 第 3 节（外部点击和 Esc 不关闭、只靠关闭按钮关闭）；ADR 0134 第 1 节的 `labels` 开关（`cityColors` 不变）；ADR 0080 第 1 节和 ADR 0133 后果里"三维不画 `symbol`"；补充 ADR 0140 的偏好清单

## 背景

用户 2026-11-05 提出重新设计底图切换，保持简洁：取消顶部常驻的透明度和关闭按钮但保留功能；选了底图自动关闭，再点入口也关闭；保留透明度，新增标注显隐；内网静态底图的地名不再靠改代码开关。看过第一版原型后又明确：打开面板时只有切换按钮，面板高度就是缩略图加边距，标注和透明度不算必要功能，点开才有；入口放在当前缩略图的角上。

几个决定是一起定的，因为它们互相牵连：没有了 ×，关闭只能靠别的途径；标注的默认值公网和内网不同；内网只有静态底图，它的地名是 `symbol` 图层，而 Cesium 一直不画 `symbol`，不补的话内网三维里这个开关没有作用。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 标注和透明度放哪 | 面板里常驻两行；缩略图右边一个竖向入口；当前缩略图角上的入口 | 角上的入口（用户选）：面板看起来只有三个按钮，缩略图保持 90 宽。右边的入口更不容易误点，但缩略图变窄到 77，内网还多空一格。入口紧贴"点了就关闭"的缩略图，误点的代价只是关闭面板 |
| 点外部、Esc | 不关闭（ADR 0069）；关闭 | 关闭：没有 × 之后要有顺手的关闭方式，两个浮层也不会同时开着互相压住。拖动和滚轮缩放地图不算点外部：边调边看是调透明度的主要用法 |
| 点外部怎么判断 | Element 的自动关闭；VueUse 的 `onClickOutside`；自己写 | 自己写（`useLightDismiss`，约 40 行）：Element 的关不掉拖动（ADR 0069 已经忽略它的请求），`onClickOutside` 没有拖动的容差，MapLibre 拖动后吞掉 click、Cesium 不吞，行为不一致 |
| 标注的状态 | 每种底图各记一个；全局一个 | 全局一个：切换二三维时底图会自动换（ADR 0078），各记一个的话在二维关掉，到三维又出现了 |
| 标注的默认值 | 都开；都关；公网开、内网关 | 公网开、内网关：公网和以前一样，内网沿用 ADR 0134 的默认关闭；两种底图不会在同一次部署里同时出现 |
| 记不记住 | 不记；并进 `basemap`；单独一项 | 单独一项 `basemap-labels`，默认打开：用户明确要 `VITE_PREFERENCE_BASEMAP` 保持关闭（ADR 0140），标注又不该每次重新打开 |
| 标注的状态和底图的状态放一起吗 | 同一个 `shallowRef`；分开 | 分开：`usePreference` 把恢复之前状态变化当作用户操作过，放一起时一项恢复会让另一项放弃恢复 |
| 内网三维的地名 | 给 Cesium 补文字；三维里把开关置灰 | 补文字：用户要二三维都能用，内网又只有这一种底图。约 100 行，走现有的覆盖物推导；三维引擎还在评估，换成 MapLibre 的话这段不再需要，代价可以接受 |
| 文字怎么画 | Entity 的 `label`；单独的 `LabelCollection`；画成图片 | Entity：和现有的线、面、点走同一条路（增删改、留到新的画好再移除）。不做避让：Cesium 没有现成的，地名一百多个 |
| 行政区浮层 | 保留操作栏；一起去掉 | 一起去掉（用户确认）：两个浮层共用外壳。复用现状底图功能标签里的 `BoundarySettingsPanel`，透明度入口和勾选同一行，不另做一套 |

## 决定

### 1. 底图面板

- `MapOptionsPopover` 没有操作栏和透明度，只有外壳：四周留 12，高度由内容决定。底图面板收起时高 86（缩略图 60 + 内边距 24 + 边框 2）
- 当前缩略图左上角 20 × 20 的入口点开标注和透明度两行，再点收起；无底图没有入口。面板接收 `active`，不显示时收起，每次打开都是收起的，调过的值在拥有者里
- 点缩略图选中并关闭，包括点当前这张；关闭后焦点回到入口
- 外壳自己监听内容的尺寸并重新定位：Element 的监听只在 `visible` 变化时开始，`persistent` 为 false 时内容挂载时已经可见，监听不会开始。窄屏时浮层按顶部定位，不这样做的话展开后底部超出视口；宽屏时按底部定位，位置没错，但报告给右侧面板的顶部是旧的

### 2. 关闭

- `useLightDismiss`：浮层显示时在 `document` 的捕获阶段监听。单击外部关闭，按下到松开移动超过 4 像素算拖动，不关闭；从浮层里按下、拖到外面松手不关闭；按键触发外部的按钮也算点击
- Esc 关闭并 `stopPropagation`：当前工具不会同时结束；焦点回到入口
- 再点入口、页面停用照旧关闭；窄屏让给另一边时浮层不显示，这时不监听

### 3. 标注

- `useBasemap` 多了 `labelsVisible`、`setLabelsVisible`。关闭时 `basemap-labels` 分组是空的，推导函数是 `labelsGroup(state, visible)`，不读全局状态
- `STATIC_BASEMAP_OPTIONS` 只剩 `cityColors`，`staticLabelsGroup(opacity)` 不再有开关
- 偏好 `basemap-labels`：版本 1，值是布尔；开关 `VITE_PREFERENCE_BASEMAP_LABELS`，`.env` 是 `true`。使用 `useBasemap` 的业务页都传范围，标注的显隐在页面之间共用；底图偏好的开关打开时，这些页面也会一起记住底图

### 4. 三维的文字

- `symbol` 图层有 `text-field` 时进覆盖物，推导出 `LabelShape`（位置、文字、大小、颜色、描边），和引擎无关；只有图标的 `symbol` 仍然报告为不支持
- `CesiumScene` 画成 Entity 的 `label`：字体取画布容器继承的 `font-family`，描边宽度是 `text-halo-width` 的两倍（画布的描边一半在字里面）；深度测试用默认值，相机倾斜时不被地球切掉，漫游时会被模型挡住
- 跨级重新推导时文字和样式没变就不重建；透明度变了要重建，走"留到新的画好再移除"

## 后果

- 公网的行为有一处变化：选底图后面板关闭，要连续比较几种底图时要多点一次
- 改了 ADR 0069 的决定：点外部和 Esc 会关闭。`docs/design/current-map-reference.md` 的已确认细节同步更新
- 两个浮层不再同时打开，ADR 0128 记下的"展开透明度后会压住一段"不再出现（键盘操作也按点击处理）
- 其他地图页接了偏好范围（只有 `basemap-labels` 生效）：`VITE_PREFERENCE_BASEMAP` 打开时，这些页面也会记住底图。页面缓存打开时（`VITE_PAGE_STATE_RESET=false`），缓存着的页面不会跟着别的页面改的标注变，回到页面时还是自己的状态
- 三维的文字没有避让，级别低、区县密集时会重叠；区县 8.5 级才出现，和二维相同。真实显卡上的效果没有实测（开发机只有软件渲染）
- 字体不入库不影响地名：只有汉字，二维用 `localIdeographFontFamily`，三维用画布，都不请求字形（`static-basemap.test.ts`、生产冒烟检查）
- 测试：`useLightDismiss.test.ts` 覆盖单击、拖动、拖出、按键、Esc、作用域结束；`BasemapPanel.test.tsx`、`BasemapCard.test.tsx` 覆盖收起展开和关闭；`basemap-preference.test.ts` 覆盖两项偏好互不干扰；`overlay-plan.test.ts`、`overlay-update.test.ts`、`cesium-scene.browser.test.ts` 覆盖文字的推导、就地更新和真实 Cesium 上的像素；`static-basemap.spec.ts`、`application.spec.ts` 在生产构建上验证二三维的地名和偏好
