# 0063. 地图页的页面缓存：KeepAlive 加路由 meta，停用期间暂停视图

- 状态：已接受
- 日期：2026-10-16
- 补充 ADR 0053 第 4 节（面板内容在隐藏时 `active` 为 false：页面停用也算隐藏）；视图的暂停沿用 ADR 0024、0026 的生命周期，相机操作在暂停期间等待沿用 ADR 0039 第 3 条

## 背景

旧项目的布局用 `<keep-alive :include>` 缓存后端菜单标了 `cacheable` 的页面，地图组件只在 `onActivated` 里调用一次 `resize()`。新项目现在不缓存：从文件管理等页面回到现状底图时，地图页重新创建，相机、勾选以外的状态（点选结果、测量、打开的面板、区划选择、图例的浏览位置）都丢了。勾选的资源、底图、边界有偏好（ADR 0042），重建时能恢复。

### 实测（2026-10-16，现状底图在本地临时包一层 `KeepAlive`，不提交）

在真实后端上（应用内浏览器里已有的会话）：

- **尺寸**：停用时 Vue 把页面的 DOM 移进不在文档里的容器，MapLibre 自己的 `ResizeObserver` 随即把画布缩成 0×0，视图仍是 `ready`，还发出过一次画面稳定。恢复时画布回到原来的尺寸，地图正常
- **隐藏期间的相机操作**：区划定位里点"南京"后立即切走，定位在隐藏期间执行。回来时相机停在 7 级、南京在整块画布的中央：`fitBounds` 按 0×0 的画布和量不到的悬浮元素算出了错误的级别和边距
- **全局按键**：document 上只有图钉拖动中的 Esc 监听，其余按键都在画布上或只在拖动期间监听，在别的页面按 Esc 不影响地图
- **弹出层**：批量设置年份的下拉、图例编辑器的取色器打开时用浏览器后退切走，弹出层都自己收起，别的页面上没有残留，回来时也不重新弹出；但取色器被动收起时会不会报告"取消预览"没有验证（ADR 0044）
- **保留的状态**：相机、区划选择、两组面板和 Tab、图例展开的位置、正在编辑的地类、行内展开的透明度滑块都在

用 Playwright 驱动无界面的 Edge、本地的假后端（资源目录为空），地图 → 文件管理 → 地图，各 3 次：

| | 回到地图后到视图就绪 | 到画面稳定 | 离开地图后的 JS 堆（强制回收后） |
|---|---|---|---|
| 不缓存（重建） | 约 30 ms | 约 550 ms | 14 MB |
| 缓存 | 恢复即就绪 | 约 10 ms | 16 MB |

重建的时间里没有资源图层的瓦片（假后端没有目录），真实页面勾选了资源时更长；缓存时多留一个 WebGL 上下文和它的瓦片纹理，显存没有量。

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 要不要缓存 | 缓存；不缓存，回来时按偏好和会话状态恢复 | 缓存：重建要重新加载样式、瓦片，点选结果、测量、面板、区划选择要另存再恢复，而且每加一种状态都要记得存；缓存只多约 2 MB 的 JS 堆和一个 WebGL 上下文 |
| 怎么指定缓存的页面 | 布局里常驻 `KeepAlive`，路由 meta 写 `keepAlive: true` 的页面放进去；`include` 写组件名（旧项目）；把地图常驻在路由外面、用样式隐藏 | 路由 meta：和页面权限一样写在路由上（ADR 0015），`routes.test.ts` 能检查；组件名要和路由对上，改名时容易漏；常驻地图要绕开路由，和页面按需组装（ADR 0027）冲突 |
| 停用期间视图怎么办 | 暂停视图；什么也不做、恢复时调用一次 `resize()`（旧项目） | 暂停：隐藏期间的定位等到恢复后再执行（实测里落错了位置），工具收不到输入，不发出画面稳定；暂停和恢复本来就是视图接口的一部分（为二三维切换准备） |
| 恢复时的尺寸 | 恢复时先按容器的实际尺寸调整画布；关掉 MapLibre 自己的尺寸监听、隐藏时不缩成 0×0 | 先调整：MapLibre 的 `ResizeObserver` 要到下一帧才量到恢复后的尺寸，恢复后立即执行的定位仍会按 0×0 算；不缩成 0×0 要自己接管尺寸监听，而缩小带来的代价实测只有约 10 ms 的重绘 |
| 停用期间的临时交互 | 按"面板隐藏"处理：面板内容的 `active` 为 false；不处理 | 按隐藏处理：取色预览、坐标拾取、图例编辑器的结束规则已经由 ADR 0053 的 `active` 测过，页面停用时复用，不在每个内容里另写 |

## 决定

### 1. 缓存的页面

`AppLayout` 的 `RouterView` 里常驻一个 `KeepAlive`：路由 meta 写了 `keepAlive: true` 的页面放进 `KeepAlive`，其余页面照常渲染在它外面。`KeepAlive` 里只会出现标了 `keepAlive` 的页面，缓存的数量不会超过它们的个数，不另设上限。

- 现在只有现状底图标 `keepAlive: true`；以后的页面需要时在路由上加（旧项目的城市国土空间监测指标页也缓存，阶段六迁移时再定）
- `keepAlive` 写进 `RouteMeta` 的模块扩充；`routes.test.ts` 列出缓存的页面，修改时同步更新
- 布局卸载时缓存跟着清空：登录页、404 不在布局里，退出、会话过期、别的标签页退出都会跳到登录页，缓存的地图页随之卸载，释放会话和视图；之后再登录（包括换了用户）得到的是新的地图页

### 2. 停用期间的地图页

- **视图暂停**：`MapCanvas` 在页面停用时暂停视图，激活时恢复。暂停期间上下文的 `view` 为 null，相机操作等视图恢复后再执行，工具收不到输入，鼠标位置清空，不发出画面稳定
- **恢复时先调整尺寸**：视图恢复显示时，先按容器的实际尺寸调整画布，再追赶样式、同步相机、进入 `ready`（map-core 的 `MapLibreView.resume`，二三维切换以后同样用得上）
- **面板内容按隐藏处理**：页面停用期间，两组 Tab 面板给内容的 `active` 为 false：结束坐标拾取、丢弃取色预览、图例卸载条目（浏览位置按 5D 的修复保留）；激活后按原来的 Tab 恢复
- **拖动中的图钉**：页面停用时取消，和按 Esc 一样回到拖动前的位置
- **其余状态全部保留**：相机、资源图层、点选的结果和选择、测量（包括画了一半的）、打开的面板和 Tab、当前工具、区划选择。隐藏期间晚到的结果（识别、区划边界）照常写入，需要移动相机的等恢复后执行

页面停用、激活用 Vue 的 `onDeactivated`、`onActivated`；`shared/composables` 加 `usePageActive()` 给 shared 和 feature 的组件用，map-vue 的 `MapCanvas` 直接用这两个钩子。

### 3. 验收

- 单元测试：路由 meta 决定哪些页面进 `KeepAlive`（同一个页面实例在切走再回来后仍在）；退出后再登录是新的实例；`MapCanvas` 停用时暂停、激活时恢复；`resume` 先调整尺寸；面板内容在页面停用时 `active` 为 false；图钉拖动中停用时回到原位
- 真实页面：切到文件管理再回来，相机、勾选、点选结果、测量、面板、区划都在，地图不闪；区划定位刚开始就切走，回来后正确定位到区划并避开面板；取色器拖动中切走，回来后地图上没有残留的预览；框选、分割线、排序拖动中切走（键盘或浏览器的前进后退），回来后没有残留；退出再登录后地图页是新的

## 后果

- 好处：回到地图约 10 ms 画面就稳定，所有状态保留，不用逐项另存
- 好处：页面停用复用已有的两套规则（视图暂停、面板隐藏），没有新的状态
- 代价：离开地图后多占约 2 MB 的 JS 堆和一个 WebGL 上下文（含瓦片纹理）；会话期间常驻
- 代价：缓存的页面里，查询（如资源目录）的观察者在后台照常工作；数据不变时没有额外开销
- 约束：`KeepAlive` 按组件类型缓存，两个标了 `keepAlive` 的路由不能共用同一个页面组件
