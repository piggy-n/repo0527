# 0110. 驾驶舱的菜单入口：查询统计 → 专项统计，新标签页打开

- 状态：已接受
- 日期：2026-10-29
- 修改：ADR 0077（驾驶舱"无菜单入口"）

## 背景

驾驶舱迁移时沿用旧项目，只能直接访问 `/city-dashboard`，没有菜单入口（ADR 0077）。用户 2026-10-29 要求在"查询统计 → 专项统计"下新增"驾驶舱"，接入现有模块。

驾驶舱是独立的大屏布局（不在 `AppLayout` 里），页面上没有回到应用的入口。

## 候选方案

| 方案 | 问题 |
|---|---|
| 当前标签页跳转 | 进去以后只能靠浏览器的后退回来；大屏通常单独开着 |
| 当前标签页跳转，驾驶舱加"返回" | 要改已验收的大屏标题区 |
| 新标签页打开 | 当前页面保持不变；会话存在 localStorage，新标签页直接是登录状态 |

选新标签页打开。

## 决定

- `menus.ts` 的导航页面加可选的 `newTab`；"专项统计"最后加 `{ label: '驾驶舱', route: RouteName.cityDashboard, newTab: true }`
- 宽屏下拉里新标签页的页面渲染为普通 `<a href target="_blank" rel="noopener">`（`RouterLink` 没有声明 `target`），点完关上面板；窄屏菜单用 `window.open(href, '_blank', 'noopener')`
- 驾驶舱的路由、权限（全部登录角色）、独立布局和懒加载都不变；它不在 `AppLayout` 里，导航上不会显示为当前页

## 后果

- 测试：宽屏下拉里驾驶舱是新标签页的链接，窄屏菜单点它调用 `window.open`、当前页面不跳转；去掉 `newTab` 时两项都以断言失败
- 应用内置浏览器的窗格不能开新窗口，会在当前标签页打开；普通浏览器是新标签页
