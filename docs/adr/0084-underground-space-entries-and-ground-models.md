# 0084. 地下空间时隐藏不适用的入口；钻地时隐藏地面上的模型；徐州倾斜摄影

- 状态：已接受
- 日期：2026-10-27
- 补充 ADR 0053（地图页的区域）、ADR 0083（漫游时选工具退出）；修改 ADR 0081 第 6 节"钻地时隐藏白膜"

## 背景

用户 2026-10-27 提出：进入地下空间时自动隐藏地图工具栏、底图切换按钮等不适用的功能入口，退出后恢复显示，原有功能及状态不受影响。先在原型 `/dev/map-3d` 里做出来，用户确认，并选定：

- 视图控制保留放大、缩小、指北针和 2D/3D，隐藏默认视角
- 进入时正在用的工具（测距、测面、点选）切回移动，退出后不恢复
- 当前区划条一起隐藏
- 先提交 3D.4a（`cf0060c`），再单独做这一步

同时用户要求真实页面再加一个徐州市的 3DT。旧项目 2026-10-27 的 `b4f3987`（"添加徐州模型"，在 3D.3 的基线 `6b4799b` 之后）加了 `public/XZ_GC_3DT`：用 `tools/osgb-to-3dtiles` 把 OSGB 倾斜摄影转换成 3D Tiles，1.4 GB、1085 个瓦片，位于徐州市区（117.1807°E, 34.2657°N），包围球半径约 210 米；高度保留原始的 41.112 米、不贴地；钻地期间暂时隐藏（"地面模型会挡住站内漫游"）。数据里没有名称，旧界面只写 XZ_GC、"徐州3DT"。

## 决定

### 1. 什么是地下空间

- 三维、拥有者的钻地不为空；漫游地下的模型时进入钻地（ADR 0083 第 4 节），所以也算
- 由页面推导（`undergroundSpace`），不放进会话：只影响界面的排布；切到二维时页面结束钻地（ADR 0081 第 6 节），所以不另外判断二三维

### 2. 隐藏与保留

| 入口 | 地下空间时 | 原因 |
| --- | --- | --- |
| 业务工具栏（移动、点选、测距、测面、区划定位、坐标定位、行政区、图例、清除） | 不渲染 | 三维不识别点选；测量、定位、边界都作用于地表，地表这时是半透明的；定位会飞离模型 |
| 功能面板组 | `visible` 为 false，打开的功能、当前标签和内容都保留，内容按隐藏处理（`active` 为 false） | 同上 |
| 底图卡片与浮层 | 不渲染；浮层是否打开由页面的状态保留 | 地表半透明，换底图看不出来 |
| 当前区划条 | 不显示，所选区划不变 | 区划只裁剪二维资源和地表 |
| 默认视角 | 不显示 | 会飞到全省、离开模型 |
| 放大、缩小、指北针、2D/3D | 保留 | 相机仍然可用；2D 也是退出地下的入口 |
| 三维模型面板、钻地条、漫游操作条、状态栏 | 保留 | 地下用到的就是它们 |
| 查询详情 | 随工具切回移动关闭，和二维里点"移动"一样 | 详情属于点选工具 |

隐藏只是不显示，各项状态仍由原来的拥有者持有，退出后按原样显示。基础组的 `MapViewControls` 加 `defaultView`（默认显示）。

### 3. 当前工具

- 进入地下空间时切回移动：测量中的这一笔结束，画好的结果保留；退出后停在移动
- 漫游时换成移动以外的工具才退出漫游（ADR 0083 原来是工具一变就退出）：正在测距时开始漫游地下的模型，进入地下空间切回移动，不能把刚开始的漫游退掉

### 4. 钻地时隐藏地面上的模型

- ADR 0081 第 6 节只在钻地时隐藏白膜，改为隐藏所有不在地下的模型（白膜、倾斜摄影、地面上的室内模型）：都会挡住地下空间，和旧项目隐藏 XZ_GC 一致

### 5. 徐州倾斜摄影

- 清单加 `xz-gc`：名称暂定"徐州倾斜摄影"，`cityCode` 是 320300，`kind` 是 `oblique`，地面上，`tileset` 是 `XZ_GC_3DT/tileset.json`；数据按 ADR 0081 从旧仓库复制、不入库
- 高度和旧项目一样按数据，不贴地；瓦片集参数用现有的（和旧项目的只差缓存大小）
- 加一个测试：入库的清单通过校验、地址都在 `3dt/` 下、路线有长度

## 后果

- 好处：地下只留下可用的入口；隐藏不改各拥有者的状态，退出后原样恢复
- 代价：地下时不能直接测量、定位，要先退出钻地；漫游地下的模型时工具栏不在，"选工具退出漫游"只对地面上的模型有意义
- 构建会把 `public/3dt` 下的数据复制进产物，徐州的 1.4 GB 让本地构建变慢、产物变大；数据和应用分开部署以后再定
