# 0067. 地图浮窗间距、透明度入口与图例对齐

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0066 的资源操作显隐、右侧浮窗排布及底图透明度入口

## 背景

用户在实际页面发现透明度浮窗关闭后入口残留、浮窗与工具栏间距过大、复杂图例和普通图例的符号及文字未对齐，并要求底图浮窗与基础控制条等高。此次按截图直接修正，不改地图状态拥有者。

## 决定

1. 已勾选区域的整行展开入口去掉自身阴影，保留原浅渐变和数量
2. 资源透明度入口只随对应行悬停显示；键盘的 `:focus-visible` 和触屏保留可操作入口。鼠标点击留下的普通焦点、浮窗打开状态不维持入口可见，打开状态仅改变配色；两处继续复用 `LayerOpacity`
3. 页面浮层共用三行网格：上方功能区、基础控制区、底部入口。浮窗与对应工具之间使用 `--space-md`（12 像素），业务工具列按实际 40 / 72 像素分配，80 像素的底图卡不再撑宽工具列
4. 功能浮窗仅占第一行，底边不超过基础控制区上沿，并保留 12 像素间距；内容过多时在浮窗内部滚动。底图浮窗位于基础控制条左侧、缩略图入口上方，与控制条底边对齐；高度直接通过 `useShownElementSize` 读取控制条，避免重复维护按钮尺寸
5. 底图及边界透明度滑块默认隐藏，由底图浮窗头部的透明度图标统一展开、收起。显隐不改变数值，关闭再打开浮窗恢复收起状态；原 `BasemapPanel`、`BoundaryPanel` 接收 `showOpacity`，继续使用原滑块和拥有者
6. 图例的单一符号和多色摘要共用 28 × 20 展示区域；名称、年份、修改标记、箭头和配置按钮各有稳定位置，缺少修改标记或展开功能时保留相应位置。图例设置和行内配置按钮对齐，编辑器的内边距、控件列宽及行高统一

## 验证范围

补充鼠标关闭后移出资源行时隐藏入口、底图透明度显隐保留数值及重新打开默认收起的用例。`pnpm build` 及已有产物检查通过；按用户要求未启动服务、未运行测试或改坏验证，真实页面验收仍由后续确认。本次不提交。
