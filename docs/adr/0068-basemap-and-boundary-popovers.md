# 0068. 底图与行政区独立 Popover

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0066、0067 的底图容器、行政区入口及功能面板高度上限

## 背景

用户要求将行政区从底图中拆出，在右上工具栏图例上方提供独立入口；底图和行政区都改为按钮左侧带箭头的 Popover，多标签功能面板可延伸至基础工具栏底部。

## 决定

1. 使用 Element Plus `ElPopover`，与已有资源透明度浮层保持一致；新增公共外壳 `MapOptionsPopover`，复用 `MxTitle`、项目图标和间距令牌，不再嵌套 `MxPanel`。固定定位、左侧弹出、间隔 12、宽 320；窄屏限制宽度，矮屏内容内部滚动
2. 底图与行政区分别使用原有 `BasemapPanel` 和 `BoundaryPanel`，原拥有者、地图分组推导及偏好保持不变。各自有透明度图标和关闭按钮，透明度默认收起，重新打开恢复收起但保留数值。由 Element 处理入口切换、点击外部和 Esc 关闭
3. 工具栏新增「行政区」，紧接在「图例」上方，使用与现有工具一致的 20 像素线性图标。`MapToolbar` 提供动作名插槽，页面把原按钮作为 Popover 入口，保留原有 Tooltip 与按下状态
4. 底图按钮位置和缩略图保留，点击后在按钮左侧显示底图 Popover。移除旧 `BasemapWindow` 和读取控制条高度的逻辑
5. 多标签功能面板跨页面网格的前两行，最大高度到右下基础工具栏底部；与底图按钮和状态栏仍留 12 间距。增加一个工具按钮后，单列切换双列的高度阈值由 648 调至 680，行政区和图例各占末尾一行
6. 两个 Popover 分别登记右侧定位避让，页面停用时关闭。窄屏的 `rightOpen` 同时考虑功能组、底图和行政区。关闭功能组不清空底图或边界选择
7. 已勾选入口使用「展开」「收起」短文案，无障碍名称仍保留完整功能名称

## 验证

同步入口顺序、底图与行政区拆分、独立透明度、关闭重开保留数值及矮屏阈值的用例。`pnpm build` 和产物检查通过；按用户要求未运行测试、类型检查、lint 或页面服务，真实页面效果待验收。
