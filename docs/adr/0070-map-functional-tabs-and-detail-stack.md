# 0070. 行政区功能标签、独立详情与右侧面板排布

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0053、0066、0068、0069 的分组、详情归属与底图开关规则

## 背景

用户确认：行政区并入图例、区划定位、坐标定位所在的功能标签容器，查询详情拆成独立面板；右上工具栏按类型分组，底图仍在右下角。功能与详情同列上下排列，高度不足时收起非当前内容，底图打开时预留空间。先提交上一轮实现，再修改。

## 决定

1. 复用 `usePanelGroup` 与 `MapPanelGroup` 管理四个功能。入口打开时标签前移，当前标签再次点击入口关闭；后台标签或收起状态下点击入口只切回并展开。单标签关闭与整组关闭均不影响底图、详情或边界勾选值
2. `FeatureDetailWindow` 用 `MxPanel` 包裹原 `FeatureDetailPanel`，独立收起、关闭和登记地图避让。识别开始只打开或展开详情，不切走功能标签；收起保留结果与高亮，关闭调用原 `pick.close()`。切出点选工具、取消资源等原有清理条件保留
3. 右侧两块面板同宽 320、上下间隔 12。只有一块时可使用整列；两块都展开时功能最多占可用高度的 40%，详情使用剩余空间，头部固定、内容滚动。可用高度小于 500 时，最近操作的内容展开，另一块保留 48 高标题条。手动收起与尺寸推导分开，自动收起不清空状态，恢复空间后自动恢复
4. 底图 `MapOptionsPopover` 保留入口左侧 12 的箭头浮层；入口再次点击或关闭按钮可关闭，点击外部、失焦、Esc 不关闭。入口的键盘点击和鼠标点击走同一个开关，忽略 Element 的自动显隐请求
5. Popper 在定位写入后报告浮层实际顶部，包含透明度行展开、视口变化带来的新位置；上方面板列的可用高度止于其上方 12。外部网格边界不随内部面板压缩，避免尺寸反馈。布局计算在 `panelStackHeight`、`panelStackLayout`，临时收起状态在 `usePanelStack`
6. 工具栏从上到下分为地图操作、测量、定位、显示辅助、清理五组。清除按钮说明为「清除测量与定位标记」，仍只执行原有操作。单列宽 40、按钮高 32；增加分隔线后双列阈值为地图高度 692，两列时完整分组排列、清理独占末行
7. 当前工具实心主色；当前显示的功能入口浅主色底；已打开但未显示的功能入口仅主色图标。独立的 `OpacityToggle` 复用底图与行政区的透明度入口，避免 Tooltip 的状态影响选中样式
8. 窄屏继续采用原有左右排斥，隐藏只改变显示，不关闭窗口。收起功能面板时向内容传 `active: false`，结束取色预览、坐标拾取等临时交互。详情与功能分别登记地图定位避让

## 取舍

不新增占用地图宽度的详情列，也不引入自由拖拽弹窗。继续使用现有地图会话、查询与偏好拥有者，页面负责组合，排布与开关保持可独立验证。

## 验证

更新行政区标签、独立详情、清除入口、底图关闭来源及矮屏阈值用例，补充高度分配与底图预留空间的纯函数用例。`pnpm build` 和产物检查通过；按用户要求未运行测试、类型检查、lint 或页面服务，真实页面效果待验收。
