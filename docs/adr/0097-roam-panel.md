# 0097. 漫游改版：合并的"漫游"入口、替换模型面板的漫游面板、统一的速度，去掉单独的钻地

- 状态：已接受
- 日期：2026-10-28
- 修改 ADR 0081 第 6 节（钻地：定位地下的模型进入钻地、地表不透明度）、ADR 0083 第 4 节（路线漫游的入口、0.5× / 1× / 2× 倍速、地图下方的操作条）、ADR 0084（地下空间时隐藏的入口）、ADR 0086 第 5 节（步行漫游的入口和操作条）、ADR 0087（小地图只在步行时有）；补充 ADR 0095

## 背景

用户 2026-10-28 的现状底图优化（roadmap"现状底图的调整（2026-10-28）"第 4～6 步）：

- 把"步行漫游""路线漫游"合并为右侧的"漫游"按钮；进入地下空间后隐藏底部的地图信息栏和右侧工具栏
- 进入漫游后用漫游操作面板替换三维模型面板，退出漫游后恢复；漫游过程中不允许勾选、取消勾选其它图层，不允许切换为二维（不允许做漫游之外的越界行为）
- 原来在外面的路线选择整合进漫游面板；路线漫游时同样显示小地图；"回到出生点"改为"回到起始点"；初始漫游速度 4 m/s
- 去掉单独的钻地和地表透明度调整，退出漫游时同时退出钻地

用户确认"外部路线新增功能"指预置路线的选择。原型在 `/dev/map-3d`（2026-10-28 用户确认），三处待定的按推荐定：路线速度统一用 m/s；路线漫游可以打开完整地图，但不能瞬移；地下的模型保留"定位"。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 漫游面板放在哪 | 左侧替换三维模型面板；仍在地图下方 | 左侧（用户要求）：漫游期间模型面板没有可做的事，替换它也就做到了不能勾选模型 |
| 步行和路线的关系 | 两种漫游各自开始、各自退出；同一次漫游的两种方式，面板里切换 | 同一次漫游：入口只有一个"漫游"，面板里切换方式不用先退出；能步行的从步行开始，只有路线的停在第一条路线的起点；从步行切回路线时接着上次的路线 |
| 漫游期间隐藏哪些入口 | 只在地下空间里隐藏（ADR 0084、0095）；漫游期间都隐藏 | 漫游期间都隐藏：业务工具栏、功能面板、底图、区划条、视图控件和状态栏，只留漫游面板和小地图；"不允许越界"对地面上的模型同样成立。去掉单独的钻地以后，地下空间只在漫游地下的模型时出现，两条规则合成一条 |
| 路线的速度 | 保留 0.5× / 1× / 2×（1× 是 1.6 m/s）；和步行共用米/秒的档位 | 共用（用户选）：0.5、1、1.6、2.5、4、6、8 m/s，默认 4，两种方式之间沿用；4 m/s 比原来的 1× 快 2.5 倍 |
| 路线漫游的完整地图 | 小地图只看不点；能打开完整地图、不能瞬移；和步行一样能瞬移 | 能打开、不能瞬移（用户选）：路线是固定的，瞬移不适用；打开时暂停路线 |
| 去掉钻地以后地下模型的"定位" | 去掉；保留 | 保留（用户选）：飞到模型上方，从地面看不到地下的模型，要看就漫游 |

## 决定

### 1. 入口

- "已加载"里能漫游（有出生点或有路线）的模型，第二行最右边是"漫游"按钮；原来的"步行漫游""路线漫游"和"漫游中""钻地"标签都去掉
- 点"漫游"：有出生点的从步行开始，否则停在第一条路线的起点

### 2. 漫游面板

- 漫游时左侧换成漫游面板，退出后换回三维模型面板；和模型面板同宽、同样的浅灰标题栏和收起竖条（"漫游"）
- 标题"漫游"，后面灰色的"模型名 · 类型"；标题栏右边是"退出漫游"和收起
- "步行""路线"两段切换，没有出生点或没有路线的那一段不可用
- 步行：分析站内空间的进度、进入站内、失败和重试同原来的操作条；进到站内以后是速度、"回到起始点""脱困"、提示，下面是两列的操作说明
- 路线：预置路线一条一行（名称、长度），当前的浅蓝底；选一条就停在它的起点；下面是开始 / 暂停 / 继续 / 重新开始、进度条、"已走 / 总长 · 剩余 m:ss"、速度和操作说明
- 地图下方的漫游操作条和钻地条都去掉

### 3. 漫游期间

- 业务工具栏、功能面板、底图卡片与浮层、区划条、视图控件和状态栏都不显示，不能勾选模型、不能切二维；只隐藏不改状态，退出后原样显示
- 开始漫游时当前工具切回移动；选了移动以外的工具就退出漫游（同 ADR 0083）
- Esc 先关完整地图，再退出漫游；空格开始、暂停或继续路线（同原来）

### 4. 速度

- 步行和路线共用一个速度（米/秒）：档位 0.5、1、1.6、2.5、4、6、8，默认 4，几次漫游之间、两种方式之间沿用；路线按这个速度走

### 5. 钻地

- 没有单独的钻地：定位地下的模型只飞过去，不进入钻地；地表不透明度不能调
- 漫游地下的模型时进入地下空间（地表固定半透明，地面上的模型不显示，同 ADR 0084）；退出漫游就回到地面

### 6. 小地图

- 步行进到站内以后、路线漫游开始以后，右上角都有小地图；路线漫游时画出整条路线、走过的一段加深
- 室内模型的导航网格在漫游开始时建（两种方式共用，按模型缓存）：路线不等它，建好后出现小地图
- 路线漫游时也能打开完整地图，打开时暂停路线，双击不瞬移

### 7. 实现的分步

- 第 5 步：漫游面板、合并的入口、漫游期间的隐藏、统一的速度
- 第 6 步：去掉单独的钻地，退出漫游回到地面；路线漫游的小地图和完整地图

## 后果

- 去掉了钻地条和地图下方的漫游条；`RoamBar`、`UndergroundBar` 由新的漫游面板代替
- 地下空间和漫游期间的界面规则合并：现状底图页只按"是否在漫游"决定隐藏哪些入口
- 地下的模型只能通过漫游看到；从地面定位只能看到位置
