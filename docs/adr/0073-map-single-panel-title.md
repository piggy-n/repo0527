# 0073. 单功能面板直接显示功能标题

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0071 的固定「地图工具」标题与标签显示条件

## 背景

仅打开一个功能时，通用标题和单个标签重复占用空间。用户要求按打开数量自动切换标题布局。

## 决定

1. 只有一个功能时，面板标题直接显示该功能名称，不渲染标签区
2. 两个及以上功能时，标题为「地图工具」，显示已有的两列标签；名称、蓝色竖条与选中外观继续按 ADR 0072 及后续反馈
3. 两种布局都复用面板级 `MxTitle`，保留深色加粗标题、蓝色竖条和收起 / 关闭图标，不新增 Tooltip
4. 标题关闭图标关闭当前打开的全部功能；单功能时无障碍名称标明该功能，多功能时标明「关闭全部功能」
5. 数量变化只更新标题和标签区，不重新挂载仍打开的内容，不清空输入、图层或工具状态

## 后果

单功能为内容留出更多高度；多功能继续支持切换与逐项关闭。补充真实布局用例覆盖单项 → 多项 → 单项的高度恢复与内容保留；本轮按用户要求仅运行构建，不启动服务或执行测试。
