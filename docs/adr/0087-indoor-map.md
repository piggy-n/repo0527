# 0087. 步行时的室内地图：右上角的小地图、完整地图与双击瞬移

- 状态：已接受
- 日期：2026-10-27
- 落实 ADR 0078 第 6 节步行漫游的小地图（3D.4d-1）；补充 ADR 0086（步行意图多了暂停和瞬移，视图报告人的位置）

## 背景

旧项目的室内地图在 `cesium/indoorMap/`（`IndoorMap.js`、`IndoorMinimap.js`、`IndoorMapView.js`、`mapDraw.js`，数据层 `levels.js` 已在 3D.4b 迁入）：

- 小地图在右上角，180 × 180，以人为中心、北朝上，跟着所在楼层；人是黄色箭头加视野扇形，点击移动的落点是圆点，左上写层名、左下比例尺，+/− 在 20、40、80、160 米之间（档位记在 localStorage）；点它打开完整地图
- 完整地图是大面板：顶部切换楼层（人所在的层标"当前"）、"定位到我"、+/−、×；拖动平移、滚轮缩放，双击跳到这一层最近能站的地方（30 米内没有时提示）；看别的楼层时用淡色圈标出人的平面位置；打开期间步行的键鼠暂停
- 地图从导航网格现画，每层单色；底图按网格、楼层缓存

用户 2026-10-27 选定：小地图放在右上角 180 × 180（地下空间时那里的工具栏、功能面板都隐藏了）；第三人称迁移并开放切换，放到 3D.4d-2；3D.4d-1 先在 `/dev/nav-grid` 用真实网格做组件预览，确认后接进页面（预览当天确认）。

## 决定

### 1. 数据与绘制（`features/scene-models/indoor-map`）

- 室内地图属于三维模型这个业务域，放在 feature；楼层和区域着色复用 map-core 的 `detectLevels`、`planRegions`、`renderFloorMap`（ADR 0085），正北朝上、按区域着色
- `indoorMapOf(navigation)`：楼层、着色按导航网格缓存；拥有者在导航网格建好时顺带算好（还在"分析站内空间"），进到站内不再顿一下
- 底图都是正北朝上的平面里的一块：完整地图按楼层画一次（四周留 6 米，最细 0.2 米一像素、不超过 200 万像素）后缓存；小地图以人为中心采显示范围 1.5 倍的一块，人走出 1/5、换楼层或范围才重采
- 完整地图的取景（打开时整层放得进 150 米宽就整层显示，否则以人为中心；换楼层时位置和比例不变；以鼠标处为不动点缩放，最大每米 24 像素）是纯函数（`map-camera.ts`），node 下测试
- 人用主色箭头加同色渐隐的视野扇形，描边是容器底色（从 CSS 令牌读）；落点用和三维光环相同的青色（按数据画的颜色，记在 `docs/design/color-and-typography.md`）

### 2. 会话与视图

- `WalkRoam` 加 `paused`（完整地图打开时暂停：不响应键鼠，点击移动的路径照常走完）和 `teleport`（`{ count, spot }`，计数变了就闪切到 `spot`，同 ADR 0086 的一次性命令）
- 步行状态加 `player`：人的局部坐标、脚下地板、偏航、水平视场角（按画布宽高比由竖直的换算）和点击移动的落点；进到站内以后每帧变了才报告
- 视图没有新的接口给地图，地图只读拥有者转出来的 `walkPlayer`

### 3. 界面

- 小地图（`IndoorMinimap`）：右上角，横跨中间一列和工具栏一列靠右；手机宽度、左侧面板展开时不显示（会压在面板上，同区划条），收起面板后出现；左上"-2F · 北↑"，左下比例尺，右下 +/−（20～160 米，默认 40 米，不持久化）；点地图、回车打开完整地图
- 完整地图（`IndoorMapDialog`）：盖住地图区域的遮罩（同 Element 弹窗的遮罩色），面板贴右上、最宽 1000，用 `MxPanel` 的浮动外观和浅灰标题栏；第二行是楼层、操作说明（提示时换成主色的提示）、"定位到我"、+/−；点遮罩、×、Esc 关闭，Esc 只关地图、不退出漫游（地图拦下，页面的 Esc 也先关地图）
- 双击：这一层 30 米内离双击处最近的能站位置，闪切过去并关掉地图；没有时提示"这附近没有可以到达的地面"
- 开发页 `/dev/nav-grid` 保留"步行地图预览"：不挂 Cesium，用 `Walker` 在真实网格上模拟走动，调界面时用

## 后果

- 好处：小地图、完整地图和行走用同一份导航网格和区域着色；规则在纯函数里，组件只画
- 代价：步行时每帧报告一次人的位置（经过会话和 Vue 的响应式），只在变了的时候
- 待定：小地图的档位是否记进偏好；楼层名的配置（ADR 0085）
