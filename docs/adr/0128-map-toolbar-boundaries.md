# 0128. 地图控制栏里的行政区边界入口

- 状态：已接受（2026-11-03 用户提出，待真实页面验收）
- 日期：2026-11-03
- 修改：ADR 0098 中"行政区放在指标成果面板里"的做法
- 补充：ADR 0053 第 3 节（基础组的内容）、ADR 0111（不支持三维的地图页的控制栏）

## 背景

用户要求统一各模块的地图工具：

1. 除现状底图外，所有包含地图的模块新增"行政区边界"按钮及功能，复用现有组件
2. 原"行政区"统一改名为"行政区边界"
3. 城市国土空间监测指标的边界控制迁到工具条，去掉重复入口，功能和默认显示不变
4. 各模块的样式、交互、状态一致

此前的状况：现状底图的业务组有这个入口，面板在功能标签里。其他地图页只有基础组（`MapViewControls`）和底图卡：监测指标把勾选放在"指标成果"面板里，要先选指标才看得到；数据查询、AI 对话、指标 AI 计算只能看默认的边界，改不了。

第一版在这些页面的右上角另放了一个只有一个按钮的工具栏，面板由各页排布。用户看过方案后明确：直接加到底部工具条，不要单独写一个工具条。

## 决定

### 1. 范围

| 模块 | 地图 | 默认显示（不变） |
|---|---|---|
| 城市国土空间监测指标 | 页面地图，两个页签都有入口 | 省、市、县 |
| 数据查询（四个专题） | 页面地图 | 省 |
| AI 对话 | 主区地图 | 省 |
| 指标 AI 计算 | 结果地图、自定义范围弹窗的地图，共用页面的拥有者 | 省、市 |

不纳入：现状底图（入口仍在业务组，打开功能标签）；驾驶舱（Three.js 立体地图，没有这条控制栏，也没有这组边界图层）。"行政区划""涉及的行政区"以及驾驶舱的行政区筛选说的是区划本身，不是这项功能，不改名。

### 2. 入口在基础组

`MapViewControls` 增加可选的 `boundaries`（拥有者）、`boundariesOpen`、`boundariesVisible`、`update:boundariesOpen`，写法和"不传 `dimension` 就没有 2D/3D"相同：不传就没有入口。开关由页面持有，窄屏时计入 `useSideExclusion`，和底图卡的 `open`、`visible` 同一套写法。勾选和透明度仍在 `useBoundaries`，默认级别由页面照旧设置，不记偏好的页面依旧不记。

按钮排在指北针一段和默认视角之间，各隔一条分隔线。不放在最下面：紧贴底图卡时两边向左打开的浮层会互相压住；不放在最上面：数据查询的底图卡在控制栏左边、顶部对齐，浮层会盖住底图卡。

状态同业务组的动作按钮：浮层显示时浅主色底和 `aria-pressed`，窄屏让给另一边时只标主色，这时点击是重新显示。

### 3. 点开是底图同款的浮层

复用 `MapOptionsPopover` + `BoundaryPanel`（`showOpacity={false}`，透明度在浮层的操作栏）：左侧带箭头，再点入口或 × 关闭，外部点击不关闭，页面停用时关闭。浮层跟着入口定位，页面不需要任何排布代码，五处地图的行为自然一致。`MapOptionsPopover` 增加 `placement`，这里用 `left-end`（底边和按钮对齐、向上展开），给下方的底图浮层让位。

现状底图仍用功能标签，因为它有四个功能共用一个容器；其他页面只有这一项，用不上标签和收起。

### 4. 矮地图

控制栏高了 41（182 → 223）。AI 对话的结果展开后地图只剩 240～420 高，一列放不下控制栏和底图卡：地图低于 340 时底图卡移到控制栏左边、顶部对齐（CSS 容器查询，高度取 `.map`，和数据查询的一行排法相同）。其他页面的地图都放得下。

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 入口放在哪 | 右上角单独一个 `MapToolbar`；基础组里 | 基础组（用户决定）：不多一个工具条，五处地图本来都有基础组 |
| 点开后是什么 | 单功能的 `MapPanelGroup`（标题、收起、关闭），由页面排布；`MapOptionsPopover` | 浮层：不需要页面排布，和紧挨着的底图卡一致；只有一行勾选，用不上标题和收起 |
| 两个浮层同时打开 | 算出位置互相避让；打开一个时关掉另一个；排开默认状态、接受极端情况 | 排开默认状态：避让要在每页接上几何计算，互斥又违背底图"外部点击不关闭"的规则 |
| 监测指标的控制 | 留在成果面板里，工具条只是另一个入口；挪走 | 挪走（用户要求去掉重复入口），计算页签也能用 |

## 影响

- 用户可见的名称变了：提示、`aria-label` 都是"行政区边界"，透明度入口是"调整行政区边界透明度"
- 数据查询的控制栏高了 41，结果最大化时从它下面开始，也少 41 像素
- 已知的限制：两个浮层同时打开时默认不重叠，展开透明度后会压住一段（监测指标约 27 像素，数据查询和 AI 对话的矮地图最多约 49 像素），后打开的在上面，关掉一个即可
