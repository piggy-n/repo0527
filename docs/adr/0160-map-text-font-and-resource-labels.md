# 0160. 地图文字用页面的普惠体在本地画，资源图层加标注

- 状态：已接受（右键菜单的"标注…"去掉省略号写"标注"，用户 2026-11-25 调整，见设计文档）
- 日期：2026-11-16
- 取代：ADR 0133 第 3 节"样式校验要求有 `text-field` 时必须有 `glyphs`，页面传 `root: BASEMAP_STYLE_ROOT`""名称只能是汉字"；ADR 0041 第 2 节"标注只带 Noto Sans 的 0-255 字形区段"的设想
- 补上：ADR 0041 的"待定：标注的时机"、ADR 0157 第 6 节"标注这次不做"
- 补充：ADR 0042（资源图层的显示状态多一项 `labeled`）、ADR 0044、0154（符号覆盖多一项 `label`，版本不变）、ADR 0047（点到标注的文字也是候选）、ADR 0050（框选估数不数标注图层）

## 背景

现状底图改版第三批的需求 6：资源图层要能标注（旧项目给地类图斑、水域线层写死了标注）。样板、设计说明和普惠体的实测在 `local/design/legend-symbols-v1/`（第 3 块）、`local/design-src/legend-symbols-v1/spike/`，调研在 `local/design-src/current-map-revamp/scout.md` 的 labels 一节（不入库）。用户 2026-11-16 答复 T1～T8：除 T3 外按推荐，T3 改成所有资源默认都不开标注；另外补充了编辑器的两处和"选中要素时的标注"（`batch1-decisions.md` 的"用户的答复"）。

核对的事实（MapLibre 6.12、style-spec 26.4）：

- 样式不写 `glyphs` 时，MapLibre 把所有字符都用 TinySDF 在本地画；`validateStyleMin` 也不要求有 `glyphs`。ADR 0133 第 3 节"有 `text-field` 就必须有 `glyphs`"对现在的版本不成立
- `text-font` 不是默认栈时，汉字按 `text-font` 的名字加 `sans-serif` 当 CSS 字体画，`localIdeographFontFamily` 的字体名不起作用。所以静态底图的地名（`text-font: ['Noto Sans Regular']`）其实画成了微软雅黑，不是 ADR 0133 说的"页面的字体"
- 本地画之前会 `document.fonts.load` 这个字体，页面 `@font-face` 声明的普惠体能用上；字重只从栈里第一个名字猜。只写 `['Alibaba PuHuiTi SemiBold']` 会落到系统黑体（页面上没有叫这个名字的字体），写成 `['Alibaba PuHuiTi SemiBold', 'Alibaba PuHuiTi']` 才是普惠体 600（样板实测）
- 普惠体按授权不能拆分、转换，做不了 SDF 字形文件；页面已经加载 400、600 两个字重

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 字体（T1） | 不写 `glyphs`，`text-font` 写普惠体；保留 `glyphs`，部署 Noto Sans 的字形文件 | 不写 `glyphs`：不下载任何东西，内网可用；汉字、数字、字母同一种字体，和界面一致；底图地名一起改 |
| 可选的字体（T2） | 普惠体常规、中粗；再列出微软雅黑、黑体、宋体等本机字体 | 只有普惠体两档：本机字体取决于客户端，发布成默认后别人的电脑上可能没有 |
| 默认开不开（T3） | 照旧项目开地类图斑、水域线层；全部默认关 | 全部默认关（用户 2026-11-16） |
| 显示级别（T4） | 固定 14 级起；14 级起、用户可调 | 14 级起（地类图斑 15 级），用户可调最小、最大级别 |
| 存储（T5） | S1 显隐和样式都进符号覆盖；S2 显隐进资源图层的显示状态，样式进符号覆盖；S3 单独一项偏好 | S2：开关标注和开关图层一样是显示状态；样式跟着"恢复默认"和发布的默认符号走；两项都只加可选字段 |
| 入口（T6） | 只用右键菜单；再加工具栏按钮 | 右键菜单"显示标注 / 隐藏标注""标注…"，工具栏第 8 个按钮"标注"（标题改成两个字后放得下，ADR 0157 第三批的命名） |
| 分组（T8） | G1 放在 `resources` 分组里跟着资源；G2 单独的 `resource-labels` 分组 | G2：在 `selection` 和 `region-clip` 之间，三维里画在模型上面，区划外被遮罩盖住；碰撞可以统一排先后。模型层的位置机制由同批的 ADR 0161 改，这一组不依赖它 |

## 决定

### 1. 字体

- 地图样式一律不写 `glyphs`。`text-font` 只用 `shared/map/map-fonts.ts` 的两个栈：常规 `['Alibaba PuHuiTi']`，中粗 `['Alibaba PuHuiTi SemiBold', 'Alibaba PuHuiTi']`
- 静态底图的地名也改成普惠体常规。`BASEMAP_STYLE_ROOT` 删掉，页面不再传 `root`；地名不再限于汉字。`pages/map-pages.test.ts` 改成检查地图页都不写 `glyphs`
- `JIANGSU_MAP_OPTIONS` 的 `localIdeographFontFamily` 保持真值：只在 `text-font` 是默认栈时用到它的字体名；万一样式带了 `glyphs`，汉字也在本地画、不请求字形

### 2. 可以标注的字段

- 目录接口不给字段清单：`features/resource-map/label-fields.ts` 按 `code` 登记，一个资源一行，只列瓦片里实际有的、业务上看得懂的属性：名称、类型、地类名称这类，以及业务上常看的编码和编号（地类编码、图斑编号、路线编号、批准文号）；机器用的标识码（`bsm`、`ysdm`）、各种单位代码（`*dm`）、面积、日期不列。第一个是默认字段，带有值的比例（来自 2026-11-01 的探查，年份取各资源最新的一年）。没有登记的资源不提供标注，入口灰掉、写"没有可标注的字段"
- 文字是 `to-string(coalesce(get(字段), ''))`，等于后端的占位值 `-9999` 时为空（水域线层的名称三分之二是它，按 AGENTS.md 只过滤）

### 3. 标注的样式

| 项 | 取值 | 默认 |
|---|---|---|
| 字段 | 登记的字段 | 登记的第一个 |
| 字体 | 普惠体常规、中粗 | 常规；水系（水域线、面，河流、湖泊、水库）中粗 |
| 字号 | 10 12 14 16 18 20 | 12 |
| 颜色、描边色 | 任意颜色，拖动预览、确认写入（ADR 0044） | 面 `#1F2937`、线 `#4B5563`、点 `#374151`，水系 `#0B4A78`；描边白色 |
| 描边宽度 | 0 1 1.5 2 3 | 1.5，有描边时 `text-halo-blur` 0.5 |
| 放置 | 点：自动、右侧、上方；线：沿线、水平；面：中心 | 点"上方"（用户 2026-11-16），线沿线，面中心 |
| 显示级别 | 8～20 的整数范围，最大拉到头时不限制 | 14 级起，地类图斑 15 级起 |
| 压盖 | 开关：文字之间允许重叠 | 关 |

- 点的文字让开画出的点：按各类里最大的形状、大小和描边，在点的大小曲线的断点上算出偏移（定位针往上让开针头），按级别插值；"自动"用 `text-variable-anchor-offset`，先右、再左、上、下
- 线沿线是 `symbol-placement: line`（间隔 260、最大转角 35°），水平是 `line-center` 加 `text-rotation-alignment: viewport`；面是默认的 point 放置（每块瓦片取不可达极点，跨瓦片的大面会重复标）
- 文字的透明度跟着图层，低于 10% 按 10%（SDF 的着色器低于 0.1 整个不画，同点，ADR 0159）；透明度为 0 时不推导标注图层：MapLibre 放置标注时不看透明度，看不见的文字照样占着避让的位置、挤掉别的标注，也会被点到
- 最小显示级别不低于资源的最小显示级别（ADR 0137）

### 4. 存储

- 显隐是资源图层显示状态的 `labeled`（偏好 `resource-layers`），没有这一项的旧数据按不显示；样式是符号覆盖的 `label`（偏好 `resource-symbols`），只记和默认不同的字段。两项偏好都不升版本、不改严（ADR 0154、0157 的先例）；字体、放置方式的取值以后只能增加，不能改名或删除
- 默认标注是代码给出的再叠加发布的默认（`resource-symbol-defaults.json` 的 `label`，由 `symbols:import` 写入，没登记字段的资源、不认识的字段跳过）；"恢复默认"（单个资源和全部）连标注一起恢复，标注编辑器另有"恢复默认标注"只恢复标注，关着标注时也能点。图例的"改过符号"（`isCustomized`）只看符号的覆盖，只改了标注不算：标注在标注编辑器里看、在那里恢复
- 拥有者：显隐在 `useResourceLayers`（`setLabeled`），样式在 `useResourceSymbols`（`labelOf`、`setLabel`、`previewLabelColor`、`resetLabel`），标注颜色的预览和符号的预览一样参与推导、不保存

### 5. 地图

- 分组顺序（第三批约定）：`basemap`、`resources`、`selection`、`resource-labels`、`selection-labels`、`region-clip`、`basemap-labels`……。`resource-labels` 由 `useResourceLayers.deriveLabelsGroup` 推导，只有画在地图上、开着标注、透明度不为 0、校验通过、登记了字段的资源，和资源共用数据源（ID 以分组名为前缀，没有自己的数据源），和 `resources` 读同一份状态、同一轮提交
- 碰撞：MapLibre 从上面的图层先放，组里从下到上是面、线、点（点 > 线 > 面），同一种几何按面板的先后。点的图标开着 `icon-ignore-placement`，不挡文字，名称可能压在别的点上（样板的说法；要避开得把名称和图标放进同一个图层，但标注要在模型上面的分组里，做不到）
- 目录变化时的校验（ADR 0041 第 4 节）连同默认标注的图层一起校验；每个登记的资源的标注图层（各种几何、字段、字体、放置和加强标注）都有 `validateStyleMin` 的单元测试
- 三维里照常画（同一个 MapLibre 视图），引擎不画样式图层时同资源分组为空

### 6. 点选与框选

- 文字画在所有资源上面，按面板顺序逐个资源识别会先命中上面的资源（看到的是学校名称，点到的却是地类图斑）。所以识别前先在点击位置（一个点，不是容差框）查开着标注的资源的标注图层，命中时结果就是最上面那条文字所属的资源，候选是它在这一点的文字（距离 0，按 guid 去重，文字所属的要素要在区划范围里），不再往下识别（2026-11-16 复核）
- 点击位置不在文字上时照常逐个资源识别，不算标注图层：容差框碰到的文字不是点到了它，不会排到直接点中的要素前面、也不会多出候选
- 框选不算标注图层（2026-11-16 复核）：估数只数画出要素本身的图层（ADR 0050），只用渲染要素时的计数和候选也去掉标注图层，文字伸进框里的框外要素不会被选中；标注图层的 ID 是 `resource-labels-…`、`selection-labels-…`

### 7. 查询详情里那个要素的加强标注

- 只给查询详情里正在看的那一个要素（不等详情到，用瓦片里的这个要素），而且只在它所在的资源开着标注时；框选、悬停、在"图层"列表里选中一行、图层没开标注时都不变
- `selection-labels` 分组由点选的拥有者推导：同字段、同放置、同级别，中粗、大 2 号、文字 `#f5222d`、白色 2 像素描边，`text-allow-overlap` 和 `text-ignore-placement` 都开（始终显示、不挡别的标注），不跟着图层的透明度，不加倾斜（普惠体没有斜体）
- 资源的标注图层按 guid 滤掉这个要素；页面把点选拥有者的 `labelEmphasis` 交给 `deriveLabelsGroup`，两组读同一份状态、同一轮提交

### 8. 入口和编辑器

- "图层"的右键菜单在透明度、图例后面加"显示标注 / 隐藏标注"和"标注…"，工具栏在图例后面加第 8 个按钮"标注"；三维模型的行没有（同透明度、图例）。320、294 宽放得下；360 宽的手机（面板 264）上标题行的内容宽不到 250，按钮再紧凑一档（21 宽、竖线两边 1），8 个按钮共 183，最右的"移除"不压进右边 12 的留白（2026-11-16 复核后实测，`/dev/map-ui`）。手机上右键菜单不一定好用，所以不在窄屏收起"标注"按钮
- "标注…"和工具栏打开第三种浮层（宽 300，同透明度、图例浮层开在面板右边、箭头对着行）：最上面"显示标注"开关，下面的行同符号编辑器；关着标注时编辑器不能操作（"恢复默认标注"除外）。压盖是开关，名称后面的问号悬停或键盘聚焦才显示"文字之间允许重叠"（用户 2026-11-16）

## 后果

- 好处：不新增任何字体、字形文件，内网照常；地图里的汉字、数字、字母和界面是同一种字体；底图地名和资源标注统一
- 好处：标注的样式能像符号一样记住、恢复、发布成默认；点到文字就能选中要素
- 代价：每个新字都要在主线程用 TinySDF 画一次，样板在软件渲染下约 0.35 毫秒一个字；POI 名称多的资源第一次显示可能卡一下，显卡机器上的帧率、首次开销没测（`docs/backlog.md`）
- 代价：部署缺普惠体时退回 `sans-serif`；字重靠名字猜，依赖 MapLibre 的实现
- 代价：底图地名从微软雅黑换成普惠体，外观有变化
- 代价：跨瓦片的大面会重复标（MapLibre 的 point 放置），低级别瓦片里后端合并或删减了属性（地类图斑（城镇村）探查的 7、9、11 级瓦片里没有 `dlmc`），把最小级别调低时有的标注是空的
- 代价：字段清单是 2026-11-01 各资源最新一年的探查结果，别的年份、后端改了字段时要重新探查、改登记。只有编码或没有属性的（村级调查区界线、行政区界线、推土区、城市内涝积水线、`bgdc_ccwjq`）、名称几乎都空着的（城镇村等用地、`bgdc_gfbq`、城区内房屋建筑面层）、只有一两个固定取值的（城市内涝积水点、地类图斑变化线层、坑塘的流域名称）、探查没取到数据的（耕地保护目标、永久基本农田保护图斑）现在不能标注
- 第三批里模型层的位置由 ADR 0161 改；合并之前，现在的 `sceneBelow: 'basemap-labels'` 让 `resource-labels` 也在模型下面，合并后才在模型上面
