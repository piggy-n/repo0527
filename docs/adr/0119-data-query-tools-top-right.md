# 0119. 数据查询：高级查询暂时隐藏，地图控制和底图卡移到右上角，结果横跨整页

- 状态：已接受
- 日期：2026-10-30
- 修改：ADR 0104 第 2 节（四个页签）、ADR 0112 的结果排布（右边给底图卡让出 40）

## 背景

用户 2026-10-30 要求：数据查询暂时隐藏"高级查询"按钮，只显示其余三个，保留原有代码和业务逻辑；地图导航工具栏和底图切换按钮移到右上角，查询结果区域充分利用页面宽度。同一天看过第一版（控制在上、底图卡在下）后补充：底图卡放到工具栏左侧，不要放到下方。

ADR 0112 之后，结果从页面左边开始，但右下角是地图控制（基础组）和底图卡，结果右边要给底图卡让出 40，并排在控制所在的一列左边。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 隐藏高级查询 | 删掉页签和表单；只在面板上不列出 | 只在面板上不列出：`QUERY_TABS` 和表单、提交、导出的逻辑都保留，`SHOWN_QUERY_TABS` 过滤掉它，恢复时去掉过滤 |
| 控制和底图卡的排法 | 横排、底图卡在控制左边；竖排、控制在上底图卡在下（同原来的上下关系） | 横排（用户当天的补充）：右上角只占一行，底图浮层仍从卡片左边展开；第一版的竖排在合入前改掉 |
| 结果最大化 | 占满整个浮层、盖住右上角；从右上角的控制下面开始 | 从控制下面开始：最大化时整列从网格第二行开始，不盖住地图控制和底图卡 |

## 决定

- 查询面板的按钮组只显示属性查询、空间查询、自然语言查询；`useDataQuery` 的页签、表单和提交不变
- 浮层是两行两列的网格：右上角一行是底图卡和地图控制（底图卡在左、顶部对齐，间隔 12；入口按所在盒子占满宽度，包一层按卡片本身的宽度排）；查询面板和结果仍在同一列，占满整个浮层，结果贴底、从左边一直到右边，不再给底图卡让位；结果最大化时这一列从控制下面开始
- 查询面板右边留出右上角一行的宽度和间距（144），页面窄到放不下时面板不伸到它们下面

## 后果

- 结果的表格比原来宽约 92 像素，右下角不再有遮挡
- 其余页面（指标、AI 对话、指标 AI 计算）的控制仍在右下角，不受影响
- 测试：`QueryPanel.test.tsx` 改为三个按钮；排布在 `/dev/data-query` 的真实页面上量过（1600 × 940：底图卡 80 × 56 在控制左边 12，控制宽 40，浮层在卡片左边 12 展开；结果宽 1568，最大化时从控制下面 12 开始）
