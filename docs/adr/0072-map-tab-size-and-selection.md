# 0072. 地图功能标签的字号与选中状态

- 状态：已接受
- 日期：2026-10-20
- 修正：ADR 0071 的标签字号、行高与选中外观

## 背景

用户反馈功能标签过大，要求参照资源详情中的区块副标题；原来的浅灰底与短下划线不够醒目。

## 决定

1. 标签名称使用既有区块副标题规格：14 / 600、`--color-text-title`；最小行高从 32 缩至 28，纵向内边距缩至 2
2. 选中背景覆盖整块标签，使用 `--color-primary-bg` 和 1 像素 `--color-primary-border` 内描边；取消短下划线，悬浮时保持选中样式，文字继续深色加粗
3. 保留标准面板标题、两列标签、固定内容滚动区、逐项关闭与全部关闭的交互，不新增 Tooltip 或主题令牌

## 验证

同步既有布局用例的文字规格断言，按用户要求只运行生产构建，浏览器效果待验收。
