# 0175. 图例以看为主：单击只看，修改从样式设置进，过滤掉的类别淡显

## 背景

图例有两处：右侧"图例"页（`ResourceLegend`）和图层面板的图例浮层（`LayerLegend`），样式设置（`LegendSettings` + `SymbolEditor`）两处共用。调研（`local/design/legend-v3/research/`）发现同一个"单击"在五个地方是四种意思：单一符号、统一配色的行单击进整层设置；按类别配色的行单击展开收起，设置要点悬停才出现的按钮；子图例单击直接编辑这一类；浮层里单一符号、统一配色一打开就是设置，按类别配色先浏览。"显示方式"有三个入口（右侧行上、浮层标题栏、设置里），行上为了对齐还要留 24 的占位和 56 的留白。面的描边宽度 0 早就是无描边（ADR 0045），但要点"自定义"再输入 0。

## 候选方案

| 问题 | 方案 | 取舍 |
|---|---|---|
| 统一入口 | 单击只看，修改只从行尾的样式设置进（采用） | 三种图例一个样子；改一类要先进设置再选，用户另定子图例单击也进这一类的设置 |
| | 单击都进编辑 | 和"以看为主"相反，浏览时误点就进编辑 |
| | 面板级的"编辑"开关 | 平时最干净，但多一个模式、多一次点击，浮层还要另做一套 |
| 显示方式 | 只在样式设置里切换（采用） | 少一个按钮，行尾只剩样式设置；切换要先进设置 |
| | 只留浮层标题栏的 | 两处又不一样 |
| 过滤 | 列出全部类别，过滤掉的淡显（采用） | 看得出哪些被过滤，不加文字；按别的字段过滤图例里看不出，靠图层行上的漏斗 |
| | 名称后面漏斗；名称下面写条件 | 用户：漏斗和年份、改过的点挤在一起"太丑"，纯文字"不太喜欢" |
| 无描边 | "描边方式"下拉第一项"无描边"（采用） | 同"填充方式"的"无填充"；存的仍是宽度 0，格式不变 |
| | 描边宽度四档前加"无" | 浮层里控件列只有 180 宽，五档加"自定义"放不下 |

## 决定

1. **单击只看**：右侧"图例"页每一行是箭头、摘要、名称、年份；按类别配色的单击展开、收起，单一符号、统一配色的不是按钮，单击不做什么。行上不标过滤、不标改过符号。
2. **修改从样式设置进**：每一行行尾同一列一个样式设置（三种图例都有），浮层标题栏同样一个；点子图例的一类也进样式设置，类别已选好。两处进的是同一个视图：标题和"返回图例"、显示方式、编辑器（按类别配色时第一行选类别，只列资源实际有的）、恢复整个图层默认。
3. **显示方式只在样式设置里**：去掉右侧行上和浮层标题栏的快捷切换。
4. **浮层**：单一符号、统一配色没有子图例，一打开就是样式设置（按钮按下），不在设置里时只剩标题栏；按类别配色先看子图例。
5. **过滤（修改 ADR 0173 第 4 节）**：子图例列出全部类别，过滤掉的淡显、悬停写明地图上不显示，仍可点进设置；行首的摘要、"盖住模型"的判断只看画出来的类别。名称后面的漏斗、名称下面的条件文字都去掉。
6. **两边互让**：只有两边都在样式设置里、对着同一个资源时才让，浮层让出时回到看图例、不关；只是看图例不让右侧退出设置。
7. **无描边**：面的"描边方式"第一项是"无描边"，写 `outlineWidth: 0`（存储的格式和版本不变）；无填充和无描边不能同时选；自定义宽度改成 0.1～8，关掉描边只走下拉。

界面的尺寸、文案、焦点和吸顶等细节写在 `docs/design/current-map-reference.md` 的"已确认的界面细节"。

## 后果

- 改某一类比以前多一步（先进设置再选）——子图例单击直接进这一类的设置后，只有从行尾进来时要在"类别"里选。
- 按别的字段过滤（如学校按"办学类型"）在图例里看不出来，只在图层行上的漏斗和它的提示里。
- 行尾只剩一个按钮，三种行同一个网格，年份天然对齐，名称多出约 28 像素；占位、留白和快捷切换的图标都删掉了。
- "改过符号"只在样式设置里看（"恢复默认"能不能点）和底部的"全部恢复默认"。
- 无描边的取值不再单独拆出一个什么也不画的描边图层（推导里线型按画出来的取值算）。
