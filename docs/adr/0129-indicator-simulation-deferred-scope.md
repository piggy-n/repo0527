# 0129. 城市国土空间监测指标AI计算：先对话、后补充监测范围

- 状态：已接受
- 日期：2026-11-03
- 修改 ADR 0106 第 6 条（指令没写城市按全省、写了不可选的年份按 2025 年）、ADR 0121 第 1 条（说了自定义范围但还没有时不配置；弹窗只在条件配置阶段）

## 背景

原来发送指令前要先把范围想好：没写城市就按全省计算；说了自定义范围但还没上传，只提示、不配置；一句话只能是完整的指令，回复"南京市"会被拒绝；计算中不能去掉最后的范围；范围弹窗只在条件配置阶段可用。

用户 2026-11-02 要求支持先进行 AI 对话、再补充或指定自定义范围：未指定范围时允许继续对话和编排，标记为待补充；AI 主动提示，也可以选行政区；补充后自动更新条件，不用重新输入；可以随时新增、替换、移除范围；正式计算前检查条件是否完整，避免缺少范围或条件冲突产生无效结果。交互原型 v7（`apps/web/public/design.local/indicator-simulation-v7/`，不入库）经用户确认后开发。

此前有过类似方案，已作废、分支已删除，没有留下可参考的记录。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 范围在哪里补充 | A：条件配置阶段；B：先进入计算，在"条件解析"节点停下来问 | A（用户确认）：还没开始计算，天然不会算出无效结果；条件库、编排图、对话栏三个入口都在这里。B 要给引擎加回等待状态（ADR 0106 刚去掉确认点），流程图和叙述都要处理"没有范围"，计算阶段也没有条件库 |
| "待补充"放在哪里 | 范围类型加第三种 `{ kind: 'pending' }`；由已有的状态推导 | 推导：`citiesScope([])`、`areaScope(null)` 加 `missingConditions` 已经能表示缺范围。加一种类型和"空"的含义重复，每个判断范围种类的地方都要多一个分支 |
| 补齐后是否自动开始 | 都自动；都等确认；按操作区分 | 按操作区分：回复、快捷按钮、弹窗确定是一步完成，用户说过要计算，自动继续（和完整指令一致）；在条件库里逐个点城市可能还要多选，不自动开始，引导卡写"条件已齐全"并给开始按钮 |
| 已有范围时说没写范围的话 | 总是问；沿用 | 沿用：页面上看得见的范围（选好的市、上传的范围）就是上下文，写明"沿用范围"。要试待补充时先重置条件 |
| 跟进的话怎么理解 | 新写一套规则；复用计算阶段的 `interpretCommand` | 复用：加上、去掉、只看、改参数的规则只有一份。说了指标、又说了年份、范围或"计算"，没有动词的算新指令（`isFullInstruction`）；其余是跟进 |
| 引导放在哪里 | 只在待补充节点上；对话栏上方；两处 | 两处：对话栏上方的引导卡负责问话和回答（用户的视线在输入框）；节点负责标记和就地操作。条件库也标出来 |
| 计算阶段上传新范围 | 回到条件配置再传；就地打开弹窗 | 就地打开：暂停计算，确定后从条件解析重算，取消后继续。一个地图上下文只能挂一个画布，弹窗打开时结果地图先卸下（`useCanvasHolder`），关上后镜头移回计算范围 |
| 计算阶段移除范围 | 留在计算阶段等；回到条件配置 | 回到条件配置：引擎不能没有范围。停止计算，标为待补充，其余条件保留，补上后自动继续 |

## 决定

1. **解析**：指令没写范围时，页面上已有范围就沿用，否则留空，由调用方标为待补充；不再默认全省。说了自定义范围但还没有时也是待补充（切到自定义范围）。年份没写仍按 2025
2. **条件冲突**（要用户确认，不替用户选）：写的年份都不可选（不按 2025 悄悄算）；同时说了自定义范围和城市；同一项参数说了两种取值（旧规程和新规程、相交和 50%、人口增加和减少）。"把旧规程改成新规程""把自定义范围换成南京市"说的是后面那个，不算冲突
3. **不阻断的说明**：部分年份不可选时按可选的算；参数对所选指标不适用时按标准口径。说明在开始计算时写进时间线
4. **执行校验**：`canRun`（条件齐全且没有冲突）是唯一的判断，开始按钮、自动开始、计算中的重算都先过它
5. **引导卡**（`compose/guide.ts` 推导，`ComposeGuideCard` 显示）：一次问一件事，其余写"还有 n 项"；开头写刚改了什么，没有时写已识别的条件；问范围时已有的范围（记下的自定义范围、刚移除的市）放最前面，正在用哪一种就先给哪一种的入口。选项发出的话和用户回复走同一条路
6. **待补充期间**：说的话只改说到的条件。这句话补齐了条件、又说过要计算时才自动继续；已经齐全时再改条件不自动开始
7. **计算阶段**：换范围从条件解析重算；移除范围回到条件配置；说"上传范围""绘制范围"或点"上传范围"打开弹窗。计算之前的对话接到时间线的最前面，不再逐字打出

## 后果

- `parsePrompt` 的结果多了 `conflicts`、`notes`、`keptScope`，少了 `reason: 'area'`；`RunCommand` 多了 `conflict`；`log.begin` 接收对话的列表
- 范围弹窗常驻页面（内容按需渲染），画布由 `canvasHolder` 决定；结果地图的数据在弹窗打开时为空，关上后镜头移回
- 跟进的说法只认规则里的写法：空白页只说"南京市"仍提示未识别指标，这次不做"先说范围、后说指标"
- 用法、测试语句和实测见 [indicator-simulation.md](../modules/indicator-simulation.md) 的"S19：先对话、后补充范围"
