# 0120. 城市国土空间监测指标AI计算：去掉目标值与达标评价

- 状态：已接受
- 日期：2026-10-30
- 修改：ADR 0106 的目标值参数、ADR 0107 的"评价分级"一步、ADR 0108 的达标三态与按达标着色

## 背景

ADR 0106 起参数里有一项"目标值"（13 市 2026 年模拟值的中位数取整，Excel 没有目标值），推演有"评价分级"一步，结果、预估栏、地图都按目标值判断达标、接近、未达标（ADR 0107、0108）。

用户 2026-10-30 要求结果简化：移除"达标""未达标""目标"等相关描述、状态判断、功能及视觉效果，不再进行达标评价或比较。

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| "评价分级"这一步 | 保留，改成按数值分级；去掉 | 去掉：这一步只做目标值的对照和达标统计，按数值分五档本来就在结果地图的着色里，没有可以单独演示的内容 |
| 目标值参数 | 只在界面上隐藏；从模型里删掉 | 删掉：留在参数里会继续参与"改了哪些参数"、重算起点和对话的理解，隐藏后反而难解释 |
| 结果地图的着色 | 保留切换，只剩数值一项；去掉切换 | 去掉切换：只有一种着色时切换没有意义，左下卡片只放年度和图例 |
| 说到"目标"的对话 | 当作没听懂；明确回复不设目标值 | 明确回复：否则"人均公园绿地目标改成 13"里的"改成"会被当成"只看人均公园绿地"，悄悄改了条件 |
| 没有可调参数的指标 | 不处理；指标直接连到 AI计算并在参数列说明 | 直接连到 AI计算：以前目标值对全部指标都起作用，参数列从不为空；去掉后只选城区面积覆盖率时参数列为空，编排图的连线也会断开 |

## 决定

- 参数只有计算规程、覆盖认定、常住人口变化；结果只有区县、市和全省的值
- 推演 8 个步骤：条件解析 → 人口、设施、用地（并行）→ 数据核查 → 空间分析 → 指标计算 → 结论生成；结论按条件里的顺序汇总各项的值，模拟情景时写和标准口径的差
- 预估栏、人工干预的预估只写预估值和相对标准口径的变化；结果列表只写结果，条长按最大值；地图只按数值五档着色，城市标注的圆点统一主色
- 对话不再理解按达标着色、改目标值；说到"目标"时回复"计算结果只给出各项指标的值，不设置目标值"，不改条件
- 所选指标都没有可调的参数时，计算参数列写"所选指标没有可调整的计算参数"，指标直接连到 AI计算

## 后果

- 全程默认时长从约 22.1 秒变为约 19.7 秒，流程图少一列
- 结果的数字不变（同样的条件和参数得到同样的值），只是不再和目标值比较
- 以前说过的"按达标着色"等现在当作没听懂，回复里的示例同步去掉
