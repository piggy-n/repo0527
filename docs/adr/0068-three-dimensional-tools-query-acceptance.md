# ADR 0068：三维公共工具、查询范围与验收边界

- 状态：接受（3D.4，沿用 ADR 0064 的首期范围）
- 日期：2026-10-19
- 补充：ADR 0034、0047～0051、0064～0067

## 背景

三维已经镜像会话样式，但工具还没有声明视图能力。原框选直接连接四角的经纬度，在倾斜的球面上不一定贴合屏幕框；天空拾取失败后退回空的渲染查询，会误报没有结果。切换候选的失败也不能当作当前地图的引擎失败。

## 决定

### 工具和读数

`MapTool.supportedViews` 声明支持的视图，省略时保持兼容二三维。适配器通过 `toolFor(kind)` 取生效的光标、手势和输入处理：不支持时采用浏览手势，但不修改当前工具 ID、不调用 activate/deactivate。公共指针事件继续用于状态栏，暂停的工具不接收操作，包括 Esc。

当前浏览、距离/面积测量、位置拾取和点/框选都支持二三维。切走视图会结束指针预览和框选草稿，测量已确定点、已完成结果和已经生成地理范围的查询继续保留。框选监听视图身份并同步清草稿，避免同一轮 detach/attach 被合并后漏掉清理。

测量继续使用 geographiclib 的椭球距离与面积。状态栏读数保留实际 `surface` 和椭球基准 `height`；投影或拾取失败就没有坐标。现有界面仍只显示经纬度、比例尺和角度，不添加高度栏，不把椭球零高程写成地形或国家高程。新增高度界面仍需设计确认。

### 三维查询范围

二维的查询契约不变。三维不依赖 `queryRendered()` 的空数组估数，也不启动隐藏二维查询；仍只查询 ADR 0048 登记的五个数据集，使用后端第一页 30 条和总数。5000 是二维渲染估数拒绝阈值，不把它解释为后端总数上限。

三维框选和点、线的点击容差框沿屏幕边缘细分。每段屏幕长度至多 64 像素，并检查经纬度直线的四分之一、二分之一、四分之三位置投影偏差；天空、跨经线、退化范围和超出预算明确拒绝。面点选仍使用拾取到的单点。

有区划时先和 `readyBoundary` 求交，保持遮罩与查询范围一致。所有三维多边形都经过 `queryGeometry` 的有效性、舍入和最多 120 个坐标检查，包括没有区划的框。简化候选还需双向比较对应边界环的投影偏差；洞和岛不能在比较时丢失。屏幕边缘、曲线细分和简化分别保留误差余量，真实 Cesium 测试用更密的独立采样复核最终偏差不超过 2 像素。

这是有点数、递归深度和比较次数预算的采样验证，不是对任意投影曲线的解析证明。无法验证的范围不发请求，在既有详情提示区域显示调整视角或缩小范围、不伪称没有要素；沿用逐资源查询顺序，已验证的上层面点选仍可执行。已有地理范围生成后不随相机移动或切换重新计算。

本步不凭空增加面积或级别的业务阈值。120 点约束请求复杂度，不约束范围内要素数量、后端统计耗时或返回总数；真实服务的范围成本需要另行测量后决定限制。

### 页面与加载

现状底图复用已确认的基础组 2D/3D 按钮，默认二维。应用通过路由属性提供资源地址和运行时准备函数，页面不导入 app。切换画布保留原二维的缩放范围和滚轮速率。

按钮只发出意图，按下状态取已经交接的视图。加载期间允许返回原视图作废候选切换。加载与失败使用已有地图提示区域；候选失败时重试交给切换拥有者，不能调用只接受当前引擎失败的 `MapContext.retry()`。缓存、失败恢复和 KeepAlive 暂停继续由 `MapViewSwitch` 管理。

### 性能与释放

用本地数据和真实 Chromium/WebGL/Worker 验收，不在自动化中请求后端或天地图。分别记录冷创建、热切换、连续相机变化、暂停恢复和销毁，时间与功能等待上限分开报告。

项目 MVT Worker 必须遵守池大小、排队上限与数据缓存字节预算，完成/取消后没有进行中任务，销毁后终止；转移位图消费或晚到时都关闭。默认 64 MiB 只包括自有瓦片数据缓存，不包括 Canvas、位图和 SDK/GPU 内存。

SDK 资源通过公开生命周期和 WebGL create/delete 接口验收，不访问或强行关闭 SDK 私有 Worker。软件 WebGL 的耗时不能当作实际显卡帧率，资源计数也不能换算成进程总内存。独立报告 SDK 跨实例保留、共享与释放的观测结果。

固定 SDK 版本实测 `widget.destroy()` 后仍有地形缓冲通过 `isBuffer()` 检查。最终销毁后对本视图独占的画布调用公开 `WEBGL_lose_context.loseContext()`，使残余句柄失效；这不等同于所有对象都显式调用了 delete。暂停与缓存切换不关闭上下文。浏览器没有此扩展时仍销毁 SDK，其余 GPU 回收由浏览器完成，不能承诺立即回收。

已撤销的 MVT 提供者请求向 SDK 兑现透明占位，避免 SDK 把正常取消打印成瓦片故障；仅在本次取消信号已经中止时使用，真实网络、解码和绘制错误照常拒绝。底层 Worker 的取消仍是 AbortError，晚到位图仍关闭，恢复仍重建提供者追赶有效内容。

## 备选方案

- 只用四角：实现最少，但倾斜球面误差无法满足查询约定
- 三维调用隐藏二维查询：需要同步两套视口，违背 ADR 0064 的查询边界
- 不支持的工具切回浏览：会调用退出逻辑，丢失应当保留的状态
- 新建三维专属工具栏或高度面板：首期没有必要，增加设计和状态分支
- 只提高等待超时作为性能验收：只能证明最终完成，不能说明耗时或释放是否符合预期

## 学习点

能力声明和当前工具身份是两件事；投影后的直线与经纬度直线也不是一件事。跨视图共享应复用会话状态和业务查询协议，把差异限制在输入、投影和视图生命周期中。性能证据需要注明测量对象与环境，避免把缓存预算、GPU 对象数和应用总内存混为一谈。
