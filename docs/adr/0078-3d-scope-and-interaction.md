# 0078. 三维阶段的范围与交互

- 状态：已接受（2026-10-26 用户确认交互原型 `/dev/map-3d`）
- 日期：2026-10-26

## 背景

三维阶段在 2026-10-20 暂缓，等重新调研和设计。2026-10-26 用户提出本阶段的需求：

1. 范围：二维 / 三维切换、三维地图展示、三维工具栏及其功能、3DT 模型的加载与展示、漫游；暂不接入 MVT
2. 3DT：展示全省的 3DT 资源列表，按需加载和卸载模型，列表状态和地图一致
3. 漫游：只保留第一视角，新增路线漫游，支持开始、暂停与退出
4. 验收：二三维切换、三维显示与 3DT、工具栏和两种漫游都能用，二维不受影响，不涉及 MVT

读旧代码（`master-demo` 的 `6b4799b`，`views/current-map-new/cesium/` 等约 9000 行，基线见 [migration.md](../migration.md)）得到的事实：

- 旧项目只有两份本地模型：苏州一座地铁车站（`public/SZ_3DT`，约 90 MB）和苏州白膜（`public/SZ_WhiteModel`，三种效果各一套瓦片），都不入库；资源树接口只返回矢量图层，所有分支里都没有"全省 3DT 列表"
- 旧的漫游是车站里的步行：导航网格判断碰撞和楼层，点击移动，第一人称和第三人称（人物模型）可以切换，有室内小地图，地下模型配有"钻地"和地表透明度；没有路线漫游
- 旧的三维沿用二维的工具栏，测量时把透明的二维画布叠在三维上面接管鼠标

调研后的问题由用户回答（2026-10-26），原型据此画出并确认。

## 决定

### 1. 范围

本阶段做二三维切换、三维地图展示（底图和二维的覆盖物：行政区边界、区划、测量结果、位置点）、三维工具栏、3DT 的加载与展示、漫游。资源图层（矢量瓦片）在三维里不显示，按支持清单跳过（ADR 0079 第 7 节）。

### 2. 切换与底图

- 入口是基础组的 2D / 3D 两格（ADR 0053 第 3 节），当前的一格高亮
- 二维切三维时默认选影像底图，三维切二维时默认选矢量底图；没有这种底图（内网关闭天地图）时保持原样
- 切换时先退出漫游、结束钻地

### 3. 3DT 清单

全省的 3DT 资源用部署目录里的一份静态清单（JSON）描述：名称、所属市、类型（倾斜摄影、白膜、室内）、tileset 地址、是否在地下、步行的出生点、预置的漫游路线、白膜的各套效果。前端读入后用 zod 校验，不合法的清单整体按加载失败处理。以后后端提供接口时只换读取的来源。清单的字段和地址在 3D.3 定稿。

### 4. 三维模型面板

- 3DT 列表不放在工具栏上：三维时左侧的资源图层面板换成"三维模型"面板，切回二维时换回来，两边的收起状态各自保留
- 外观和资源图层面板一致：宽 320、浅灰标题栏、收起后是左上角的竖条"三维模型"
- 目录按市分组、带数量，可按模型名或所属市搜索；勾选即加载，取消即卸载
- 底部的"已加载"按加载的先后排列，每行有定位、卸载，可以步行漫游的有"步行漫游"，有预置路线的有"路线漫游"（下拉选择路线），白膜可以换效果
- 加载中显示转圈；失败时目录行标红"失败"，"已加载"里显示"加载失败"和"重试"，定位不可用；最近定位或正在漫游的行左侧有蓝条，并标"漫游中""钻地"
- 清单正在加载、加载失败（可重试）、没有模型、搜不到模型各有提示

### 5. 钻地

定位到地下的模型时进入钻地观察：地表变成半透明，地图下方居中显示"钻地观察"条（地表不透明度 0～60%，退出钻地）。漫游期间不显示这一条。

### 6. 漫游

- **步行漫游（第一人称）**：迁移旧版车站步行的全部能力（导航网格碰撞、楼梯、点击移动、W/A/S/D、右键拖动转向、滚轮调视场角、速度档位 0.5～8 m/s 默认 1.6、回到出生点、脱困、小地图，展开后双击瞬移）。第三人称和人物模型的代码一并迁移，暂不开放入口
- **路线漫游**：路线随清单预置。选择后先停在起点，可以开始、暂停、继续、到终点后重新开始，以及退出；显示走过的距离、总长和剩余时间，速度有 0.5×、1×、2× 三档；暂停时可以拖动查看四周，继续后回到路线视角
- 漫游操作条在地图下方居中、状态栏上方；手机宽度时横跨三列。空格暂停或继续路线漫游，Esc 退出漫游
- 漫游接管鼠标，相当于一个工具：选工具栏上的工具、切换到二维时先退出漫游

### 7. 工具栏

- 二维的按钮全部保留
- 点/框选在三维里可以选中，鼠标旁用 `PointerHint` 提示"三维模式暂不支持点/框选 / 切换到二维后使用"，点击没有效果
- 图例面板在三维里说明"三维模式暂不显示资源图层，图例在切回二维后可用"
- 测距、测面、区划定位、坐标定位、行政区、清除在三维里照常使用，测量拾取地表或模型（ADR 0024 第 2、4 条）

### 8. 状态栏

二维仍是比例尺和经纬度。三维显示视点高度、经纬度和俯仰；步行时显示第一视角、眼高和朝向；路线漫游时显示视点高度。

### 9. 分步

| 步骤 | 内容 |
|---|---|
| 3D.1 | Cesium 运行时与静态资源、map-cesium 的三维视图（生命周期、相机换算与同步、定位、拾取、投影、输入）、栅格底图的镜像、map-vue 的多视图与切换、现状底图的 2D/3D 和底图规则 |
| 3D.2 | GeoJSON 覆盖物的镜像（边界、区划与遮罩、测量、位置点），三维的测量与修饰键平移，点/框选提示、图例说明、三维状态栏 |
| 3D.3 | 3DT 清单、三维模型面板、模型的加载卸载与定位、白膜效果、钻地观察 |
| 3D.4 | 步行漫游（导航网格 Worker、碰撞、小地图）、第三人称的代码、路线漫游 |
| 3D.5 | 加载耗时实测与预加载、页面缓存、生产冒烟、阶段总结 |

每一步先读对应的旧代码、补充需要的 ADR，再实现和验收。

## 后果

- 好处：交互在原型上确认过，实现时只需要对照原型和本 ADR
- 好处：3DT 的来源先用静态清单，不等后端；换成接口时只改读取
- 代价：资源图层在三维里看不到，用户切到三维后需要靠图例面板的说明理解；MVT 接入另起阶段
- 代价：第三人称的代码迁移了但暂不开放，要保持它可以运行（测试覆盖），直到开放或删除
- 待定：清单的字段与部署地址（3D.3）、导航网格和漫游的技术方案（3D.4）、Cesium 是否预加载（3D.5）
