# 0112. 数据查询的按钮参考旧页面，结果从左侧开始

- 状态：已接受
- 日期：2026-10-29
- 修改：ADR 0104 第 2 节（标题下一行四个页签）、第 3 节的面板与结果排布

## 背景

用户 2026-10-29 要求国土变更调查、城市国土空间监测两个专题的条件布局参考旧页面的按钮结构和排列，保留现在的小标题，颜色和样式按新规范；查询结果可以从页面左侧开始、盖住条件区，优先保证结果的空间。

旧页面：查询方式是整行的分段按钮（`el-radio-group`）；"添加查询条件""显示 SQL 语句"是整行的描边按钮；查询、重置各占一半；高级查询是面板右边单独的按钮和第二个面板；结果在页面底部、横跨整页。

原型（`public/design.local/data-query/`，不入库）加了"现行布局 / 参考旧项目"的切换，以及"高级查询单独按钮""结果从左侧开始""查询面板让出结果的高度"三个选项。用户确认：高级查询放进按钮组、排在自然语言查询之前，不要单独的按钮；其余按原型的推荐。

## 决定

- 查询方式：`ElRadioGroup class="radio-group-block" size="small"`，四项等宽占满一行（属性查询、空间查询、高级查询、自然语言查询），在标题栏下面（`MxPanel` 的 `subheader`）。主题里 `radio-group-block` 的左右内边距收到 6：文字居中，内边距只决定最长一项的最小宽度，"自然语言查询"等四项放得进 320 的面板（坐标定位的写法切换不受影响）
- 属性查询："添加查询条件"是条件列表下面整行的主色描边按钮（`type="primary" plain`），点开是还没加的字段；"显示 SQL 语句"同样是整行的描边按钮（自然语言查询共用）；区块的小标题不变
- 底栏：查询在前、重置在后，各占一半（同筛选栏 `QueryForm` 的"查询 / 重置"）
- 结果：查询面板和结果放在同一列（左列加中列）。面板在上、按内容定高；结果贴底、从左边开始，右边给底图卡让出 40；有结果时面板让出结果的高度，表单在面板内部滚动，查询按钮始终露在结果上方；结果最大化时占满整列，面板不显示；窄屏时结果停在底图卡上方，左边是竖条（`useSideExclusion` 不变）

## 后果

- 结果比原来宽（从左边开始），表格的列显示得更全；有结果时查询面板变矮
- 测试：查询方式是按钮组、高级查询在自然语言查询之前；"添加查询条件"在条件下面、选图层前不可用；底栏查询在前。生产冒烟改按按钮组切换方式
- 建设中的两个专题没有按钮组和底栏，不受影响
