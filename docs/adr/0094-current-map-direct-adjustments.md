# 0094. 现状底图的直接调整：复合图例默认展开、目录全部展开、批量年份加 2020 与 2021、「已选择图层」、步行默认 4 m/s

- 状态：已接受
- 日期：2026-10-28
- 修改 ADR 0066（复杂图例默认显示摘要）、ADR 0052 第 2 节（可选的年份、没有这一年时抛错）、ADR 0081 第 7 节（最近定位的行标蓝条）、ADR 0086 第 5 节（步行默认 1.6 m/s）

## 背景

用户 2026-10-28 提出现状底图的一轮优化，要求可以直接调整的按要求实施，涉及重新设计的布局或交互先出方案确认。按这个要求分成 7 步（见 roadmap"现状底图的调整（2026-10-28）"），本 ADR 是第一步：只改默认值、文案和一条选项规则的几项。

用户同时就几个有歧义的地方做了选择：

- 批量设置年份要加 2020、2021。按现在的目录，没有资源有 2020 年的数据；2021 年只出现在单年份的资源里（如城镇村地类图斑，ADR 0052 背景），批量选这两年地图都不会变。用户选"固定加上"：以后数据补上自动生效
- 其他三个问题（图层顺序、状态栏的位置、漫游面板里的路线）属于后面的步骤，在各自的 ADR 里记

## 候选方案

| 问题 | 候选 | 选择与理由 |
|---|---|---|
| 复合图例怎样默认展开 | 记下展开的条目、新勾选的默认加进去；改成记下收起的条目 | 记下收起的：默认值就是"没有收起"，不用在勾选变化时同步；收起是图例自己的界面状态，按 `code` 记、不持久化，和以前的展开一样 |
| "没有选中图层时默认展开所有树节点" | 只在目录第一次到达时判断；每次勾选数变成 0 时都展开 | 只在第一次：用户在页面里展开、收起的不被打断，页面缓存期间保留（ADR 0063）；"再次进入页面"指重新登录、刷新以后 |
| 批量年份的选项 | 固定加上 2020、2021；从 2020 起逐年列到最新；先不加，等数据 | 固定加上（用户选）：只加要求的两年，其余仍按数据（多年份资源的年份并集） |
| 选了没有数据的年份 | 拥有者照旧抛错，面板先判断；拥有者不再抛错，面板提示 | 不再抛错：这一年已经是界面上的合法选项；"没有资源要改"本来就不替换状态，没有资源有这一年只是它的一种情况。提示由面板给（组合式函数不弹提示） |
| 去掉最近定位的蓝条后 `focus` 状态 | 保留；一并去掉 | 一并去掉：只有这个样式用它 |

## 决定

### 1. 复合图例默认展开

- 按类别配色、地类这类复合图例默认展开；用户收起的按 `code` 记在图例里，新勾选的复合图例展开，收起过的再勾选仍收起；不持久化
- 收起时仍是多色块摘要，统一配色和单一符号不变

### 2. 资源目录：一个也没有勾选时全部展开

- 目录第一次到达时，有勾选的资源就展开含有它们的分类（不变）；一个也没有勾选时展开全部分类（`expandedByDefault`）
- 之后目录刷新、勾选变化不改用户的展开（不变）

### 3. 批量设置年份加上 2020、2021

- 可选的年份：多年份资源的年份并集，加上固定的 2020、2021，新的在前；其他只出现在单年份资源里的年份仍不列出（`batchYearOptions`）
- 没有任何资源有这一年时什么也不改，不再抛错；年份不是整数时抛错（`withYearForAll`）
- 面板选了没有数据的年份时提示"没有资源有 2020 年的数据，图层保持不变"（`ElMessage.info`），判断用纯函数 `hasYearData`；有资源有这一年但都已经是这一年时不提示（同以前）
- 没有多年份资源时选择框也显示，只有 2021、2020

### 4. 「已勾选」改名「已选择图层」

- 资源图层面板下半区的标题、展开收起入口和分割线的无障碍名称都改成"已选择图层"；代码注释和测试里指这块区域的说法同步，描述勾选状态的"已勾选的资源"不改

### 5. 三维的几处

- 清单里苏州站模型的名称改为"星海广场站"（`public/3dt/manifest.json`，模型 ID 和数据目录不变）
- "已加载"的行不再标出最近定位的模型（去掉左侧 3 像素的蓝条），拥有者的 `focus` 一并去掉
- 步行操作条的"回到出生点"改为"回到起始点"，"附近没有开阔的地面"的提示同步；代码里仍叫出生点（`spawn`）
- 步行的默认速度从 1.6 m/s 改为 4 m/s（`DEFAULT_WALK_SPEED`，档位不变）；路线漫游的速度在漫游面板的设计里定

## 后果

- 图例的测试大多先点"展开"，改为默认展开以后去掉这一步；改坏验证（默认展开、全部展开、固定年份、没有数据的提示、默认速度、文案）都由断言测出
- 批量选 2020、2021 现在只会看到提示，等后端有这两年的多年份数据才会切换（记进 roadmap 的待办）
- 地下空间、漫游入口、漫游面板、钻地和图层顺序的调整在后面几步，另写 ADR
