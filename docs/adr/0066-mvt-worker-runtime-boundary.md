# 0066. MVT Worker 的运行环境入口与缓存边界

- 状态：已接受（用户确认受限 Worker 子入口）
- 日期：2026-10-19
- 补充 ADR 0004、0021、0025、0064、0065

## 背景

3D.3b 开始执行真实 MVT 任务。下载、解码和缓存按既定决策放在 map-core，三维绘制放在 map-cesium，通信复用 utils。Worker 必须单独使用 WebWorker 类型环境；当前 map-core 的唯一入口同时导出 MapLibreView 等 DOM 实现，即使只使用瓦片服务，类型检查仍会遍历这些源码。

## 入口选择

为 map-core 增加一个明确的 `@yzt/map-core/worker` 子入口，只导出引擎无关的瓦片协议、下载、解码和缓存能力。它不导入主入口、MapLibre 或 DOM 实现。主线程继续从 `@yzt/map-core` 使用公共能力，内部仍用相对导入；别名、依赖规则与独立 Worker 类型检查共同约束边界。

替代方案是现在把瓦片服务拆为独立模块，但会扩大本步目录、依赖与文档调整。将 DOM 与 WebWorker 类型混在一起，或按环境把同一个别名偷偷指向不同入口，都不能清楚表达运行环境，因此不采用。

## 沿用的实现约束

- 每个三维视图拥有惰性 Worker 池；暂停取消未完成任务并保留已完成缓存，恢复时按最新样式请求，释放视图即终止 Worker，不使用跨会话全局池
- 数据身份包含来源地址、数据版本、权限范围和原生父瓦片坐标；同一父瓦片固定分配到同一个 Worker，显示子瓦片重新绘制，不放大父位图代替
- 同一数据的下载和解码按消费者共享；每个消费者独立取消，最后一个离开才取消底层任务。失败不缓存，合法空瓦片可以缓存
- 字段按同源图层的样式、过滤及身份需求取并集；字段变化重新解码。解码缓存留在 Worker，位图一次性转移，晚到位图关闭
- 仅内存 LRU，命中刷新顺序，按原始数据和解码结果的估算字节控制预算；不增加持久化缓存，不截取 MapLibre 请求，跨引擎复用暂依赖 HTTP 缓存
- 池数量、并发与预算是可配置参数，以本地合成任务和真实瓦片实测记录校准；本步不宣称完成省域性能验收

## 首次实现的参数与边界

3D.3b 初始配置为 2 个惰性 Worker、合计 64 MiB 驻留数据缓存、最多 16 个未完成请求，每个 Worker 同时执行 4 个任务。父瓦片身份的确定性散列决定线程，不另存持续增长的分配表。预算平分到线程，包含原始数据与解码结果的估算字节，不包含执行中的工作集、位图或 Cesium 纹理；超预算单瓦片可完成当前任务但不驻留。

隐藏图层、替换提供者、暂停和销毁会取消相应任务。当前精确版本 Cesium 没有公开的单瓦片丢弃通知可供自定义异步提供者使用；平移时已经不需要的单个任务可能继续到完成。本步不访问私有 RequestScheduler 或 Request 字段，先以有界任务池限制数量；3D.4 单独验收快速平移的延迟与内存。

真实地类瓦片的下载去重、父子复用和超预算处理已经实测；同一父瓦片只落到一个线程，不能以此证明 2 个 Worker 的性能收益。数据及测量边界见 [3D.3b 记录](../stages/stage-3d-3b-mvt-worker.md)。

## 验收

验证源图层、属性过滤、promoteId、孔洞与多几何，父瓦片复用及像素尺寸；验证下载去重、字段扩展、LRU、超预算、独立取消、暂停/销毁、Worker 崩溃与晚到产物释放。真实浏览器执行 Worker 与 Cesium 集成测试，自动化仅使用合成数据。真实业务瓦片只做独立只读实测，不入库。
