# 0057. 右下角的卡片与行政区边界的线型

- 状态：已接受
- 日期：2026-10-16
- 修正 ADR 0033 第 3 节（每一级一条线、线的样式照搬旧项目）、ADR 0053 第 7 节（卡片在面板打开时的外观）

## 背景

用户在 5D 打标签之后的优化意见（第三步）里提出：

- 图例卡、底图卡的文字不在一条线上。量得两者差 7 像素：图例卡是图标加文字整体居中，底图卡是缩略图铺满、文字压在底部
- 两张卡片和地图区分不明显：矢量底图的缩略图铺满卡片，放在矢量底图上看不出卡片的边界
- 底图卡写"底图"，没有说明当前是哪种底图
- 省界和市界不好区分：三级都是 `#597EF7`，只靠线宽和不透明度区分

设计稿（静态 HTML，不入库）用真实的 MapLibre、天地图瓦片和项目里的边界数据，比较了两种卡片和四种线型。数据上有两点影响方案：

- 市界和省界在共用的边上顶点完全一致，所以省界是实线时能盖住下面的市界
- 县界是另一份更粗的数据，和市界一个点都不重合

## 候选方案

| 问题 | 候选 | 选择 |
|---|---|---|
| 卡片的结构 | A 白底卡片，上图下字；B 白边里铺满，字压在半透明条上 | A（用户选择）：两张卡片结构相同，文字天然对齐；缩略图四周有白边和细边框，放在矢量底图上也看得出卡片 |
| 面板打开时的外观 | 浅主色底加主色细边（ADR 0053 第 7 节）；外边框 | 外边框（用户要求）：和键盘焦点同一个位置，颜色用主色；缩略图周围不加圈 |
| 底图卡的文字 | "底图"；"矢量底图"；"矢量" | 简称"矢量""影像"：四个字在 56 宽里要缩小字号；无障碍名称写全称 |
| 线型 | 现状；方案一：省界加色带、核心线更深，省市下面加白边；方案二：点划线；方案三：每级换颜色 | 方案一（用户选择）：省市都是实线，共用的边上一级盖住下一级；白边让影像底图上的线更清楚。方案二的市界会从省界点划的空隙里露出来，要先处理数据；方案三的紫色和天地图高速公路的紫色撞色 |

## 决定

### 1. 卡片

**结构和尺寸**

- 56 × 56 的白底卡片（`--color-bg-mask`、`--shadow-md`、`--radius-md`），四周留 4
- 上面是 48 × 30 的图：
  - 图例卡：浅灰底上居中的图标
  - 底图卡：铺满的缩略图，加一圈 `--color-border` 的细边
- 下面一行字，字号 12、行高 16；两张卡片的字都在卡片内 35～52 像素
- 尺寸不变，所以卡片行的位置和手机宽度的排法（ADR 0053 第 8 节）都不受影响

**状态**

| 状态 | 外观 |
|---|---|
| 悬停 | `--color-primary-bg-light` 底，文字和图标变主色 |
| 面板打开 | 外面 2 像素的主色边框（离卡片 1 像素，和键盘焦点同一个位置），文字和图标变主色；缩略图不加圈 |
| 键盘焦点 | 同样位置的 `--color-primary-border-hover` 边框 |
| 面板打开时又有键盘焦点 | 主色边框外面再加一圈焦点色 |

面板打开时卡片和工具栏按钮的外观不同（工具栏是浅主色底）：卡片是图片入口，用外边框更醒目，也不会盖住缩略图。

**底图卡的文字**

- 写当前底图的简称：矢量、影像、无底图
- 无障碍名称写全称，例如"底图：矢量底图"
- 为此 `MapCard` 加一个 `name` 属性，用来给出无障碍名称；名称要包含显示的文字

### 2. 行政区边界的线型

**图层**

- 每一级由几条线叠成，共用这一级的数据源
- 核心线的 ID 仍然是 `boundaries-province` 等；色带、白边的 ID 是 `boundaries-province-band`、`boundaries-province-casing` 这样在后面加上部位
- 各级之间的叠放仍是县、市、省从下到上；一级之内是色带、白边、核心线从下到上

**样式**

| 级别 | 从下到上的线 |
|---|---|
| 省界 | 主色色带：宽 7～16，不透明度 0.22，虚化 1<br>白边：宽 3.4～5.6，不透明度 0.7<br>核心线：`#2F54EB`，宽 1.8～3.2，不透明 |
| 市界 | 白边：宽 2.4～4，不透明度 0.6<br>主色实线：宽 1～2，不透明度 0.95 |
| 县界 | 主色虚线（3、2）：宽 0.8～1.4，不透明度 0.8 |

- 省、市都是实线。在共用的边上，省界的核心线（不透明，各级都不比市界的窄）和白边（不比市界的白边窄）盖住市界
- 每一级的线从下到上一条比一条窄，这样才露得出下面的白边和色带
- 状态里的透明度乘在每一条线上
- 颜色是地图样式的数据，写在 `boundary-style.ts`，不走 CSS 令牌

**面板里的线型示意**

- 改成 SVG，从下到上叠同样的几条线
- 线宽取中间一档：省界、市界是 9 级，县界是 11 级
- 宽 24，高度放得下最宽的那条线
- 色带的虚化只有 1 像素，示意里不画
- 虚线的线段和间隔按线宽换算，圆头画在线段外面，和 MapLibre 的圆头虚线一样（见 `line_atlas.ts` 的 `addRoundDash`）

### 3. 验收

**单元测试**

- 线型：每条线的 ID、颜色、宽度、不透明度
- 省界盖住市界的宽度关系
- 透明度乘在每一条线上
- 面板里的示意
- 卡片的结构和无障碍名称
- 页面上底图卡的文字和缩略图跟着当前底图变化

**设计稿和真实页面**

- 设计稿上对比过 6.8、9、11 级和影像底图
- 真实页面上核对卡片的各种状态和线型

## 后果

**好处**

- 省界一眼就能认出来
- 影像底图上三级线都更清楚
- 两张卡片的文字对齐，和地图分得开，底图卡说明了当前底图

**代价**

- 每一级多了一两个图层（省界 3 个、市界 2 个、县界 1 个），绘制上看不出影响
- 色带在 6.8 级时比较醒目
- 县界和市界不重合的问题还在：沿着市界能看到旁边有一条县界的虚线。要换更准确的县界数据才能解决，已记进待办
