# 指标智能推演

纯前端的"城市国土空间监测指标 AI 模拟计算"：编排计算条件，看 AI 分步推演，可以人工干预，在地图和图表上看结果、对比版本。全部是确定性的模拟数据，不接后端。设计与取舍见 [ADR 0102](../adr/0102-indicator-simulation.md)。

## 交互原型

第二版原型（2026-10-28 用户确认）是开发的依据，不入库：

- 页面：`apps/web/public/design.local/indicator-simulation/`；第一版留在同级的 `indicator-simulation-v1/` 作对照
- 素材脚本：`apps/web/design.local/indicator-simulation/build.mjs` 生成指标值、区县摘要、边界副本和依赖副本；`serve.mjs` 起一个只读 `public`、到时自动退出的本地预览（`node apps/web/design.local/indicator-simulation/serve.mjs 5189`，用 localhost 打开，天地图按来源限制访问）
- 原型用 GSAP 的时间线兼作推演时钟、直接操作 MapLibre，正式实现按 ADR 0102 拆开，不照搬原型代码

## 分步实施

分支 `indicator-simulation`，独立 worktree，从本地 main `3068b55` 开始。每一步单独提交，界面相关的步骤在真实页面验证后交给用户看。

| 步骤 | 内容 | 状态 |
|---|---|---|
| S1 | 菜单"智能体"（一层下拉）与路由，页面先用占位页 | 完成 |
| S2 | 驾驶舱的指标目录与生成函数移到 shared，驾驶舱行为不变 | 未开始 |
| S3 | 推演模型：区县分解、覆盖率与人均两类模型、多年度、缺失人口、建议情景、敏感性、变化归因、设施撒点（纯函数与测试） | 未开始 |
| S4 | 推演引擎：步骤状态、人工确认、干预后的失效与复用、版本；时钟注入，假时钟测试 | 未开始 |
| S5 | 条件编排：条件库、五列编排图（拖入、移除、指标排序、参数节点与情景作用范围） | 未开始 |
| S6 | 推演界面：竖向步骤、当前步骤详情、阶段条、人工干预、停止、面板收起，以及推演动效 | 未开始 |
| S7 | 地图：区县分级、设施点与服务圈、城外遮罩、扫描、城市标注，与推演联动 | 未开始 |
| S8 | 结果：结果面板与图表、版本对比、多年度、干预预览 | 未开始 |
| S9 | 页面缓存、减少动画、尺寸与交互验收、文档和阶段总结 | 未开始 |

## 菜单

顶部导航的"智能体"是一层下拉（`menus.ts` 的 `kind: 'menu'`），面板只有一列页面，没有分组列；窄屏菜单里在标题下直接列出缩进的页面，不显示分组名。两级下拉（`kind: 'dropdown'`，如"查询统计"）不变。导航配置与宽度适配见 [layout.md](layout.md)。
