## 旧入口与资源

## 数据口径

目录来自旧根目录 `data.json` 和 `data2.json`，归并为安全韧性 5 项、创新高效/开放繁荣 27 项、共享幸福 44 项、协调节约 20 项，共 96 项。排除的 7 项及来源字段保留旧 `mock/DATA-NOTES.md` 的结论，不重新解释相近指标的业务含义。

旧 `dashboardData.js` 按年份、城市编码、指标编码建立唯一索引。2026 年时生成 2017–2026 共 12,480 条固定模拟记录，页面开放 2021–2026，默认 2026、2025 和全部 13 市。数值按固定编码/年份散列及 2025 参数锚点生成，刷新不重新随机；数据范围会随自然年滚动，页面开放年份由独立配置决定。

这些记录没有真实统计接口背书。原目录的 sampleValue 不绑定真实城市和年份；城市特征、排名、覆盖率、发展曲线均是假设。未来只替换数据适配入口，不能把本轮模拟数据验收表述为真实业务验收。

| 行为 | 应保留的口径 |
|---|---|
| 比较年份 | 可多选、移除、清空；内部按年份排序，地图当前年份必须属于所选年份，否则回到最新年份或 null |
| 城市 | 默认全选；取消后地图灰化、保留名称，图表移除该市并重算均值；不把空集合当作零 |
| 指标分类 | 切换后选择该类第一项，右侧显示该类全部卡片并复位滚动 |
| 具体指标 | 左侧选择更新地图并定位右侧卡片；点右侧标题更新地图但保留列表位置；滚轮翻卡不修改指标 |
| 地图时间轴 | 只切地图当前年份，不修改比较年份或最新年份均值 |
| 均值 | 每年分别计算所选城市算术平均，顶部与均值线只用最新所选年份；开关属于卡片，不影响摘要与 Tooltip |
| 柱图 | 1–3 年并列，超过 3 年沿用旧版按城市堆叠；轴名明确“年度值累计”，禁用均值线，不解释为覆盖率或总评分 |
| 图表类型 | 每个指标有语义配置的默认类型；卡片和详情共享手动类型、均值偏好；切类别会重建卡片，旧版不会跨类别持久化这些偏好 |
| 图例 | 按年份固定配色，隐藏年份影响对应视图与 Tooltip；详情初始复制卡片图例，详情后续图例状态独立 |
| Tooltip | 地图和卡片使用地图标题下方的唯一固定表格；来源/指标/城市分离，180ms 延迟关闭，可移入滚动；详情使用弹窗内浮层 |
| 地图详情 | 地图区域、标签和二维降级点击打开当前指标详情，强调该城市；未选城市注明未纳入筛选，不自动勾回 |
| 单位 | 数量按整数，比例/面积/密度按指标精度；均值至少一位小数；1:X 的值表示 X，均值是 X 的均值 |
| 导出 | 卡片导出当前卡片；详情导出放大画布与该视图图例状态；地图导出合成城市标签，均包含完整标题；旧地图 PNG 不包含页面上的分级图例和时间轴 |

## 分步实施方案（已确认）

### D1 数据、筛选与图表联动

`pages/city-dashboard/CityDashboardPage.tsx` 只组合 feature；`features/city-dashboard` 内分目录、模拟数据、纯计算、状态组合式函数和组件。页面局部共享状态通过有类型的 props / provide 传递，当前没有跨页面客户端状态需要 Pinia，也没有接口数据需要 Vue Query。

先将指标/城市/记录/筛选状态建模，迁移分级、均值、轴刻度和图表默认类型，再接年份、城市、分类、卡片定位、图表类型及唯一 Tooltip。保留现有素材和布局。每个小步骤补关键测试，故意破坏行为验证断言能发现问题。

学习点：可辨识联合表示有效值/缺失值；纯计算与响应式状态分离；按拥有者划分状态。替代方案是先照搬旧巨型卡片，但会让 Tooltip、图例、均值和详情继续混在一起，故不采用。

### D2 地图、详情与图片导出

迁移 Three.js 场景类及几何、材质、标签布局；场景不依赖 Vue，接收数据快照与窄回调接口。对象与监听登记到 DisposableStack；取消、失败降级和回调异常明确处理。组件负责尺寸和可见性，场景负责 GPU 资源。仍属于驾驶舱 feature，不为它扩充现状底图的 map-core。

详情复用 ElDialog + `dialog-panel-header` + MxTitle；业务图表选项由纯函数构建。导出保留用户当时的年份、指标、图例和城市快照，异步等待完成后检查操作有效性；防重复、可见失败反馈、卸载后不触发旧下载。补未选城市、长标题、图例变化、切换期间导出的测试。

学习点：适配器与资源所有权、异步操作快照、Canvas 与 DOM 标签分层。二维降级继续用 ECharts 地图，不引入另一套地图引擎。

### D3 动画、性能与完整验收

保留地图先入场、名称与着色、标题/面板、数值、边框分阶段的方向；通过明确阶段数据管理交互是否开放。隐藏时暂停、恢复时先更新尺寸；卸载结束等待并释放资源。校验减少动画偏好与 WebGL 创建失败/上下文丢失路径。

按路由懒加载检查产物；不改变登录页和现状底图的初始依赖。测量进入耗时、空闲重绘、切换响应、图表实例数和反复进入退出的资源趋势。CPU/GPU 的结论必须来自测量，不以 dispose 被调用或 Canvas 被移除替代泄漏验收。

### 风险与必要改进

- 旧场景 tick 即使不重绘也持续 requestAnimationFrame；正式阶段评估按需调度，动画期间保持连贯
- 旧地图加载重试在 await 后主要检查 disposed，未始终检查本次请求身份；正式代码应使用 LatestController，避免晚到结果覆盖
- 旧导出会等待字体和图片；仅固定标题还不等于固定全部标签数据，正式版应冻结整个导出输入并处理异常
- 旧 `ChartCard` 同时包含选项、Tooltip HTML、详情与导出，需按用途拆开；字符串提示在未来接外部数据时仍须转义或改为 DOM 渲染
- 旧类别切换重建卡片、离屏画布保留实例；D1 仅在可见区域附近创建图表，离开或隐藏时释放，偏好由数据拥有者保留；D3 再实测内存和切换性能，不改变偏好语义
- 原型是旧组件复用，不代表新 TSX 代码、正式鉴权、生命周期契约或真实数据已验收
