# 城市国土空间监测综合分析驾驶舱

相关决策：ADR 0163（公共部分在 `shared/dashboard`）；独立路由和菜单入口沿用城市体检驾驶舱的 ADR 0077、0110
对应目录：`apps/yzt/src/features/land-space-dashboard/`，页面 `apps/yzt/src/pages/land-space-dashboard/LandSpaceDashboardPage.tsx`

布局、视觉、入场、交互沿用城市体检驾驶舱（[city-dashboard](city-dashboard.md)）。外壳、筛选控件、图表卡片、立体地图、指北针和比例尺、提示、导出都是 `shared/dashboard` 的单元（用法见 [dashboard](dashboard.md)），这个 feature 只有数据、状态和组合：

```
features/land-space-dashboard/
├─ data/          land-space-2025.json（生成的数据）、land-space-data.ts（目录、读值、zod 校验）
├─ cards.ts       三张卡的卡位、图表类型、配色组
├─ composables/   useLandSpaceDashboard：筛选、一二三级的选择、三张卡的偏好
└─ components/    LandSpaceView（三栏组合）、LandSpaceCharts（三张卡、详情、下载）、PartTabs（分项栏）
```

## 入口

- 路由 `/land-space-analysis`，路由名 `RouteName.landSpaceDashboard`，`meta.title`"城市国土空间监测综合分析"；和 `/city-dashboard` 一样在 `AppLayout` 外懒加载，要登录、不限角色、不缓存
- 菜单"查询统计 → 专项统计"里"城市国土空间监测驾驶舱"后面的"城市国土空间监测综合分析驾驶舱"，新标签页打开
- 页面标题（h1）"江苏省城市国土空间监测综合分析"；加载耗时的标记名 `land-space-dashboard`（`DashboardShell` 的 `traceName`）

## 数据来源与口径

- 来源是《指标汇总.xlsx》，用 `pnpm --filter yzt land-space:data <xlsx 路径>` 转成 `data/land-space-2025.json`（见 [commands](../commands.md)），不手改；`land-space-data.ts` 加载时用 zod 校验一次
- 只取 2025 年的"现状值"和"全省汇总"，剔除 M51（公安派出所 5 分钟出警覆盖率）
- 单位为 % 的值存成百分数（57.48），"无量纲"的单位存成空字符串，标题不出现空括号；"不适用"和空单元格是 null（只有泰州的交通枢纽便捷度·与机场之间距离）
- 精度取 Excel 的数字格式，指数都是两位
- 均值是所选城市的算术平均（`shared/dashboard` 的 `compareIndicator`，至少保留一位小数），和原驾驶舱一致；数据里另有全省值（`LAND_SPACE_DATA.province`），界面目前不显示

### 层级

| 层级 | 来源 | 名称 | 值 |
|---|---|---|---|
| 一级（6 个） | 「指标字典」的一级分类：生活宜居便利性、公共资源人均享有度、公共服务均衡普惠性、城市安全韧性、交通网络通达性、建筑与住宅规模结构合理性 | 一级分类名 | 一级指数 I01、I09、I17、I20、I21、I27 |
| 二级 | 该一级下的二级指数，按字典顺序 | 「二级分类」名（如"养老便利性"，指数名是"福利设施便利性指数"） | 二级指数；I20、I27 既是一级也是它唯一的二级 |
| 三级 | 同一一级、同一二级分类下的单一指标 M*，按编码顺序 | 指标名 | 指标值 |
| 分项 | 只有 M62（3 项）、M63（4 项） | 「分项」列 | 值的 id 是 `M62:与一级公路之间距离`（`partValueId`），不带分项的值是"综合"，id 就是 `M62` |

体育活动便利性（I05）、养老便利性（I06）、城乡融合水平（I26）原报告没有列二级指数值（`hasValues: false`），保留在二级列表里，地图和二级卡显示"原报告未列指数值"，三级照常。

## 状态与联动

`useLandSpaceDashboard()` 是页面唯一的状态拥有者，组件只调用它的操作：

- 快照 `{ years, cityCodes, domainId, subIndexId, indicatorId, partId, activeYear }`，`partId` 为 null 是"综合"；默认第一个一级（生活宜居便利性）、它的第一个二级和三级、"综合"、13 个市、2025
- `selectDomain(id)`：选中这个一级的第一个二级、第一个三级和"综合"；再点当前一级也回到第一个二级，同原驾驶舱再点当前指标类型时回到第一个指标
- `selectSubIndex(id)`：只接受当前一级下的二级，选中它的第一个三级和"综合"
- `selectIndicator(id)`：只接受当前二级下的三级，分项回到"综合"；点当前三级不变
- `selectPart(id | null)`：只接受当前三级的分项
- `setCities`、`toggleCity`：和原驾驶舱一样，按 13 市的目录顺序去重
- `setYears`、`setActiveYear`：只有 2025 一年，空集合和数据里没有的年份都忽略，年份不会被清空（筛选里 `YearFilter` 的 `clearable` 为 false）
- 派生：`domain`、`subIndex`、`indicator`、`parts`、`part`、`cities`、三张卡的 `metas`、`comparisons`、`notice`、`classification`、`mapValues`、`preferences`

地图只跟二级：`mapValues`、`classification` 经过只返回二级指数编码、所选城市、年份的中间计算属性，它们的值不变时不通知下游，所以切三级、分项时两者是同一个对象，地图不重算。色阶以 13 个市 2025 年的二级指数为基准，不随城市筛选变；地图只写所选城市的值，其余城市为空（同原驾驶舱）。

图表偏好按卡位保存（`LandSpacePreferences`：一级、三级是 `ChartPreference`，二级是 `ChartPreference<ChartType>`），切换一级、二级、三级时不清空；默认一级柱、二级雷达、三级柱，均值线开。

## 三张卡（LandSpaceCharts）

右栏固定三张 `ChartCard`，`data-chart-id` 是卡位：

| 卡位 | 标题 | 图表配置的指标（`IndicatorMeta`） | 类型 | 配色组 |
|---|---|---|---|---|
| `domain` | 一级名称，如"生活宜居便利性" | 一级指数 | 柱、折线（默认柱） | 0 |
| `sub` | 二级名称，如"教育便利性" | 二级指数 | 柱、折线、雷达（默认雷达） | 1 |
| `indicator` | 下拉框，写三级名称和单位，如"交通干线便捷度（km）" | 三级；有分项时名称是"交通干线便捷度 · 与一级公路之间距离"（`PART_SEPARATOR`），值取分项 | 柱、折线（默认柱） | 2 |

- 颜色 `cardColor(card)` = `paletteColor(year, 组, 2025)`，同一张卡的图表、详情、提示同色
- 每张卡都有均值摘要"2025均值 X"、均值线开关、类型切换、放大、下载；读屏文字、放大和下载的按钮名、详情标题、下载的标题和文件名用指标的名称（三级带分项名）
- 标题不可点击，不加原驾驶舱的 `.selected`，不接翻卡导航；三张卡等分高度
- 雷达以所选城市为轴（`createRadarOption`），画布和详情都用 `hoverMode="none"`，提示是引擎自己的提示框；卡片里图例竖排在左上角
- 空态（有空态时均值线、下载停用）：二级没有指数值时"原报告未列指数值"；没选城市时"请选择城市后查看比较数据"；雷达且所选城市少于 3 个时"雷达图至少需要 3 个城市"
- 详情：`useChartDetail<LandSpaceCardId>`，目标是卡位；放大按钮打开对应卡位的详情，地图点城市打开二级卡的详情并强调这个城市
- 下载：`useChartDownload`，文件名"2025-{名称}"、详情加"-详情"，同一卡位的卡片和详情分别防重复
- 入场揭示图表之前预热一级卡的图；二级卡是另一种图（默认雷达）时也预热一次

### 三级的下拉框

- `ElDropdown`（点击打开）+ 自己的触发按钮：按钮用 `charts.module.scss` 的 `title` 类（字体、字号同其他卡片标题），写 `title` 属性，长名称在文字上省略；末尾的 `dashboard-chevron` 转 90° 朝下，展开时朝上
- 菜单列出当前二级下的全部三级（带单位），当前项高亮并写 `aria-current`；长名称在菜单里换行完整显示，菜单最高 `min(60vh, 460px)`，超出滚动
- 菜单传送到 body，外观用本 feature 的 `pickerPopper` 类（浅蓝底、`#b2d5fd` 边框、16px 字），贴近年份下拉的 `yearPopper`，不改全局 Element 主题

### 分项栏（PartTabs）

- 只在当前三级有至少两个分项时出现（`ChartCard` 的 `toolbar`）；选项是"综合"和各分项，默认"综合"
- `role="tablist"` / `"tab"`、`aria-selected`，只有选中项在 Tab 键顺序里；方向键左右切换上一个、下一个，Home、End 到两端，焦点跟着选中项
- 横向滚动、不显示滚动条；左右两个圆形按钮（`dashboard-chevron`）切到上一个、下一个分项，到头时停用，按钮停用前有焦点的话焦点交给选中的分项（不落回页面）；选中项露不全、或移动方向那一侧的边缘切着半个分项时，只滚分项栏：那一侧对齐到整个分项，并尽量多放下那一侧的分项（`revealScrollLeft`，切回第一个分项时连同"综合"滚到头）；交出焦点时不让浏览器自己滚（`preventScroll`），减少动画时不平滑滚动

### 尺寸

- 三张卡按右栏剩余高度等分；最小高度 216px（绘图区约 130px，和原驾驶舱卡片的最小高度相当），有分项栏的三级卡 248px，绘图区不因分项栏变小。放不下时右栏的列表滚动：1920×1080 下三张都是 305px；1366×768 下默认多出约 30px、有分项栏时约 60px
- 窄屏（≤1180px）右栏所在行的高度是 880px（外壳的 `--dashboard-charts-row`），三张卡每张约 285px，筛选面板也放得下六个一级；≤720px 时外壳的筛选行固定 760px，筛选内容约 860px，要在面板里滚到二级列表（记在 backlog）
- 左栏比原驾驶舱多两个一级（约 86px）：矮屏（宽于 1180px、高不超过 900px）时 `FilterPanel` 用 `compact` 收紧区块间距、标题、年份框、城市按钮和选项的行高（一级每项约 32px），二级区块的最小高度降到 108px。1366×768 下筛选面板正好放下、二级列表露出两项；1280×720 下六个一级完整、二级列表露出第一项，面板滚动约 50px；1440×900 下二级列表约 210px 高
- 二级卡的六个按钮让标题在 300 像素宽的右栏里只剩五六个字（1280×720 下"教育便…"），矮屏卡片的绘图区约 128 像素、雷达半径约 40 像素：都还没改，记在 backlog 的"待用户决定"

## 地图

- 显示当前二级：标题"2025年江苏省{二级名称}分布图"，二级的单位为空，不加括号；导出文件名"江苏省-2025-{二级名称}"
- `showValues=false`：三维标签、二维降级、导出图片都只写城市名
- 当前二级没有指数值时地图全灰、不显示图例，标题下方提示"原报告未列指数值"（`notice`）
- 右上角指北针、右下角比例尺（`topRight`、`bottomRight` 插槽）
- 悬停提示：地图悬停显示二级卡的提示表格，卡片悬停显示那张卡的；提示的 `indicatorId` 是卡位
- 时间轴只有 2025，按现有单年逻辑停用

## 与城市体检驾驶舱的差异

| | 城市体检驾驶舱 | 综合分析驾驶舱 |
|---|---|---|
| 标题 | 江苏省城市国土空间监测驾驶舱 | 江苏省城市国土空间监测综合分析 |
| 年份 | 2021～2026 多选，可以清空 | 只有 2025，不能清空 |
| 指标 | 指标类型（4 个）、具体指标 | 一级指标（6 个，带图标）、二级指标 |
| 地图 | 当前指标，标签写数值 | 当前二级，标签只写名称，没有指数值时提示；有指北针、比例尺 |
| 右栏 | 当前指标类型的全部卡片，翻卡导航、选中框、点标题切换地图 | 固定三张卡，标题不可点击；三级标题是下拉框，有分项栏 |
| 图表 | 柱、折线 | 二级多一个雷达（默认） |
| 均值 | 所选城市的算术平均 | 同 |
| 下载文件名 | {比较年份}-{指标名} | 2025-{指标名} |
