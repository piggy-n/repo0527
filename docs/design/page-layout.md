# 页面布局规范

决策：[ADR 0016](../adr/0016-ui-components-in-libs-ui.md)（通用 UI 组件放在 `libs/ui`）
设计稿：2026-09-30 确认（阶段三 3.1，静态 HTML，未入库）
组件：`libs/ui`（`@yzt/ui`）的分栏布局 `MxSplitLayout`、面板 `MxPanel`、区块 `MxSection`、标题 `MxTitle`（阶段三 3.2 实现），用法见 [modules/ui.md](../modules/ui.md)

本文规定业务页面内容区的排布：页面分几块、间距多大、面板和标题长什么样、窄屏怎么收。顶部栏和内容区背景属于 `app/layout`，见 [modules/layout.md](../modules/layout.md)。

## 为什么要统一

旧项目的主视图大多是左右结构，但每页各自实现：

- 左栏宽度有 200、296、320、348px 多种
- 左栏贴着屏幕左边，只有右边留空；主区用 `calc(100% - 32px)` 加外边距凑出高度
- 页面背景各不相同：`#f5f7fa`、`#eef4fb`、各自的渐变
- 类似的"竖杠 + 标题"在各视图里约有 82 处各自实现，字号有 20、16、14px

阶段三先定规则和组件，后续页面直接使用，不再各写一套。

## 页面类型

| 类型 | 适用 | 要点 |
|---|---|---|
| 分栏型 | 列表、管理、配置类页面：文件管理、资源管理、系统管理、数据下载、指标 | 侧栏加主区，四周留统一间距，内容放在面板里 |
| 画布型 | 地图页：现状底图、数据查询 | 地图铺满内容区，操作栏和面板悬浮在地图上。阶段五实现 |

不属于这两类的页面在迁移时再定：消息中心是单列居中（`min(1088px, 100% - 48px)`）；基本统计页的左栏可以收成窄条。

## 间距与圆角

令牌定义在 [color-and-typography.md](color-and-typography.md) 第 6.1 节：

| 令牌 | 值 | 令牌 | 值 |
|---|---|---|---|
| `--space-xs` | 4 | `--radius-sm` | 4 |
| `--space-sm` | 8 | `--radius-md` | 8 |
| `--space-md` | 12 | `--radius-lg` | 12 |
| `--space-lg` | 16 | `--radius-xl` | 16 |
| `--space-xl` | 24 | | |

使用范围：

- 圆角一律使用令牌；圆形和两端全圆的胶囊形写 `50%` 或 `999px`
- 间距在布局一级使用令牌：页面边距、面板之间、面板内边距、区块之间
- 组件内部的细小间距可以写数值（如顶部导航项的 18px 内边距），不为它们增加令牌，也不为了套令牌改变已确认的外观

## 分栏布局

```
┌────────────────────────── 内容区（背景由 AppLayout 提供）───────────────────────────┐
│                                        16                                           │
│  16  ┌─ 侧栏 ─┐  16  ┌──────────────────── 主区（自适应）───────────────────┐  16   │
│      │ 200    │      │ 面板                                                  │       │
│      │ 或 320 │      │                                                       │       │
│      └────────┘      └───────────────────────────────────────────────────────┘       │
│                                        16                                           │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

- 布局占满内容区，四周和两栏之间都是 `--space-lg`
- 侧栏宽度只有两档：菜单型 200、面板型 320。页面不写任意宽度，旧页面的 296、348 迁移时归到 320
- 主区宽度自适应，可以纵向放多个面板，面板之间 `--space-lg`
- 页面不设背景，透出内容区的渐变

**高度与滚动**：页面本身不滚动，各面板在内部滚动（flex 子项设 `min-height: 0`）。表格占满面板剩余的高度，表头固定，分页固定在面板底部；页面不再写 `calc(100% - 32px)`。

**1200 宽的复核**：窄屏断点上沿、侧栏 320 时，主区宽 1200 − 16 × 3 − 320 = 832。在设计稿中按文件管理页测算：筛选条件换成两行，"文档名称"列变窄并省略，分页和操作列都放得下。3.3 做出真实页面后再复核一次。

## 面板

```
┌──────────────────────────────────────────────────┐
│ ▍标题 ………………………………………………………… [右侧操作]   │  头部：最小高 48，左右 16，元素间距 8
│                                                  │
│ 内容区（内部滚动）                                │  内边距 0 16 16
│                                                  │
│                                      [底部，如分页] │  可选，内边距 0 16 16
└──────────────────────────────────────────────────┘
```

| 项目 | 取值 |
|---|---|
| 背景 | `--color-bg-container` |
| 圆角 | `--radius-md` |
| 边缘 | `--shadow-sm`，不加描边 |
| 头部 | 最小高 48，左右内边距 `--space-lg`，元素间距 `--space-sm`；右侧放操作按钮 |
| 头部与内容之间 | 不加分隔线，靠留白区分 |
| 内容区 | 内边距 `0 16 16`，内部滚动 |
| 底部 | 可选，内边距 `0 16 16` |

- 内容区可以去掉内边距：表格要贴边、放地图、内容自带内边距（如页面内菜单）时
- 头部可以省略：菜单型的左栏只放菜单
- 放进抽屉时去掉圆角和阴影

**菜单型左栏**（参考值，实现方式在迁移系统管理时再定）：面板无头部、内边距 8；菜单项高 44、字号 16、图标 18、圆角 `--radius-sm`，项之间 `--space-xs`；当前项 `--color-primary-bg` 底、主色文字、600 字重；悬停 `--color-primary-bg-light`。与顶部下拉菜单的配色一致。

## 标题

| 层级 | 字号 / 字重 | 颜色 | 标签 | 竖杠 | 自定义图标 |
|---|---|---|---|---|---|
| 面板标题 | 16 / 600 | `--color-text-strong` | `h2` | 4 × 16 | 20 |
| 区块标题 | 14 / 600 | `--color-text-title` | `h3` | 4 × 14 | 16 |

- 默认左侧是竖杠：宽 4、高等于字号、两端全圆、`--color-primary`，与文字间距 `--space-sm`
- 竖杠可以换成自定义图标，主色，由页面通过插槽传入（`libs/ui` 不能引用 `SvgIcon`）
- `extra` 插槽放在右侧，不参与省略；标题文字过长时省略
- 区块之间 `--space-lg`，区块标题与下方内容之间 `--space-md`；"区块标题 + 内容"用 `MxSection`，这两个间距由它负责，页面不再自己写（3.2b 加入）
- 颜色按规范原文对应：`text-strong` 用于"面板标题"，`text-title` 用于"页面 / 区块标题"，所以区块标题比面板标题略深，两者差别很小
- 旧页面的标题是 20px 和 16px，迁移后按本表小一号

## 卡片头部

旧统计页"选择查看报表"这类卡片，标题左侧是一个 20×20 的 PNG：浅蓝圆角方块里一个蓝色图形。新的写法：

- 面板头部提供浅底图标块：24 × 24，`--color-primary-bg`，圆角 `--radius-sm`；里面的图标 16、主色，由页面通过插槽传入
- 与"标题换成自定义图标"的区别只在底块：图标是标题的一部分，底块是面板头部的装饰
- 只在同一页有多张并列卡片、需要用图标区分时使用（如统计页的结果区）；普通面板用竖杠标题
- 旧项目的标题 PNG 不再使用

## 筛选栏

列表页表格上方的查询条件，用 `shared/query-form` 的 `QueryForm`（用法见 [modules/query-form.md](../modules/query-form.md)）。按是否换行分三种情况：

```
条件和按钮都放得下一行：标签按文字宽度，按钮紧跟在条件后面，"上传文档"在最右端
文档名称 [        ]  年份 [        ]  业务类型标签 [        ]  [查询] [重置]          [上传文档]

条件放得下一行、按钮放不下：标签按文字宽度，按钮另起一行，"上传文档"与最后一个输入框右对齐
文档名称 [        ]  年份 [        ]  业务类型标签 [        ]
[查询] [重置]                                     [上传文档]

条件放不下一行：换行，标签统一宽度并两端对齐，各行输入框的起点对齐；按钮另起一行，"上传文档"与最右边的输入框右对齐
文 档 名 称 [        ]  年        份 [        ]
业务类型标签 [        ]
[查询] [重置]                  [上传文档]
```

- 条件从左到右排列，靠左，不拉开分散；项之间 `--space-lg`，行之间 `--space-md`
- 控件一律宽 180
- 条件放得下一行时，标签按文字本身的宽度，不拉开字间距
- 条件换行时，所有标签取同一宽度：最长标签的字数（每字 1em）加右侧内边距 12，文字两端对齐，各行输入框的起点对齐；不论换行后有几个条件，都用这一个宽度
- 按钮另起一行时，"查询 / 重置"靠左，与第一个标签的左边对齐；页面级操作（如"上传文档"）靠右，右边与最右边的输入框对齐。按钮配图标，见下文"操作按钮"
- 编辑条件不触发请求，点"查询"或在文本框里按回车才生效；"重置"清空条件后立即查询
- 标签不能包住控件：`<label>` 包住控件时，点控件里的清除图标，浏览器会把这次点击转给输入框，下拉框随之展开。`ElFormItem` 生成的标签通过 `for` 关联控件，没有这个问题
- 与下方表格的间距 `--space-lg`，由页面设置

文件管理的三个条件按文字宽度排成一行需要 776，加上按钮和"上传文档"需要 1084：视口约 1485 以上时是第一种，约 900～1485 时是第二种（1440 宽的屏幕属于这种），更窄时是第三种（实测 1600、1440、900、760 四种宽度）。

3.3 验收时改了几版：第一版是网格，宽屏下条件被拉开、按钮被推到最右端；第二版放得下时横排、放不下时换网格，控件宽度不一，换网格后"上传文档"在右上角，和"查询 / 重置"分在两处；第三版标签总是统一宽度、按钮总是另起一行，宽屏下也占两行，标签字间距被拉开。最终按"条件是否换行"区分：不换行时保持紧凑，换行时才统一标签宽度。各宽度下的效果见主题预览页（`/dev/theme`）的"查询表单"一节。

## 操作按钮

工具栏和筛选栏里的按钮带图标，图标来自 `@element-plus/icons-vue`，同一个操作在全应用用同一个图标：

| 操作 | 图标 |
|---|---|
| 查询 | `Search` |
| 重置 | `RefreshLeft`（逆时针箭头，表示恢复初始条件，与"刷新"区分） |
| 刷新 | `Refresh` |
| 新增 | `Plus` |
| 上传 | `Upload` |
| 下载、导出 | `Download` |
| 批量删除 | `Delete` |

- 表格行内的文字按钮（如"删除"）不加图标，保持紧凑
- 新的操作先补进这张表，再在页面中使用；表中的按钮可以在主题预览页的"按钮"一节查看

## 窄屏

视口宽度 < 1200 时，左栏收进抽屉。

- 断点与顶部导航收成"☰ 菜单"的断点相同，全应用只有一个"窄屏"定义，由 `libs/ui` 提供（ADR 0016）
- 为什么不直接隐藏：迁移范围内的左栏多是页面内导航（系统管理）或筛选条件（文件管理的目录树、资源管理的资源菜单），隐藏等于在窄屏上拿掉功能
- 用 `ElDrawer` 从左侧滑出，宽度等于侧栏档位，按 `ElDrawer` 的默认行为盖住整个窗口
- 左栏收成左侧 40 宽的窄条，点击打开抽屉：外观与面板相同，上面是图标（`Expand`）和竖排的左栏名称。只放图标更省地方，但看不出点开是什么，未采用
- 为什么是窄条（3.3 验收后调整）：初版把打开按钮放在主区第一个面板头部的最左侧，后接竖线再接标题，和页面标题处在同一行，视觉上抢了标题的位置，"页面标题"和"功能入口"分不清。对比了"筛选区上方单独一行"和"左侧窄条"两种做法，采用窄条：和宽屏时的空间关系一致（目录一直在左边，只是收起了）；由布局统一渲染，页面不用放按钮；不占纵向空间，表格多显示一行。代价是横向少 56（窄条 40 + 间距 16），窄屏下可以接受
- 抽屉里放的是左栏原来的面板（去掉圆角和阴影），头部右侧加关闭按钮；点遮罩、按 Esc 也能关闭
- 在抽屉里选中一项后是否自动关闭由页面决定：导航类（文件目录）建议关闭，筛选类保持打开
- 窗口宽度跨过断点时，左栏内容在侧栏和抽屉之间切换，展开的树节点、滚动位置等状态都保留：用 `Teleport` 移动内容而不重新创建，滚动位置由布局记下并写回（3.2c 实现，见 [modules/ui.md](../modules/ui.md) 的 MxSplitLayout）
- 只做抽屉一种；以后遇到只放辅助信息的左栏，再给布局组件加"直接隐藏"的选项

## 画布型（阶段五实现）

- 地图铺满内容区，没有圆角和边距
- 操作栏和面板悬浮在地图上，离地图边缘 `--space-lg`；沿用面板规范（头部、内边距、标题），背景用 `--color-bg-mask`，另加 `--shadow-md`
- 悬浮面板统一用浅色。现状底图的图层面板是白色 94%，图例面板是深蓝渐变 96%，两种混用；深色和白色的弹窗、下拉、消息提示放在一起不统一，Element 组件放进深色面板也要逐个做深色变体。以后在影像底图上确实看不清时，再作为面板的一个变体加入，并先补令牌
- 地图定位（`fitBounds` 等）的可视区域要避开悬浮面板：由布局提供被占用的区域，页面不自己计算（旧数据查询页的 `getSpatialQueryFitPadding` 是各自计算的例子）

## 设计稿确认的取舍

| 事项 | 采用 | 未采用 | 理由 |
|---|---|---|---|
| 面板边缘 | `--shadow-sm` | 无；1px `--color-border` | 规范中 `shadow-sm` 的用途就是"侧边栏、常驻容器"；白底放在 `#F5F7FB` 上只靠底色区分时边界不清 |
| 头部分隔线 | 不加 | `--color-border-light` | 表格、树自带横线，再加分隔线显得线条太多 |
| 窄屏的左栏入口 | 左侧窄条：图标 + 竖排的左栏名称（3.3 验收后调整） | 只有图标；主区面板头部的按钮（初版）；筛选区上方单独一行 | 只有图标时看不出点开是什么；放在标题行会抢标题的位置；单独一行要每个页面自己放，还占一行高度 |
| 卡片头部 | 只用于并列卡片 | 所有面板 | 普通面板用图标块会显得杂乱 |
| 悬浮面板 | 浅色 | 深色 | 与弹窗、下拉等浮层统一，Element 组件不用做深色变体 |
| 菜单型左栏 | 面板，四周留间距 | 贴边的整条白栏（旧页面） | 与面板型一致 |
| 树的层级（3.3 验收后加入） | 分组加粗 + 层级引导线 | 只区分字重；文件夹图标 | 三层的分支更容易分清父子；图标显得杂乱。详见 [theme.md](theme.md) 的"树的全局样式" |
| 抽屉范围 | 盖住整个窗口 | 只盖内容区 | `ElDrawer` 的默认行为，两者差别不大 |
