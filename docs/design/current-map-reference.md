# 现状底图：已验收交互样例

2026-10-20 页面样式调整收尾。业务界面基线为 `4aa3253`；本轮补充开发预览，不改变业务页面交互。

## 打开与使用

- 开发地址：`/dev/map-ui`，也可从 `/dev/theme` 顶部的「已验收页面样例」进入
- 默认端口以已启动的服务为准；本轮使用 `http://localhost:5174/dev/map-ui`
- 源码：`apps/web/src/pages/dev/map-ui/`
- 仅注册在开发路由，不进入生产产物；不启动额外服务

样例直接装配真实的资源图层、图例、功能面板、行政区设置、工具栏、底图浮层与标题组件。样例样式只负责画布、说明和状态表的布局，不复制组件内部样式。

目录是固定的六个资源，包含点、线、面、复杂图例、长名称和不同年份组合。所有状态只在本页存活，不读取或写入用户偏好；「还原样例」重新创建组件和状态拥有者。

本页不挂载地图引擎、不请求资源接口或地图瓦片；底图缩略图是本地示意图。图层选项、透明度、年份与符号修改可在真实组件间联动，但地图画面、定位、点选、查询及持久化仍应在 `/current-map` 验收。本页不替代地图渲染验证。

## 已确认的规则

| 元素 | 复用入口 | 当前规则 |
|---|---|---|
| 标题 | `MxTitle` | 主标题 16 / 600，区块标题 14 / 600，黑色加粗及蓝色竖条；辅助文字 12 |
| 面板 | `MxPanel`、`MapPanelGroup` | 地图主标题浅灰背景由地图外壳提供；通用面板不全局改色 |
| 功能标签 | `MapPanelGroup` + `usePanelGroup` | 单功能直接作标题，多功能显示「地图工具」及两列标签；标签关闭与关闭全部分别作用，整体可收起 |
| 工具栏 | `MapToolbar` | 图标入口，当前显示与已打开状态由页面传入，不在工具栏重复保存 |
| 资源树 | `ResourceLayerPanel` | 数量胶囊标识；已勾选默认收起，零勾选时整区隐藏；整行悬浮切换排序手柄 |
| 透明度 | `LayerOpacity`、`OpacityToggle`、`OpacitySlider` | 入口随行悬浮或键盘焦点显示；弹层不影响勾选，滚动立即关闭；选中状态随弹层状态 |
| 底图 | `MapCard`、`MapOptionsPopover`、`BasemapPanel` | 80 × 56 缩略图入口；左侧带箭头浮层，紧凑操作栏；外部点击不关闭，再次点击入口或 × 关闭 |
| 图例 | `ResourceLegend`、`SymbolEditor` | 浏览与编辑分开；普通图例整行编辑；复杂子图例缩进 24、色块 22 × 16、名称完整换行；父级摘要 28 × 20 |
| 恢复操作 | `ResourceLegendReset` | 有修改的浏览视图才显示固定底栏，顶部留 12；编辑中区分当前图例与本图层恢复，全局恢复提示明确包含未勾选图层 |

详细规范与取舍继续以 [页面布局](page-layout.md)、[主题令牌](theme.md)、[ADR 0070](../adr/0070-map-functional-tabs-and-detail-stack.md)及 [ADR 0074](../adr/0074-legend-browse-and-edit-views.md)为准。

## 批量年份：不是统一年份筛选

用户提出“批量设置成功，但输入框未回显”的问题，经设计记录、实现和既有测试核对，这是原本约定的行为：

1. [ADR 0052 第 2 节](../adr/0052-resource-years.md)明确选择后立即执行、不保留选中值；第 5 节要求检查选择框回到空
2. `ResourceLayerPanel.tsx` 将选择器的 `modelValue` 固定为 `undefined`，选择后调用 `setYearForAll`
3. `ResourceLayerPanel.test.tsx` 检查批量结果、空值以及连续两次选同一年均可执行

批量设置只修改拥有目标年份的资源，包括尚未勾选的资源；其他资源保持原年份。随后还能单独改某一层，因此不能把最后一次操作的年份当作全部资源的当前年份。实际年份在「已勾选」、图例及样例状态表中查看。

本轮保留该规则。若以后优化操作反馈，可以另行讨论成功提示或明确标注“最近批量设置”，不能未经定义就改成全局年份或用最后一次选择代替资源状态。

## 可重复检查路径

| 场景 | 操作与预期 |
|---|---|
| 批量年份 | 选 2023；村级调查区、水域线层切到 2023，地类保持 2021、坑塘保持 2024；选择框恢复占位 |
| 重复批量 | 展开已勾选，把水域线层单独改为 2025，再批量选 2023；水域线层再次切回 2023 |
| 空与单项 | 切「无资源」时已勾选区域消失、图例为空；切「单个资源」和「多个资源」后正常恢复 |
| 排序与透明度 | 展开已勾选，按住手柄拖动或用上下键排序；序号与图例顺序同步；透明度两处入口同步，滚动关闭浮层 |
| 图例阅读 | 展开复杂图例，搜索、完整名称、悬浮含义、长列表滚动；缩至 280 / 240 宽后允许单列而不横向溢出 |
| 图例编辑 | 点击普通行或子图例编辑，返回后保留浏览状态；有修改才出现全局恢复，编辑时隐藏；确认取消不改状态 |
| 功能面板 | 右侧两个图标打开图例和行政区，比较单功能与多标签；逐项关闭、全部关闭、整体收起与重开 |
| 底图 | 打开、切换、调整透明度；无底图时隐藏透明度；点击外部保持打开，再点入口或 × 关闭 |
| 尺寸 | 用 320 / 280 / 240 宽、520 / 360 高检查；页面窄屏下样例按列换行 |
| 隔离与还原 | 修改本页不影响业务偏好；「还原样例」清除本页临时状态 |
