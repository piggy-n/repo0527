# 现状底图：已验收交互样例

2026-10-20 页面样式调整收尾。业务界面基线为 `4aa3253`；本轮补充开发预览，不改变业务页面交互。

## 打开与使用

- 开发地址：`/dev/map-ui`，也可从 `/dev/theme` 顶部的「已验收页面样例」进入
- 默认端口以已启动的服务为准；本轮使用 `http://localhost:5174/dev/map-ui`
- 源码：`apps/web/src/pages/dev/map-ui/`
- 仅注册在开发路由，不进入生产产物；不启动额外服务

样例直接装配真实的资源图层、图例、功能面板、行政区设置、工具栏、底图浮层与标题组件。样例样式只负责画布、说明和状态表的布局，不复制组件内部样式。

目录是固定的六个资源，包含点、线、面、复杂图例、长名称和不同年份组合。所有状态只在本页存活，不读取或写入用户偏好；「还原样例」重新创建组件和状态拥有者。

本页不挂载地图引擎、不请求资源接口或地图瓦片；底图缩略图是本地示意图。图层选项、透明度、年份与符号修改可在真实组件间联动，但地图画面、定位、点选、查询及持久化仍应在 `/current-map` 验收。本页不替代地图渲染验证。

## 已确认的界面细节

下面是 ADR 0066～0074 之后历次界面反馈中由用户确认的细节，2026-10-23 从 AGENTS.md 原样移到这里（AGENTS.md 只留一条指向本节的规则）。改这些界面前先读本节；用户确认新的调整后同步更新本节，必要时写新的 ADR。

- 现状底图的界面优化按 ADR 0066～0070 及后续界面反馈："已选择图层"区域默认收起、入口浅灰底且无阴影，零勾选时连同分割线一起隐藏（2026-10-28 由"已勾选"改名，ADR 0094）；资源树数量与已选择图层数量使用同款灰底胶囊标识；资源树与列表复用 `LayerOpacity`，显隐只随行悬停或键盘焦点，鼠标残留焦点不维持显示；复合图例默认展开（ADR 0094），收起后是多色块摘要，与普通符号统一 28 × 20 区域。右侧面板列最大高度到基础工具栏底部，底图打开后按其实际顶部预留 12；底图与行政区透明度入口复用 `OpacityToggle`
- 资源透明度浮层固定在视口内；鼠标离开按钮与浮层 2 秒后关闭，移回取消计时，拖动滑块期间暂停计时；滚动或页面停用立即关闭，计时器和监听随浮层入口卸载清理
- 图例不显示顶部数量说明或设置栏；资源行与分类行使用 12 字号，展开箭头在色块前，普通图例保留箭头占位以逐列对齐。普通或统一配色图例点击整行编辑，不保留重复设置按钮；复杂图层设置按钮仅随行悬停或键盘焦点显示，编辑状态和鼠标残留焦点不维持显隐。有符号覆盖且处于浏览视图时，在 `MapPanelGroup` 的 `legend-footer` 插槽提供「全部恢复默认」，上方留 12，复用 `MxPanel` 固定底栏，与内容滚动分离；编辑、切走、收起或停用时隐藏
- 图例浏览与编辑按 ADR 0074：搜索和子图例整体缩进 24，子色块为 22 × 16，父级摘要仍为 28 × 20；地类平铺、名称完整换行，不再展示分类方式选择器。悬浮通过原生 `title` 看含义，点击条目进入单项编辑。配色方式在设置视图中切换，文案为「按类别配色 / 统一配色」；返回入口与当前名称同行，返回保留搜索、展开和滚动位置，继续复用原有符号编辑器及状态拥有者
- "已选择图层"列表整行悬浮时编号切为拖拽手柄，拖拽仍只从手柄开始；行政区选项显示省 / 市 / 县，线型保留，透明度入口同行并用细线分隔。功能容器按 ADR 0071～0073 及后续界面反馈：单功能用功能名称作标准标题、隐藏标签区，多功能用「地图工具」标题、下方每行两项标签；数量变化不重新挂载内容。标签沿用资源详情副标题的深色、14 / 600 和 4 × 14 蓝色竖条，选中用整块浅蓝底和内描边，悬浮保持；单项用小叉关闭，标题右侧与资源详情共用收起 / 展开箭头和关闭图标，关闭图标关闭全部功能，不加重复 Tooltip。收起只保留 48 高标题行，功能状态保留
- 底图 Popover 按 ADR 0070 及后续界面反馈：再次点击入口或右上关闭按钮关闭，不设标题；外部点击、失焦和 Esc 不关闭，页面停用仍关闭。顶部操作栏高 24，透明度和关闭按钮靠右、间隔 8，上方留 8、下方留 4，不加背景或分隔线；缩略图占满下方整行，标签叠在右下角，滑块再向下展开。内容自然撑高、不设滚动区。透明度入口用独立选中类与 `aria-pressed` 绑定展开状态，不依赖 Tooltip 会覆盖的 `aria-expanded` 控制样式；行政区改为功能标签，不再使用 Popover
- 地图 Tooltip 共用 `shared/map/tooltip.ts` 的参数：悬停 200 毫秒显示、移出立即关闭、无淡出动画、不进入提示框、不保留关闭后的节点；透明度滑块旁已有数值时不重复弹出提示。「无底图」缩略图显示 32 像素自绘禁用图标、SVG 描边 2，沿用中性文字色，为右下角标签留出空间
- 区划定位保留搜索和当前位置，市与区县之间用 `--color-divider` 浅灰分隔线，不显示分组说明；选项采用 12 像素字号、24 高、4 间距、最小宽 52，常规 320 宽面板每行 5 项，窄屏减少列数以保留完整名称
- 现状底图的资源图层、地图工具（含单功能）、资源详情主标题栏统一用 `--color-neutral-bg-light` 浅灰背景；"已选择图层"展开与收起时同色。地图工具的标签区与内容之间用 `--color-divider` 灰色分隔线，单功能无标签时不显示该线；底图不设标题栏

- 三维（ADR 0078 的原型、ADR 0080）：点/框选在三维里不识别，鼠标旁用 `PointerHint` 写两行"三维模式暂不支持点/框选""切换到二维后使用，按住 Ctrl（Mac 上 ⌘）拖动地图"，单击后不关闭；图例面板只显示"三维模式暂不显示资源图层，图例在切回二维后可用。"（12 字号、次要文字色），不显示"全部恢复默认"；状态栏第一段是"视点高度 420 km"这样的写法，代替比例尺，视点在地表以下时写"视点在地表以下 18 m"、不显示画布中心的经纬度
- 三维模型（ADR 0081，2026-10-26 验收）：三维时左侧是"三维模型"面板，和资源图层面板同宽、同样的标题栏和收起竖条；按市分组、默认展开、带数量胶囊，搜索匹配模型名或市名，勾选即加载。底部"已加载"按勾选的先后排列，整行开关同"已选择图层"；每行是名称、"钻地"标签、定位和卸载图标按钮（Tooltip 写名称），下一行是"市 · 类型"，白膜后面是效果下拉；加载中写"加载中…"，失败写"加载失败"并给"重试"；不标出最近定位的行（2026-10-28 去掉左侧的蓝条，ADR 0094）。钻地条在地图下方居中、状态栏上方：标题"钻地观察 · 模型名"、"地表不透明度"滑块（0～60%，每格 5%）和百分比、"退出钻地"文字按钮；手机宽度时横跨左边两列，不挡右边的视图切换

## 批量年份：不是统一年份筛选

用户提出“批量设置成功，但输入框未回显”的问题，经设计记录、实现和既有测试核对，这是原本约定的行为：

1. [ADR 0052 第 2 节](../adr/0052-resource-years.md)明确选择后立即执行、不保留选中值；第 5 节要求检查选择框回到空
2. `ResourceLayerPanel.tsx` 将选择器的 `modelValue` 固定为 `undefined`，选择后调用 `setYearForAll`
3. `ResourceLayerPanel.test.tsx` 检查批量结果、空值以及连续两次选同一年均可执行

批量设置只修改拥有目标年份的资源，包括尚未勾选的资源；其他资源保持原年份。随后还能单独改某一层，因此不能把最后一次操作的年份当作全部资源的当前年份。实际年份在「已选择图层」、图例及样例状态表中查看。

2026-10-28 起（ADR 0094）选项固定加上 2020、2021：数据里还没有这两年时也列出，选了没有任何资源有数据的年份时提示"没有资源有 2020 年的数据，图层保持不变"，图层不变。

本轮保留该规则。若以后优化操作反馈，可以另行讨论成功提示或明确标注“最近批量设置”，不能未经定义就改成全局年份或用最后一次选择代替资源状态。

## 可重复检查路径

| 场景 | 操作与预期 |
|---|---|
| 批量年份 | 选 2023；村级调查区、水域线层切到 2023，地类保持 2021、坑塘保持 2024；选择框恢复占位 |

| 没有数据的年份 | 批量选 2020：提示没有资源有这一年的数据，各图层年份不变 |

| 排序与透明度 | 展开已选择图层，按住手柄拖动或用上下键排序；序号与图例顺序同步；透明度两处入口同步，滚动关闭浮层 |
| 图例阅读 | 复合图例默认展开，搜索、完整名称、悬浮含义、长列表滚动；收起后是多色块摘要；缩至 280 / 240 宽后允许单列而不横向溢出 |

| 功能面板 | 右侧两个图标打开图例和行政区，比较单功能与多标签；逐项关闭、全部关闭、整体收起与重开 |

| 尺寸 | 用 320 / 280 / 240 宽、520 / 360 高检查；页面窄屏下样例按列换行 |
| 隔离与还原 | 修改本页不影响业务偏好；「还原样例」清除本页临时状态 |
